# Task 9.6 — Panel Content Pass B (Fans, Network, Disk, Power)

**Phase:** 9 (Stage B) · **Depends on:** 9.4 (parallel with 9.5) · **Rules:** 3, 4, 5

## Intent
Same contract as 9.5 for Fans, Network, Disk and Power, plus: unify chart heights (the literal 84 becomes a token), make Network show the selected interface, give Disk a per-volume view, and show Power as Battery or Power depending on `hasBattery`.

## Current code

- `MetricCategory.symbolName(hasBattery:)` / `CategoryIdentity.symbol(hasBattery:)` (9.1).
- `PreferencesStore.networkInterfaceSelection` (9.2); `StatusThresholds.disk/battery/fan`.
- `Sources/iStatsCore/RateMath.swift` for throughput rates (reset gives 0); disk SI/IEC formatting from the bug fix commit be67c76 must stay.

## Approach
1. Apply the one-value-once contract per panel; Fans keeps "read-only" label and the fanless state (`fan.slash`); Network Now shows down/up rate once plus interface chip; Disk Now shows used % and I/O rate, Details lists volumes; Power Now shows charge/watts/time remaining on battery Macs and adapter watts on desktops.
2. Replace the 84 literal with `Size.chartHeightStandard`, literal fonts with tokens, literal thresholds with `StatusThresholds`.
3. Network interface picker: footer-free control in Details writing `networkInterfaceSelection`.
4. `glossaryKey` on rows (cache hit, link speed, health, cycle count, fan target) for 9.11.
5. No fan write paths (invariant); no IOKit/SMC on `@MainActor`.
