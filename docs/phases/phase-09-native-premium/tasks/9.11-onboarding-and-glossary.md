# Task 9.11 — Onboarding (Welcome) and Metric Glossary

**Phase:** 9 (Stage E) · **Depends on:** 9.2, 9.10

## Intent
First-run `WelcomeWindow` that picks a `MenuBarPreset`, appearance and optional launch at login, and a `MetricGlossary` with `InfoButton` so terms (memory pressure, compressed, thermal state, cycle count) are explained in context.

## Current code
- `PreferencesStore.hasCompletedOnboarding` (9.2; true for migrated existing users), `MenuBarPreset` (9.8), `menuBarAppearance` (9.2).
- `iStats/App/iStatsApp.swift` (app launch), launch-at-login handling in the General pane (find with `grep -rn "SMAppService" iStats`).
- `MetricRow.glossaryKey` anchors (9.5, 9.6), keyboard `?` stub from 9.3.

## Approach
1. **Core.** `Sources/iStatsCore/MetricGlossary.swift`: `GlossaryEntry(key, title, summary, learnMore)`; `MetricGlossary.entry(for:)`; every `glossaryKey` used in panels must exist (test enumerates keys passed in by a registry constant `MetricGlossary.requiredKeys`).
2. **InfoButton.** `iStats/UI/Instrument/InfoButton.swift` (new): small `info.circle` button opening a popover with the entry; accessible label "About <title>".
3. **Welcome.** `iStats/App/WelcomeWindow.swift` and `iStats/UI/Welcome/WelcomeView.swift` (new): steps Preset (minimal/balanced/everything with live `WidgetPreview`), Appearance, Done. Applying writes `menuBarItems`, `menuBarAppearance`, `hasCompletedOnboarding = true`. Skippable; skipping applies `balanced`.
4. **Trigger.** App launch shows Welcome only when `hasCompletedOnboarding == false`; Settings > About has "Show welcome again".
5. Wire `?` in `MetricPanel.keyDown` to open the glossary list for the current page.
