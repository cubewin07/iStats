## Approach
1. **Audit per panel**: list every displayed value; remove duplicates so each appears once (e.g. CPU total % shown in headline and again in the ribbon; Memory used shown in headline and legend).
2. **Now page**: headline value + live chart (`Size.chartHeightStandard`) + 3-4 key `MetricRow`s. **Details**: per-core (CPU), breakdown segments (Memory app/wired/compressed/cached via palette series), top consumers if already sampled, thermal sensors list. **History**: `HistoryPage` with range from `categoryHistoryRanges`.
3. Replace remaining literals with tokens (9.1 sweep leaves panel-specific ones); use `StatusThresholds` helpers; use `CategoryIdentity` for titles.
4. Add `InfoButton` anchor points (no-ops until 9.11): `MetricRow` gets an optional `glossaryKey: String?`.
5. Accessibility: each row has combined label+value; charts expose a summary label.
