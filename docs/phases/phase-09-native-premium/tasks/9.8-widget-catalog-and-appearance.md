# Task 9.8 — Widget Catalog and Appearance Controls

**Phase:** 9 (Stage C) · **Depends on:** 9.7, 9.2 · **Blocks:** 9.10

## Intent
Offer users a catalog of widgets per category (what it shows, preview) and an appearance switch (monochrome, status tint, category color), backed by `WidgetModel` previews, so choosing a widget is visual and the stored config stays small.

## Current code
- `Sources/iStatsCore/MenuBarItemConfig.swift` (`supportedStyles`, `defaultConfigs()`), `PreferencesStore.menuBarItems`, `activeMenuBarItems` (716), `setActiveMenuBarOrder` (732).
- `iStats/UI/PreferencesMenuBarPane.swift` (existing item editor, replaced in 9.10), `PreferencesComponents.swift`.
- `WidgetModel` and renderers from 9.7; `PreferencesStore.menuBarAppearance` from 9.2.

## Approach
1. **Catalog core.** `Sources/iStatsCore/WidgetCatalog.swift`: `WidgetCatalogEntry(category, style, title, summary, sampleValues)`; `WidgetCatalog.entries(for:hasBattery:)`; `defaultEntry(for:)`. Catalog must agree with `supportedStyles` (test).
2. **Preview views.** `iStats/UI/MenuBar/WidgetPreview.swift` (new): renders a `WidgetModel` with sample or live data at 1x/2x, honoring appearance and light/dark.
3. **Catalog UI.** `iStats/UI/Settings/WidgetCatalogView.swift` (new, hosted in Settings by 9.10): grid of entries per category with Add/Replace actions, appearance segmented control bound to `menuBarAppearance`.
4. **Presets.** `MenuBarPreset` (core, used by 9.11): `minimal` (CPU value), `balanced` (CPU bar, Memory bar, Network throughput = today's default), `everything`; `MenuBarPreset.configs(hasBattery:)`.

## Tests
- `WidgetCatalogTests`: every category has at least one entry; entries equal `supportedStyles`; battery-only entries hidden without battery.
- `MenuBarPresetTests`: `balanced` equals `defaultConfigs()`; every preset valid (unique ids, supported styles).
- `WidgetPreviewTests`: renders non-empty image for each entry in light and dark.

## Validation commands
```
swift test --scratch-path /tmp/istats-build --filter WidgetCatalogTests
swift test --scratch-path /tmp/istats-build --filter MenuBarPresetTests
xcodebuild test -scheme iStats -destination 'platform=macOS' -only-testing:iStatsTests/WidgetPreviewTests
```

## Acceptance criteria
- Catalog lists every supported widget with a live preview; appearance changes the menu bar immediately; presets produce valid configs.

## Risks
- Catalog diverging from renderer support: guarded by the test equating it with `supportedStyles`.

## Out of scope
Settings window shell (9.9), wiring into Settings and removal of the old pane (9.10).
