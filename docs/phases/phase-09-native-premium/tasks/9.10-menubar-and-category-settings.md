# Task 9.10 — Menu Bar Editor, Category Settings, Sustained Alerts

**Phase:** 9 (Stage D) · **Depends on:** 9.7, 9.2, 9.9 · **Blocks:** 9.11

## Intent
Fill the Settings sections: a Menu Bar editor using the widget catalog, per-category settings (widget, refresh, thresholds, alert rule), and a real alert engine with sustain, cooldown and hysteresis that replaces the single-sample alert logic.

## Current code
- `iStats/App/AlertCoordinator.swift`: **app-target `struct AlertEvaluator`** (evaluateCPU/Memory/Battery/Thermal/Disk, emoji titles) and `AlertCoordinator` (`AlertType`, `lastAlertTimes` cooldown); tests in `Tests/iStatsTests/AlertCoordinatorTests.swift`. Reads the 15 legacy alert keys (lines ~198-266).
- `iStats/UI/PreferencesAlertsPane.swift`, `PreferencesMenuBarPane.swift` (item editor, drag reorder, `MenuBarOrdering`).
- `PreferencesStore.alertRules` / `AlertRule` (9.2), `WidgetCatalog` (9.8), `SettingsSection` (9.9).
- `Sources/iStatsCore/StatusThresholds.swift` for default thresholds.

## Approach
1. **Name collision first.** Rename the app-side `AlertEvaluator` struct to `AlertMessageBuilder` (it only builds titles/bodies), update `AlertCoordinatorTests`. The core type below then takes the name `AlertEvaluator`.
2. **Core engine.** `Sources/iStatsCore/AlertEvaluator.swift`: value type with per-rule state (`pendingSince`, `lastFired`, `armed`). `mutating func evaluate(rule:value:now:) -> AlertDecision` (`none`, `fire`, `clear`). Rules: fire only after value held past threshold for `sustainSeconds`; no re-fire within `cooldownSeconds`; re-arm only after value crosses back by a hysteresis margin (default 5 percent of threshold or 2 degrees). Unavailable readings reset pending state.
3. **Coordinator.** `AlertCoordinator` feeds `MetricsStore` latest values into the evaluator on its existing tick, posts notifications built by `AlertMessageBuilder`; remove legacy key reads after 9.2 migration populated `alertRules`; delete the 15 legacy keys from `PreferencesStore` and `resetToDefaults`.
4. **Menu Bar section.** `iStats/UI/Settings/MenuBarSettingsView.swift`: active items list (reorder, remove), Add via `WidgetCatalogView`, appearance picker. Replace `PreferencesMenuBarPane`.
5. **Category sections.** `iStats/UI/Settings/CategorySettingsView.swift`: widget choice, refresh interval (existing `refreshInterval`), threshold and alert rule editor (enable, threshold, sustain, cooldown). Alerts section lists all rules with a master toggle.
