# Task 9.4 — Overview Destination and One-Value-Once Page Contract

**Phase:** 9 (Stage B) · **Depends on:** 9.3 · **Blocks:** 9.5, 9.6 · **Rules:** 2, 3

## Intent
Build the Overview screen (one tile per active category with a live value, spark, and status) and define the page contract that 9.5/9.6 apply: **Now** (current value, live chart, key rows), **Details** (breakdown, per-item lists), **History** (range, stats). A value appears once per page. Rename the page labels without changing stored raw values.

## Current code
- `Sources/iStatsCore/PopoverConfig.swift`: `PopoverTab` raw values `overview/detail/history`; `supportedTabs(for:hasBattery:)`; display names in `iStats/UI/Panels/PageSwitcher.swift`.
- `PanelFactory.makePanelView` / `makeCategoryPanelView` (`iStats/UI/Panels/PanelFactory.swift`); `PanelScaffold` takes the page content closure.
- `Sources/iStatsCore/MetricsStore.swift`: `scalarPoints(for: ScalarSeriesKey)`, `latest(for:)`, `readings(for:)`; `StatusThresholds` for status; `CategoryIdentity` (9.1) for symbol/name; `PreferencesStore.activeMenuBarItems` (716) / category order (`setActiveMenuBarOrder` 732) for tile order.
- `iStats/UI/Instrument/` building blocks: `MetricRow`, `LiveChart`, `Sparkline`-style views, `StatusRibbon`.

## Approach
1. **Core summary model.** `Sources/iStatsCore/OverviewTileModel.swift`: pure `OverviewTileModel(category:, headline: String, unit:, spark: [Double], status: StatusLevel, availability)` built by `OverviewTileModel.make(category:snapshot:history:hasBattery:)`, one per category with headline rules (CPU total %, Memory used %, GPU %, Temperature peak C, Fans rpm or "No fans", Network down/up rate, Disk used % or I/O, Battery % / watts). Uses `RateMath`/`StatusThresholds`; unavailable maps to `Availability.unavailable(reason:)` text.
2. **View.** `iStats/UI/Panels/OverviewView.swift` (new): 2-column grid of tiles in 320 pt content width; tile = identity symbol, value, spark, status chip; tap swaps destination to that category; drives off `MetricsStore` snapshots (no sampling on main actor).
3. **Page contract.** Document in `design.md` and encode in a `PanelPageSection` helper (`Now`, `Details`, `History` headers use `Instrument.Typography.eyebrow`). Rename labels in `PageSwitcher` to Now / Details / History; keep `PopoverTab` raw values and `categoryLastTabs` data.
4. **Overview wiring.** `PanelFactory.makePanelView(destination: .overview)` returns `OverviewView`; the footer page switcher is hidden on Overview.
5. **Empty/loading states.** Fresh install (no samples yet) shows placeholders ("--") not zeros; unavailable categories show the reason with the `info` symbol.
