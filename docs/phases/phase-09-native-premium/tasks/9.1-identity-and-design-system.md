# Task 9.1 — Identity and Design-System Foundation

**Phase:** 9 (Stage A) · **Depends on:** 9.0 · **Blocks:** 9.2 to 9.12 · **Rules:** 1, 3, 4

## Intent
Make `CategoryIdentity` the single source of category name, short label, symbol and live symbol; re-hue the palette so identities are stable across appearances; unify `StatusLevel` symbols; collapse the two token systems into `Instrument`; and make panels read thresholds from `StatusThresholds`.

## Current code
- `Sources/iStatsCore/MetricCategory.swift`: `displayName` (power = "Battery & Power"), `symbolName(hasBattery:)` and `symbolName`, `shortLabel(hasBattery:)` and `shortLabel`. Used by `iStats/UI/PreferencesComponents.swift:196` (`preferenceCategoryIcon`), `PanelScaffold.swift:313,802`, `MenuBarIconRenderer.swift`, tests in `Tests/iStatsCoreTests/MetricCategoryTests.swift`.
- `Sources/iStatsCore/PaletteContrast.swift`: `PaletteContrast.Hex.categoryTint/categoryDeep/status` plus series hexes; `Tests/iStatsCoreTests/PaletteContrastTests.swift`. `iStats/UI/Design/CategoryPalette.swift` builds dynamic colors from them (no asset-catalog `Palette` folder exists on disk, although the 8.1 summary mentions one).
- `StatusLevel.symbolName` (`StatusThresholds.swift:23`, `checkmark.circle`) vs `StatusLevel.iconName` (`CategoryPalette.swift:223`, `.fill` variants); `MetricRow.swift:48` uses `symbolName`.
- `iStats/UI/Design/Tokens.swift`: unreferenced; pbxproj entries `110000000000000000000150` (file ref), `...151` (build file), group child (~line 319) and Sources phase (~line 540).
- `iStats/UI/Instrument/InstrumentTokens.swift`: `Typography` has `display 44, unit 17, displayCompact 30, title 15, headline 13, body 12, value 12, caption 11, sectionTitle 11.5, control 11 (unused), eyebrow 10, micro 9 (29 uses), mono 11`; `Size` has `panelWidth 352, contentWidth 320, maxHeight 560, chartHeight 72, historyChartHeight 140, eyebrowHeight 28`.

- Literal thresholds: `CPUPanel.swift:186-198,553` (90 / 75 / `1.5x` cores) instead of `StatusThresholds.cpu(usagePercent:)`.

## Approach
1. **Identity (core).** Add `Sources/iStatsCore/CategoryIdentity.swift`: `struct CategoryIdentity { displayName(hasBattery:), shortLabel(hasBattery:), symbol(hasBattery:), liveSymbol(_ state: LiveSymbolState) }` and `LiveSymbolState` (battery charge percent + charging, interface kind, volume external flag, thermal peak, fanless). Table per ADR 0011. Make `MetricCategory.symbolName/shortLabel` forwarders; change `displayName` for `.power` to "Battery" (default `hasBattery: true`) with a `displayName(hasBattery:)` that returns "Power" on desktops. Update call sites (`PanelScaffold`, `PreferencesComponents`, renderer) to `CategoryIdentity`.
2. **StatusLevel symbols.** One mapping in core (`StatusLevel.symbolName` plain, `symbolNameFilled`); `CategoryPalette` `iconName` forwards or is removed; update `MetricRow`/`StatusRibbon` and `AccessibilityAppearanceTests`.
3. **Palette.** Edit `PaletteContrast.Hex.categoryTint/categoryDeep` per ADR hue family (Network cyan, Disk pink-magenta, Power lime, Fans neutral steel, Memory mint) with the same hue in light and dark. Add `RGBColor.hueDegrees` and a hue-distance helper in core. Final hexes must pass the new tests.
4. **Tokens.** Delete `Tokens.swift` and its four pbxproj entries. In `Instrument.Typography` remove `sectionTitle` (11.5), `control`, set `micro` = 10 and `eyebrow` = 10; keep `display 44, displayCompact 30, title 15, headline 13, body 12, value 12 mono, caption 11`. Add `Space.sectionGap` (12), `Size.headerStripHeight` (28), `Size.footerHeight` (24), `Size.chartHeightCompact/Standard/Tall` (replacing the literal 84 in Fan, Network, Disk and the scaffold default 72).
5. **Thresholds.** Replace literals in `CPUPanel` (and the equivalents in other panels found by grep for `>= 9`, `>= 7`, `> 8`) with `StatusThresholds.*`; add missing helpers to core with tests rather than inline numbers.
6. **Mechanical sweep.** Replace every literal `.font(.system(size:` under `iStats/UI/Panels` and `iStats/UI/Instrument` (icon glyph sizes use a `Typography.icon(size:)` helper) and the stray radius literals (4 to 7) with tokens.

## Tests
- `CategoryIdentityTests` (core): every category has non-empty name/symbol/short label; Power name/symbol follow `hasBattery`; live symbol follows state (battery 0/25/50/75/100 and charging, wifi vs ethernet, fanless `fan.slash`, thermal low/medium/high).
- `PaletteContrastTests` extended: pairwise hue distance >= 25 deg between saturated categories; light/dark drift <= 15 deg; >= 15 deg from status hues except Fans; WCAG AA on surfaces; `MetricCategoryTests` updated for new symbols/names.
- `SymbolAvailabilityTests` (app): `NSImage(systemSymbolName:)` non-nil for every identity and live symbol.
- `TokenLintTests` (app): reads sources via `#filePath`; fails on `.font(.system(size:` under `iStats/UI/Panels`.
- Existing `AccessibilityAppearanceTests` (status symbols) and panel render tests stay green.

## Acceptance criteria
- No view hard-codes a category symbol/name; GPU = `cube.transparent`, Network = `network`, Power = `battery.100percent`/`powerplug`.
- Palette tests above pass; `Tokens.swift` gone and pbxproj clean; no font below 10 pt in panels and Kit; no literal thresholds in panels.

## Risks
- Palette re-hue may fail contrast on one surface: iterate hexes in core tests first.
- `cube.transparent` unavailable on macOS 13: `SymbolAvailabilityTests` decides; fallback `display`.
- Renaming `displayName` for Power affects tests and the Settings text; grep "Battery & Power" first.
