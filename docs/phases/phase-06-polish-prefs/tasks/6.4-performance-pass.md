# Task 6.4 — Performance pass

**Phase:** 6 — Polish, Preferences & Performance
**Requirements:** 12.1, 12.2, 12.4

## What to do

- Confirm all sampling runs off the main thread.
- Measure iStats' own CPU usage at the default interval.
- Verify that increasing the refresh interval reduces sampling frequency and footprint.

## Goal (definition of done)

- Sampling is confirmed off the main thread.
- Idle CPU at the default interval is low single-digit percent on the target hardware.
- Interval scaling demonstrably lowers the footprint.
