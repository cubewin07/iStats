# Task 6.1 — Full preferences: categories, menu bar content, units

**Phase:** 6 — Polish, Preferences & Performance
**Requirements:** 11.1, 11.3, 9.4

## What to do

- Add enable/disable toggles for each metric category.
- Make the menu bar content configurable (which metric(s) appear).
- Add unit options: °C/°F, bytes vs bits, IEC vs SI byte units.

## Goal (definition of done)

- Disabling a category stops it from being scheduled and removes it from the UI.
- Menu bar content and units reflect the chosen preferences immediately.
