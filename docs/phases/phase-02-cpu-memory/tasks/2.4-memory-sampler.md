# Task 2.4 — Implement MemorySampler

**Phase:** 2 — CPU & Memory
**Requirements:** 2.1, 2.3

## What to do

Implement `MemorySampler` using `host_statistics64(HOST_VM_INFO64)` plus
`sysctl hw.memsize`:

- Report used / free / wired / compressed / cached and swap used.
- Report total physical memory accurately (use `host_page_size` for page math).

## Goal (definition of done)

- Memory breakdown matches Activity Monitor within expected rounding.
- Total physical memory equals the host's installed RAM.
