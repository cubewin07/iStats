# Task 3.4 — Disk I/O throughput

**Phase:** 3 — Network & Disk
**Requirements:** 7.2

## What to do

- Read disk read/write throughput via IOKit block storage statistics
  (`IOBlockStorageDriver`).
- If the stats are not accessible, mark disk I/O `.unavailable` (do not block capacity).

## Goal (definition of done)

- Disk I/O throughput is reported where accessible.
- When inaccessible, it degrades to `.unavailable` without affecting capacity reporting.
