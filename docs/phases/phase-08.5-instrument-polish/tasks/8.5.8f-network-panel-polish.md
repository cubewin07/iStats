## Purpose

3. **Details Page (Max 2 Sections):**
   - **Section 1 — Network Interfaces:** Ranked interfaces with status dot, BSD name badge, and live `↓ / ↑` rates.
   - **Section 2 — Wi-Fi Radio Telemetry:** SSID, Signal Quality, RSSI, Noise Floor, SNR, and Transmit Rate as hairline `MetricRow`s.
