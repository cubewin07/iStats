# Task 8.5.1 — Pure Chart Math v3 (`ChartTimeline`, `ChartScale`, `Downsampler.alignedBuckets`)

**Phase:** 8.5 (Sub-phase 8.5A) · **Depends on:** 8.5.0 · **Blocks:** 8.5.2, 8.5.3, 8.5.5

## Purpose
Solve animation root causes **A1, A2, A3, A4, A5, A6, A7, A9** in pure, deterministic `iStatsCore` types before touching SwiftUI views.

## What to do
1. **Step 8.5.1.1 — `ChartTimeline` (`Sources/iStatsCore/LiveChartMath.swift`):**
   - Define `ChartPoint(timestamp: TimeInterval, value: Double)` and `DualChartPoint(timestamp: TimeInterval, primary: Double, secondary: Double)`.
   - Implement `ChartTimeline` holding `edge: TimeInterval`, `frozenEdge: TimeInterval?`, and `sampleInterval: TimeInterval`:
     - `targetEdge(now:latestTimestamp:)` returns `min(now - sampleInterval, latestTimestamp)`.
     - `step(now:latestTimestamp:dt:isScrubbing:)` freezes `edge` when `isScrubbing == true`, snaps immediately if `abs(targetEdge - edge) > 3.0 * sampleInterval`, and otherwise advances `edge` monotonically toward `targetEdge` at `1.0 s/s` (with a `250 ms` ease-out catch-up after scrub release).
     - `xPosition(for timestamp: TimeInterval, width: Double, window: TimeInterval) -> Double` maps `timestamp` to `width * (1.0 - (edge - timestamp) / window)`.
     - `valueAtEdge(points: [ChartPoint]) -> Double?` evaluates the interpolated Y value where `timestamp == edge` so the live head bead sits smoothly on the spline at `plotWidth`.
2. **Step 8.5.1.2 — `ChartScale` (`Sources/iStatsCore/LiveChartMath.swift`):**
   - Implement `niceCeiling(for maxVal: Double, floorVal: Double = 0.0, minSpan: Double = 1.0) -> (floor: Double, ceiling: Double, ticks: [Double])` using the `{1, 2, 2.5, 5} × 10^k` nice ladder with 3 clean intervals.
   - Implement `ChartScaleState` with asymmetric dynamics:
     - Immediate upward spring step (`response: 0.35 s`) when `targetCeiling > displayedCeiling`.
     - `3.0 s` hysteresis hold when `targetCeiling < displayedCeiling * 0.70`, followed by a `0.60 s` ease-out contraction.
   - Implement `domainFloor(for category: MetricCategory, visibleMin: Double, fixedFloor: Double?) -> Double` (Thermal: `max(20, floor((visibleMin - 5) / 10) * 10)`; Fan: `minRPM`; Percent: `0`).
3. **Step 8.5.1.3 — Time-Aligned Envelope Buckets (`Sources/iStatsCore/Downsampler.swift`):**
   - Define `BucketPoint: Equatable, Sendable` with `timestamp: TimeInterval`, `min: Double`, `max: Double`, `mean: Double`.
   - Implement `Downsampler.alignedBuckets(_ points: [ScalarPoint], bucketWidth: TimeInterval, windowDuration: TimeInterval) -> [BucketPoint]` grouping by `Int(floor(point.timestamp / bucketWidth))`. Verify that appending a new `ScalarPoint` never mutates any bucket prior to the current epoch bucket.
4. **Step 8.5.1.4 — Unit Tests (`Tests/iStatsCoreTests/LiveChartMathTests.swift`, `DownsamplerTests`):**
   - Test late sample arrival (`+50 ms` jitter): `edge` never moves backward (A1).
   - Test wake-from-sleep gap (`> 3 * interval`): `edge` snaps cleanly without multi-minute catch-up.
   - Test partial buffer (15 samples in 60 s window): `xPosition` spans the rightmost 25% of width without stretching (A5).
   - Test hover freeze and unfreeze: `edge` stays constant on hover start (A7).
   - Test `ChartScaleState` upward spring, 3 s hold hysteresis, and Thermal domain floor (A4, A9).
   - Test `Downsampler.alignedBuckets` stability: adding 1 Hz samples preserves all closed historical buckets identically (A6).
