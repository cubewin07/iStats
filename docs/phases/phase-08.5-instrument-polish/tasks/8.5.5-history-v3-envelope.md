# Task 8.5.5 — `HistoryPage` v3 (Time-Aligned Envelope, Time Axis, Hover Annotations)

**Phase:** 8.5 (Sub-phase 8.5A) · **Depends on:** 8.5.2, 8.5.3, 8.5.4 · **Blocks:** 8.5.6b

## Purpose
Overhaul `HistoryPage` so 5m and 15m ranges render stable time-aligned `min...max` envelopes with a `mean` curve (fixing **A6**), add a clean bottom time axis, unify the top control bar, declutter default annotations, and wire scrubbing into the Glance header and stats strip.

## What to do
1. **Step 8.5.5.1 — Time-Aligned Envelopes in `HistoryPage` (`iStats/UI/Panels/HistoryPage.swift`):**
   - For `.oneMinute`, query `coordinator.timedScalarHistory(for:duration: 60)`.
   - For `.fiveMinutes` (`bucketWidth: 2.5`) and `.fifteenMinutes` (`bucketWidth: 7.5`), query `coordinator.bucketedScalarHistory(for:duration:bucketWidth:)` and pass the `BucketPoint` envelope to `LiveChart`.
2. **Step 8.5.5.2 — Bottom Time Axis & Decluttered Annotations:**
   - Render a `14 pt` bottom time axis beneath the `140 pt` plot showing relative ticks (`-60s / -40s / -20s / now`, `-5m / -3m / -1m / now`, or `-15m / -10m / -5m / now`) in `9.5 pt` tertiary tabular text.
   - Hide the dashed average line and `▲` peak marker by default; reveal the average line when hovering the `AVG` stat cell and reveal the peak bead + callout when hovering the `MAX` stat cell.
3. **Step 8.5.5.3 — Scrub-Aware Stats Strip & Header Routing:**
   - Route `HistoryPage` hover scrubbing to `PanelScaffold`'s `ChartScrubState` so the main Glance numeral at the top of the panel reflects the scrubbed historical sample.
   - While scrubbing, update the 4th stat cell label from `NOW` to `AT -<time>` showing the scrubbed value while keeping `MIN`, `AVG`, and `MAX` anchored to the window statistics.
