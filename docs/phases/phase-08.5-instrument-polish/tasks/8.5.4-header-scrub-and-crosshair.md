# Task 8.5.4 — Stocks-Style Glance Header Scrub Readout & Crosshair v2

**Phase:** 8.5 (Sub-phase 8.5A) · **Depends on:** 8.5.3 · **Blocks:** 8.5.5, 8.5.6b

## Purpose
Remove the floating tooltip pill that occludes the chart curve during scrubbing, routing the scrubbed value and timestamp directly into the Glance header (Stocks style) with a spring-followed crosshair.

## What to do
1. **Step 8.5.4.1 — `ChartScrubState` Model (`iStats/UI/Instrument/LiveChart.swift` / `PanelScaffold.swift`):**
   - Define `ChartScrubState: Equatable, Sendable` containing:
     - `formattedPrimary: String`
     - `primaryUnit: String`
     - `secondaryReadout: (text: String, unit: String, color: Color)?`
     - `relativeTimeText: String` (e.g., `"12s ago"`)
     - `clockTimeText: String` (e.g., `"14:02:31"`)
2. **Step 8.5.4.2 — Crosshair v2 (`LiveChart.swift`):**
   - Delete the floating `RoundedRectangle` callout pill from `LiveChart.crosshairOverlay`.
   - Render a `1 pt` vertical hairline with `6 pt` top/bottom alpha fades and a `6 pt` snapped bead (`1.5 pt` surface cutout stroke) on each active series at the interpolated Y value under the cursor.
   - Smooth horizontal crosshair X movement with a fast spring (`response: 0.12, dampingFraction: 0.9`).
3. **Step 8.5.4.3 — Glance Header Integration (`PanelScaffold.swift`):**
   - When `scrubState != nil`, display the scrubbed value in the Glance numeral (`LiveNumber` / dual ticker) and display `"<relativeTimeText> · <clockTimeText>"` in the Glance headline with a subtle secondary highlight.
   - Move the static `glance.insight` line (`"↗ Peak 92% · 3m ago"`) to a dedicated `11 pt` caption row directly below the hero chart so it is never truncated in the top-right corner.

## Files
`iStats/UI/Instrument/LiveChart.swift`, `iStats/UI/Panels/PanelScaffold.swift`, `iStatsTests/PanelScaffoldTests.swift`.

## Definition of done
- Hovering any hero or History chart updates the Glance numeral and timestamp headline smoothly with zero floating tooltip occlusion, and releasing hover restores live telemetry.
- All tests pass and changes are committed in an atomic commit.
