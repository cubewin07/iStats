# Task 8.5.2 — Timestamped Telemetry Series (`ChartPoint`, `ChartSeries`, `BucketPoint`)

**Phase:** 8.5 (Sub-phase 8.5A) · **Depends on:** 8.5.1 · **Blocks:** 8.5.3, 8.5.5

## Purpose
Expose wall-clock timestamps and time-aligned `BucketPoint` envelopes from `MetricsStore` and `MetricsCoordinator` so `LiveChart` and `HistoryPage` can render in true time domain while keeping backward-compatible scalar helpers for `InsightEngine` and tests.

## What to do
1. **Step 8.5.2.1 — `MetricsStore` Timestamped Queries (`Sources/iStatsCore/MetricsStore.swift`):**
   - Add `timedScalarHistory(for key: ScalarSeriesKey, duration: TimeInterval) -> [ChartPoint]` returning raw timestamped points within `duration` for 1m windows.
   - Add `bucketedScalarHistory(for key: ScalarSeriesKey, duration: TimeInterval, bucketWidth: TimeInterval) -> [BucketPoint]` using `Downsampler.alignedBuckets` for 5m (`2.5 s`) and 15m (`7.5 s`) windows.
2. **Step 8.5.2.2 — `MetricsCoordinator` Forwarding (`iStats/App/MetricsCoordinator.swift`):**
   - Expose `timedScalarHistory(for:duration:)` and `bucketedScalarHistory(for:duration:bucketWidth:)` on `MetricsCoordinator`.
   - Ensure dual-channel series (`.cpuUser` + `.cpuSystem`, `.networkInBytesPerSec` + `.networkOutBytesPerSec`, `.diskReadBytesPerSec` + `.diskWriteBytesPerSec`) align by sample timestamp.
3. **Step 8.5.2.3 — Unit Tests (`Tests/iStatsCoreTests/MetricsStoreTests.swift`):**
   - Verify `timedScalarHistory` preserves exact `ScalarPoint` timestamps and filters by `duration`.
   - Verify `bucketedScalarHistory` returns stable `BucketPoint` envelopes across sequential appends.
