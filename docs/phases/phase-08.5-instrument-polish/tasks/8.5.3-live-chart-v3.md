# Task 8.5.3 — `LiveChart` v3 (Time-Domain Renderer, Independent Mirrored Scales, Dark-Mode Bloom)

**Phase:** 8.5 (Sub-phase 8.5A) · **Depends on:** 8.5.1, 8.5.2 · **Blocks:** 8.5.4, 8.5.5, 8.5.8*

## Purpose
Rebuild `LiveChart` around `ChartTimeline` and `ChartScale` so every trace glides in true time domain with zero head wobble, smooth hysteresis autoscaling, independent mirrored scales, a left-gutter axis, a calm head bead, and a subtle dark-mode underlay bloom.

## What to do
1. **Step 8.5.3.1 — `LiveChartMode` Time-Domain Upgrade (`iStats/UI/Instrument/LiveChart.swift`):**
   - Support timestamped points (`[ChartPoint]`) and optional envelope buckets (`[BucketPoint]`) while preserving convenience initializers for `[Double]` (synthesizing 1 Hz timestamps ending at `lastSampleTimestamp` so existing call sites and previews compile cleanly during migration).
   - Add `domainFloor: Double?` and threshold bands (`[ChartBand]`) with stroke gradient shading.
2. **Step 8.5.3.2 — Time-Domain `ChartRenderer`:**
   - Replace the old `truncatingRemainder` + last-point vertical interpolation code with `ChartTimeline` and `ChartScaleState`.
   - Compute Fritsch–Carlson monotone cubic segments in timestamp space; project X via `ChartTimeline.xPosition` and clip cleanly at `plotWidth`.
   - Render the `6 pt` head bead at `plotWidth` with a `2 pt` surface-colored cutout halo. Remove the looping 60 fps radar pulse ring (fixes **A8**).
   - Throttle `TimelineView` frame interval to `1/60 s` when key/transient and `1/30 s` when pinned and non-key.
3. **Step 8.5.3.3 — Independent Mirrored Scales (`.mirrored`):**
   - Maintain separate `topScale` and `bottomScale` for `.mirrored` mode (Network `↓/↑` and Disk `R/W`).
   - Draw top and bottom ceiling labels (`↓ 12 MB/s`, `↑ 800 KB/s`) in the left gutter (`9.5 pt` tertiary tabular) so both channels remain clearly legible regardless of asymmetry.
4. **Step 8.5.3.4 — Visual Polish (Stroke Bloom, Area Fill, Left Axis Gutter, Threshold Shading):**
   - Primary stroke: `1.75 pt` round-joined. In Dark Mode (`colorScheme == .dark` and `colorSchemeContrast == .standard`), draw a `5.0 pt` underlay stroke at `16%` opacity with `blur(radius: 3.0)`.
   - Area fill: linear gradient from `tint.opacity(0.20)` at the curve top to `.clear` at `85%` of plot height, masked with a `20 pt` leading horizontal fade-in.
   - Grid & axis labels: 3 solid `0.5 pt` hairlines (`Color.primary.opacity(0.06)`) with labels placed in the **left** gutter `2 pt` above each line, never overlapping the right live head.
   - In `.banded` / threshold mode, tint the stroke with a vertical linear gradient so curve segments above warning/critical thresholds turn amber/red.
