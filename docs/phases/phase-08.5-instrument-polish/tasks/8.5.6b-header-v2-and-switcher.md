# Task 8.5.6b — Header v2, Text `PageSwitcher` & Inline Status Chip (`PanelScaffold`, `PageSwitcher`, `StatusRibbon`)

**Phase:** 8.5 (Sub-phase 8.5B / Stage 3) · **Depends on:** 8.5.4, 8.5.5, 8.5.6a · **Blocks:** 8.5.7, 8.5.8*

## Purpose
Upgrade the panel header chrome with an `18 pt` tinted category badge, text-based `PageSwitcher` (`Now · Details · History`) with a sliding glass puck, and an inline status chip next to the Glance numeral, reserving `StatusRibbon` for actionable states.

## What to do
1. **Tinted Category Badge Header (`iStats/UI/Panels/PanelScaffold.swift`):**
   - Render the category symbol inside an `18×18 pt` circle filled with `CategoryPalette.tint(for: category).opacity(0.16)` next to a `13 pt` `.semibold` sentence-case category title.
2. **Text `PageSwitcher` (`iStats/UI/Panels/PageSwitcher.swift`):**
   - Update `PageSwitcher` to display text labels (`Now`, `Details`, `History`) in `11 pt` (`semibold` when selected, `regular` secondary when unselected) with the sliding glass puck (`matchedGeometryEffect`).
3. **Inline Status Chip (`iStats/UI/Panels/PanelScaffold.swift`, `iStats/UI/Panels/StatusRibbon.swift`):**
   - Show an inline status chip (`● Elevated` / `▲ Warning` / `◆ Critical`) on the trailing side of the Glance numeral row when `status >= .elevated`.
   - Reserve the full-width `StatusRibbon` strictly for actionable states (`Sampling paused · Resume` or explicit action buttons).
