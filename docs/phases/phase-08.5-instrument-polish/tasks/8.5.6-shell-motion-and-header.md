# Task 8.5.6 — Synchronized Shell Motion & Header v2 (`MetricPanel`, `PanelController`, `PanelScaffold`, `PageSwitcher`)

**Phase:** 8.5 (Sub-phase 8.5B) · **Depends on:** 8.5.4, 8.5.5 · **Blocks:** 8.5.7, 8.5.8*

## Purpose
Fix animation root causes **A10** (desynchronized window resize / chart morph clipping) and **A11** (hard cut on category switch), and upgrade the panel header with a tinted category badge, text `PageSwitcher` (`Now · Details · History`), and inline status pill.

## What to do
1. **Step 8.5.6.1 — Persistent Hosting View in `MetricPanel` (`iStats/App/MetricPanel.swift`):**
   - Keep a single `PanelBackgroundView` and `NSHostingView<AnyView>` instance on `MetricPanel`.
   - Update `setSwiftUIContent` to mutate `hostingView.rootView = AnyView(view)` in place if the hosting view already exists, preserving the glass backdrop layer across category switches.
   - Add content-layer open/close transform animation (open: `alpha 0 → 1`, `scale 0.96 → 1.0` anchored at top-center, `y -6 → 0` over `0.28 s`; close: `0.12 s` ease-in).
2. **Step 8.5.6.2 — Synchronous `PreferenceKey` Height Morph (`PanelScaffold.swift`, `PanelController.swift`):**
   - Remove the cross-view `matchedGeometryEffect(id: "panelChart-...")` between `PanelScaffold.chartZone` and `HistoryPage`. Instead, collapse `chartZone` smoothly when switching to `.history` while `HistoryPage` fades/slides in (`8 pt` directional slide + opacity).
   - Measure `PanelScaffold`'s intrinsic height via a `PanelContentHeightKey: PreferenceKey` with top-aligned root content (`frame(maxHeight: .infinity, alignment: .top)`).
   - In `PanelController.updateFittingHeight`, animate the top-anchored `NSPanel` frame using `duration = 0.32` and `CAMediaTimingFunction(controlPoints: 0.2, 0.9, 0.25, 1.0)` matching `Motion.snappy` in the same runloop turn.
3. **Step 8.5.6.3 — Header v2 & Text `PageSwitcher` (`PanelScaffold.swift`, `PageSwitcher.swift`, `StatusRibbon.swift`):**
   - Render the category symbol inside an `18×18 pt` circle filled with `CategoryPalette.tint(for: category).opacity(0.16)` next to a `13 pt` `.semibold` sentence-case category title.
   - Update `PageSwitcher` to display text labels (`Now`, `Details`, `History`) in `11 pt` (`semibold` when selected, `regular` secondary when unselected) with the sliding glass puck (`matchedGeometryEffect`).
   - Show an inline status chip (`● Elevated` / `▲ Warning` / `◆ Critical`) on the trailing side of the Glance numeral row when `status >= .elevated`, reserving the full-width `StatusRibbon` strictly for actionable states (`Sampling paused · Resume` or explicit action buttons).
