# Task 8.5.7 — Instrument Kit v2 (`Section`, Hairline `MetricRow`, `SegmentedControl`, `FilterChip`, `LiveNumber`, `TopConsumersModule`, Secondary Hues)

**Phase:** 8.5 (Sub-phase 8.5B) · **Depends on:** 8.5.6 · **Blocks:** 8.5.8a–8.5.8h

## Purpose
Resolve **A12** (slot-machine decimal numerals), **A13** (teleporting process rows), and the visual monotony identified in §2 by upgrading the shared Kit primitives and adding explicit secondary series hues to `PaletteContrast`.

## What to do
1. **Step 8.5.7.1 — Secondary Series Hues (`Sources/iStatsCore/PaletteContrast.swift`, `iStats/UI/Design/CategoryPalette.swift`):**
   - Add WCAG-checked light/dark hex pairs for `cpuEfficiency`, `memoryWired`, `memoryCompressed`, and `memoryCached` alongside `cpuSystem`, `networkUpload`, and `diskWrite`.
   - Expose them on `CategoryPalette.Series` and verify contrast in `PaletteContrastTests`.
2. **Step 8.5.7.2 — Integrated `Section` Header (`iStats/UI/Instrument/Kit/Module.swift`):**
   - Place the section title (`11.5 pt` `.semibold`, sentence-case, `.secondary`) and optional trailing accessory **inside** the top of the `Module` card (with `8 pt` spacing below the header row), eliminating the external uppercase eyebrow above every grey box. Keep `Module` as a typealias or compatible initializer so existing panels compile throughout migration.
3. **Step 8.5.7.3 — Table-Style `MetricRow` (`iStats/UI/Instrument/Kit/MetricRow.swift`):**
   - Increase row height to `26 pt`, add an optional bottom hairline (`0.5 pt` `Color.primary.opacity(0.06)`), remove hover scale/fill from non-interactive rows, and show a subtle `doc.on.doc` copy affordance on hover when `isCopyable == true`.
4. **Step 8.5.7.4 — Unified `SegmentedControl` & `FilterChip` (`iStats/UI/Instrument/Kit/`):**
   - Create reusable glass-puck `SegmentedControl` and capsule `FilterChip` components (`10.5–11 pt` text) and adopt them in `HistoryPage` (replacing the 3 mismatched chip/segment styles).
5. **Step 8.5.7.5 — `LiveNumber` Cadence Throttle (`iStats/UI/Instrument/LiveNumber.swift`):**
   - Keep `.numericText` rolling for integer formats, and for fractional strings (containing `.`) apply a `2.0 s` cadence gate unless `abs(newValue - displayedValue) >= 1.0`, eliminating 1 Hz decimal slot-machine jitter (**A12**).
6. **Step 8.5.7.6 — Animated `TopConsumersModule` (`iStats/UI/Instrument/Kit/TopConsumersModule.swift`):**
   - Animate row rank transitions with `.animation(Motion.smooth, value: processes.map(\.pid))` and format values with tabular `Instrument.Typography.value` digits instead of variable-width SF Mono (**A13**).
