# Task 8.5.6a — Shell Lifecycle & Sizing (`MetricPanel`, `PanelController`, `PanelScaffold`, `MenuBarController`)

**Phase:** 8.5 (Stage 1: Shell Correctness) · **Depends on:** 8.5.0 · **Blocks:** 8.5.6b (lands first before 8.5.1)

## Purpose
Resolve shell correctness bugs **B1–B6** and animation root causes **A10** (desynchronized window resize / chart morph clipping) and **A11** (hard cut / host rebuild on category switch) with zero chart-engine dependencies, so every open/close, category switch, hover, pin, and dynamic height transition works reliably before `8.5.1–8.5.5`.

## What to do
1. **Persistent Hosting View in `MetricPanel` (`iStats/App/MetricPanel.swift`) [A11]:**
   - Create a single `PanelBackgroundView` and a single `NSHostingView<AnyView>` in `MetricPanel.init` with `sizingOptions = []` so Auto Layout never fights animated panel frames.
   - Update `setSwiftUIContent` to mutate `hostingView.rootView = AnyView(view)` in place, preserving the glass backdrop layer across category switches.
   - On close, set `hostingView.rootView = AnyView(EmptyView())` so chart timelines stop and `onDisappear` fires (keeping `startProcessDemand` / `stopProcessDemand` balanced).
   - Add content-layer open/close transform animation without breaking **B1** or **B5**.
2. **One Synchronous Height Channel (`PanelScaffold.swift`, `MetricPanel.swift`, `PanelController.swift`) [B2, A10]:**
   - Add `PanelContentHeightKey: PreferenceKey` on `PanelScaffold`'s top-aligned root (`frame(maxHeight: .infinity, alignment: .top)`).
   - Forward the reported height from `MetricPanel` to `PanelController.setContentHeight(_:for:animated:)`, which performs the top-anchored `NSPanel.setFrame` (`duration = 0.32`, `CAMediaTimingFunction(controlPoints: 0.2, 0.9, 0.25, 1.0)` matching `Motion.snappy`).
   - Delete both `DispatchQueue.main.async { updateFittingHeight }` calls and `fittingSize` reads so all dynamic height changes (top processes loading, status ribbon, interface toggles, pause toggle, tab switch) resize in lockstep.
3. **First-Open Size Measurement (`PanelController.swift`) [B5]:**
   - Measure initial size with `NSHostingController.sizeThatFits(in:)` (macOS 13 deployment target) before ordering the panel front so the panel opens directly at its final height with no jump.
4. **One Scroll Container (`PanelScaffold.swift`) [B3, B4]:**
   - Replace `ViewThatFits` with a single `ScrollView` around the page body for all three tabs (`Now`, `Details`, `History`), sized to `min(measuredBodyHeight, maxHeight - chromeHeight)` with scrolling disabled when the body fits. Build the page body once.
5. **Close/Show Race & Status-Item Hit-Test Exclusion (`PanelController.swift`, `MenuBarController.swift`) [B1]:**
   - Add a transition generation counter in `PanelController`: calling `show()` during a fade-out bumps the generation counter, animates alpha back to `1`, and causes stale close teardown closures to return early.
   - Inject a status-item hit-test closure from `MenuBarController` so dismissal mouse monitors ignore clicks on any of the app's status-item buttons, leaving `toggle` in sole control.
6. **Visible Pinned-Panel Guard (`PanelController.swift`) [B6]:**
   - In `show` and `handleStatusItemHover`, when the target category already has a visible pinned panel, close any open transient panel and bring the pinned panel to the front instead of creating a duplicate transient panel.
7. **Tab Chart Morph Removal & Pin/Unpin Motion (`PanelScaffold.swift`, `PanelController.swift`):**
   - Remove cross-view `matchedGeometryEffect(id: "panelChart-...")` between the hero chart and `HistoryPage`; let the hero chart collapse cleanly while `HistoryPage` fades/slides `8 pt`.
   - Animate pinning to the saved frame origin and fade out cleanly on unpin.
8. **Tests (`Tests/iStatsTests/`):**
   - Extend `PanelPlacementTests`, add `PanelControllerLifecycleTests` (show-during-close keeps panel visible; hover onto pinned category creates no transient; height preference resizes top-anchored and clamps to screen — registered in `iStats.xcodeproj/project.pbxproj`), and update `PanelScaffoldTests`.

## Definition of done
- Switching categories while a panel is open never drops or blanks the panel (**B1**).
- Dynamic height changes and `⌘1–3` tab switches resize the top-anchored panel smoothly with no jump on first open and no clipping (**B2–B5, A10, A11**).
- Hovering or showing a category with a visible pinned panel fronts the pinned panel without spawning a duplicate transient (**B6**).
- `swift test --scratch-path /tmp/istats-build` and `xcodebuild test -scheme iStats -destination 'platform=macOS'` pass green, and changes are committed in an atomic commit.
