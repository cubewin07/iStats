2. **Now page:**

   - Processes slot (8.9, by footprint).
3. **Detail page (Pressure):** `LiveChart .banded` showing used % over pressure-level bands from the pressure history; swap used/total meter; active/inactive rows when present.
4. **Previews:** normal, warn, critical, no swap, `appMemory == nil`, unavailable.
