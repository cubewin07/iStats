# Task 8.3 — Glass Panel Host (`MetricPanel`)

**Phase:** 8 (Sub-phase 8A) · **Depends on:** 8.0 · **Blocks:** 8.6 · **Risk:** High

## Purpose
Replace `NSPopover` (arrow, fixed chrome, no pin) with a custom borderless panel. This is the single biggest "native premium" lever (features F1–F3 in plan.md).

## What to do
1. **Step 8.3.1 — `PanelPlacement` (iStatsCore, pure):** `frame(for buttonRect: CGRect, panelSize: CGSize, visibleFrame: CGRect, gap: 6, margin: 8) -> CGRect`. It centres under the item, clamps to the screen's left/right edges, and flips above the item if there isn't room below (rare, e.g. a bottom-positioned bar). Unit-test centre, left clamp, right clamp, small screen, and multi-display origin offsets.
2. **Step 8.3.2 — `iStats/App/MetricPanel.swift`:** an `NSPanel` subclass with `styleMask [.borderless, .nonactivatingPanel]`, `isFloatingPanel = true`, `level = .statusBar`, `backgroundColor = .clear`, `isOpaque = false`, `hasShadow = true`, `collectionBehavior [.canJoinAllSpaces, .fullScreenAuxiliary, .transient]`, and `canBecomeKey = true`. Its content is an `NSHostingView` wrapped in the `Surface.panel` background (glass on 26+, `NSVisualEffectView` otherwise; corner radius 16, continuous curve).
3. **Step 8.3.3 — `PanelController` (@MainActor):** `show(config:relativeTo:)`, `close()`, `toggle`. Sizing reads the hosting view's `fittingSize` and animates the frame with the top edge anchored. Open/close use `Motion.panelIn/Out` via the content's SwiftUI transition plus `alphaValue`. Hosting views are cached per config ID (pre-warmed) to meet the 100 ms first-frame budget.
4. **Step 8.3.4 — Dismissal:** a global + local `NSEvent` monitor for `.leftMouseDown/.rightMouseDown` outside the panel and the status button, `NSApplication.didResignActiveNotification`, active-space changes, and `Esc` (in `keyDown`). Remove the monitors on close (no leaks; test by toggling 100× in a debug harness).
5. **Step 8.3.5 — Menu tracking (F2):** while a panel is open, track the pointer over the other iStats status buttons (tracking areas on each `NSStatusBarButton`). On enter, swap content + frame with an 80 ms crossfade.
6. **Step 8.3.6 — Pin/detach (F3):** `isPinned` turns off outside-click dismissal, sets `level = .floating`, enables `isMovableByWindowBackground`, and remembers the last pinned origin per category in `PreferencesStore` (a UI preference, allowed by ADR 0006). Un-pin snaps back under the item.
7. **Step 8.3.7 — `MenuBarController` integration:** route clicks to `PanelController`. Keep the existing `NSPopover` path only behind the DEBUG launch argument `-legacyPopovers YES`.
8. **Step 8.3.8 — Edge-case matrix (manual, recorded in the handoff summary):** full-screen app, multiple displays with different menu bar heights, Stage Manager, notched display (item under the notch), Mission Control while open, sleep/wake while open, a right-edge item near the Control Center icon.

## Definition of done
- `PanelPlacementTests` pass. Clicking an item opens the panel without an arrow; outside click / `Esc` / re-click closes it; menu tracking and pin work. Edge-case matrix recorded. No `NSEvent` monitor leaks.
