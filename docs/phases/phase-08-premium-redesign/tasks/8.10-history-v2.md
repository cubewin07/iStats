# Task 8.10 — History v2

**Phase:** 8 (Sub-phase 8D) · **Depends on:** 8.4, 8.6 · **Blueprint:** [`design.md §6.9`](../design.md)

## Purpose
Replace `HistoryTab` with an instrument-grade history page: scrubbable, annotated, and calm (feature F11).

## What to do
1. **Range control:** glass segmented `1m · 5m · 15m` (existing `MetricsStore.scalarHistory` windows + `Downsampler`). The selection persists per category as a UI preference.
2. **Chart:** `LiveChart` at 140 pt with `niceTicks` y-axis (`Type.micro`), avg dashed line, ▲ peak marker with value, "now" head, crosshair lens with relative time ("2m 14s ago").
3. **Stats strip:** Min · Avg · Max · Now, each a `LiveNumber`; tapping one jumps the crosshair to it (peak/min index from `LiveChartMath`).
4. **Channel isolation:** dual-series categories (CPU user/system, Network ↓/↑, Disk R/W) get legend chips; clicking one dims the other to 15 %.
5. **Morph:** when entering History, the glance chart grows into this chart (`matchedGeometryEffect` on the chart frame) under `MotionPolicy.full`.
6. **Empty state:** if the window has fewer than 10 samples, show "Collecting — history fills while iStats runs" (in memory only, ADR 0006).

## Files
`iStats/UI/Panels/HistoryPage.swift`; delete usage of `iStats/UI/Popovers/HistoryTab.swift` (the file itself is deleted in 8.12).

## Definition of done
All 8 panels use `HistoryPage`. Downsampled spikes remain visible (the existing `Downsampler` tests still pass). Builds, tests green.
