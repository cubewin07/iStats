# Task 8.11 — Accessibility & Appearance Matrix

**Phase:** 8 (Sub-phase 8E) · **Depends on:** 8.8a–h, 8.9, 8.10

## Purpose
Premium means it holds up in every configuration, not just dark mode on a demo machine.

## What to do
1. **Matrix:** for each of the 8 panels × pages, verify:
   | Axis | Values |
   |------|--------|
   | Appearance | Light, Dark |
   | Accent / wallpaper | Graphite accent; bright and dark wallpaper behind glass |
   | Reduce Transparency | on → opaque `windowBackgroundColor` surface, modules stay distinguishable |
   | Increase Contrast | on → high-contrast palette variants, 1 pt module outline allowed *only* in this mode |
   | Reduce Motion | on → no glide/pulse/spin/particles; crossfades only |
   | Differentiate Without Colour | status dot gains its SF Symbol shape; series get dash patterns |
   | VoiceOver | logical order: eyebrow → glance → ribbon → body; charts have summaries + audio graph |
   | Text size | macOS 14+ accessibility text size preference does not truncate the display numeral (use `minimumScaleFactor(0.7)` there only) |
   | OS | macOS 13 (fallback paths), 14/15, 26 (glass) |
2. **Previews:** add `#Preview` variants for Light/Dark/Reduce Transparency/High Contrast per panel. The **user** performs visual sign-off from Xcode previews or the running app. Agents do not capture the user's screen.
3. **Menu bar widgets:** confirm the new palette hues read well at 18 pt in both menu bar appearances. Adjust `nsColor` dark/light values only (no glyph changes).
4. **Record:** the matrix results table in `docs/handoffs/08-8.11-summary.md`; failures become fix commits in this task.

## Definition of done
Matrix is complete with no open P1 issues. The user has signed off on the visual review.
