# Task 8.6 — `PanelScaffold`

**Phase:** 8 (Sub-phase 8B) · **Depends on:** 8.3, 8.4, 8.5, 8.7 · **Blocks:** 8.8a–h

## Purpose
The shared shell every panel uses: zones ①–⑤ in [`design.md §1`](../design.md), the states in §7, and the keyboard map in §8. It replaces `PopoverScaffold`, `PopoverHeader`, `TabBar`, and `PopoverFooter`.

## What to do
1. **Step 8.6.1 — API:**
   ```swift
   PanelScaffold(
       category: MetricCategory,
       glance: PanelGlance,           // value, format, unit, headline, insight, chart mode
       status: StatusLevel, ribbon: String?,
       pages: [PopoverTab], selection: Binding<PopoverTab>,
       availability: Availability?, isLoading: Bool,
       @ViewBuilder body: (PopoverTab) -> Body)
   ```
2. **Step 8.6.2 — Eyebrow row:** glyph + `Type.eyebrow` name; `PageSwitcher` (icon buttons, sliding puck via `matchedGeometryEffect`, `⌘1–3`, tooltips with titles from `PopoverTab.title(for:)`); `⋯` `Menu` (context app from the old `PopoverFooter.contextAction`, Pause/Resume, Preferences…); pin button (calls `PanelController`).
3. **Step 8.6.3 — Glance:** `LiveNumber` display + unit, headline, trailing insight; full-bleed `LiveChart` (negative horizontal padding to the panel edge). Scrubbing the chart replaces the insight with the scrub readout.
4. **Step 8.6.4 — Status ribbon:** shown only when `!status.isQuiet && ribbon != nil`; height spring; optional action button (e.g. Resume).
5. **Step 8.6.5 — States:** loading ghost (no skeleton shimmer), unavailable, paused, low-power paused, detached. All per design.md §7.
6. **Step 8.6.6 — Pages:** directional slide + fade transition; the body is wrapped in a `ScrollView` only on `.detail/.history` when the content exceeds the 560 pt cap (with edge fades). Persist the last page via the existing `preferences.setLastSelectedTab`.
7. **Step 8.6.7 — Keyboard:** `←/→`, `Esc`, `⌘,`, `⌘P`, `Space` via `.onKeyPress` (macOS 14+) with an `NSPanel.keyDown` fallback forwarding to a `PanelCommand` publisher on 13.
8. **Step 8.6.8 — `PanelFactory`:** same signature shape as `PopoverFactory`, routing to the new panels (stub panels that use only the glance until 8.8 lands).

## Files
`iStats/UI/Panels/PanelScaffold.swift`, `iStats/UI/Panels/PageSwitcher.swift`, `iStats/UI/Panels/StatusRibbon.swift`, `iStats/UI/Panels/PanelFactory.swift`, `iStats/App/PanelController.swift` (edit).

## Definition of done
- All 8 categories open a stub panel with a working glance + chart, page switching, ribbon, and states. Keyboard map verified on macOS 13 and 14+ paths. App builds and tests pass.
