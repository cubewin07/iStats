# Task 8.1 — Design Language v2: Tokens, Palette, Typography, Surfaces

**Phase:** 8 (Sub-phase 8A) · **Depends on:** 8.0 · **Blocks:** 8.2, 8.4, 8.5, 8.7

## Purpose
Replace the flat Phase 7 tokens (all-11 pt type, stock hues, bordered cards) with the "Instrument" language in [`design.md §2–4`](../design.md).

## What to do
1. **Step 8.1.1 — Asset palette:** add `iStats/Assets.xcassets/Palette/` colour sets: `cpu`, `cpuDeep`, … `power`, `powerDeep`, the series colours (`seriesCPUSystem`, `seriesNetUp`, `seriesDiskWrite`), and the status colours (`statusElevated`, `statusWarning`, `statusCritical`). Each set gets Any, Dark, and High-Contrast variants using the hex values in design.md §3.2.
2. **Step 8.1.2 — `iStats/UI/Instrument/InstrumentTokens.swift`:** namespaces `Instrument.Space` (2/4/6/8/12/16/20/24), `Instrument.Radius` (panel 16, module 12, control 8, capsule), `Instrument.Type` (table in §4, numerals `.monospacedDigit()`), `Instrument.Size` (panelWidth 352, maxHeight 560, chartHeight 72, historyChartHeight 140), `Instrument.Surface` (module/inset/hover colours).
3. **Step 8.1.3 — Update `CategoryPalette`:** keep the public API (`color(for:)`, `nsColor(for:)`, `Series`, `statusColor`) so the menu bar renderer keeps compiling. Back it with the asset colours. Add `deep(for:)`, `gradient(for:)`, and `ThermalRamp.color(celsius:)`.
4. **Step 8.1.4 — `StatusLevel.color`:** route through the palette status colours. Add `StatusLevel.isQuiet` (`true` for `.fine`).
5. **Step 8.1.5 — Contrast test:** add a `PaletteContrast` pure helper (relative luminance, contrast ratio) in `iStatsCore` and `PaletteContrastTests` asserting ≥ 4.5:1 for the text-on-surface and value-on-tint pairs listed in design.md §3.1, using the hex table as test fixtures.
6. **Step 8.1.6 — Previews:** add a `#Preview("Instrument palette")` swatch sheet and a `#Preview("Type ramp")` sheet, light and dark.
