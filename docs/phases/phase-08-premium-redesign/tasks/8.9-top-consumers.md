# Task 8.9 — Top Consumers (`ProcessSampler`)

**Phase:** 8 (Sub-phase 8D) · **Depends on:** 8.8a, 8.8b · **Supersedes:** unbuilt Task 7.8
**Skills:** `macos-system-apis`, `swift-concurrency-patterns`

## Purpose
"What's using it?" is the question every premium monitor answers. Show the top 5 apps with real icons in the CPU and Memory panels (feature F9).

## What to do
1. **Step 8.9.1 — `iStats/Sampling/ProcessSampler.swift`:** runs on the `SampleScheduler` background queue **only while a CPU or Memory panel is visible** (demand-driven; zero cost when closed). It uses `proc_listallpids` → `proc_pid_rusage(RUSAGE_INFO_V4)` for `ri_user_time + ri_system_time` (CPU) and `ri_phys_footprint` (memory). Processes it can't read (EPERM) are skipped silently. No privilege escalation (ADR 0004/0005).
2. **Step 8.9.2 — Pure math (`Sources/iStatsCore/ProcessRanking.swift`):** CPU % from Δ(cpu time)/Δ(wall) × 100 via `RateMath` semantics (pid reuse or counter reset → 0, never negative); `topN(by:)`; group helpers/XPC children under the parent app bundle when `responsibility` info is available, else show the raw process. Tests: reset, pid reuse, new pid, ties, N > count.
3. **Step 8.9.3 — Presentation model:** `ProcessRow { pid, name, bundleID?, cpuPercent?, footprint? }`. The icon is resolved on the main actor via `NSRunningApplication(processIdentifier:)?.icon` and cached by bundle ID; generic `gearshape` symbol fallback.
4. **Step 8.9.4 — UI:** a `SectionEyebrow` "Processes" + 5 `MetricRow`s (16 pt icon, name, micro-sparkline of the last 30 samples from an in-memory ring, value). Hover → "Show in Activity Monitor" affordance. Label "Your apps" if any pids were skipped.
5. **Step 8.9.5 — Model + coordinator:** add `ProcessSample` to `Models.swift`, publish `latestProcesses` (in memory only, never persisted).

## Files
`iStats/Sampling/ProcessSampler.swift`, `Sources/iStatsCore/ProcessRanking.swift`, `Sources/iStatsCore/Models.swift`, `iStats/App/MetricsCoordinator.swift`, `Tests/iStatsCoreTests/ProcessRankingTests.swift`, CPU/Memory panels.

## Definition of done
`ProcessRankingTests` pass. The top-5 CPU list matches Activity Monitor's "% CPU" ordering within ±2 pp for steady loads (recorded in the summary). The sampler is idle when no panel is open. No main-thread `libproc` calls.
