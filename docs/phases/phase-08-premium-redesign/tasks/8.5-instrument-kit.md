# Task 8.5 — Instrument Kit

**Phase:** 8 (Sub-phase 8B) · **Depends on:** 8.1, 8.2 · **Blocks:** 8.6, 8.8*

## Purpose
A small set of premium building blocks that replace bordered cards, legend rows and dividers. Panels must compose these and must not hand-roll bars.

## Components (`iStats/UI/Instrument/Kit/`)
| Component | Spec |
|-----------|------|
| `Module` | Borderless `Surface.module`, radius 12, padding 12, optional `eyebrow` title above (not inside). Hover tint. Never nested. |
| `SectionEyebrow` | `Type.eyebrow` label + optional trailing accessory (e.g. "Show all"). Replaces `Divider` + `sectionTitle`. |
| `MetricRow` | label (`Type.body`, secondary) · optional micro-sparkline (40×12) · value (`Type.value` via `LiveNumber`) · optional status dot only when ≥ elevated. Height 24. Hover tint. |
| `Meter` | horizontal capsule (height 6/10/14), gradient fill `tint → tintDeep`, `easedProgress`, optional threshold tick. |
| `SplitCapsule` | multi-segment capsule (memory composition, CPU user/system/idle, storage) with 1 pt gaps, hover lift + tooltip. Segment widths come from a pure `SegmentLayout.widths(values:total:minVisible:gap:)` in core (tested: sum ≤ width, tiny segments get a minimum visible width, zero total). |
| `ArcGauge` | configurable sweep (default 200°), zone stops, needle, centre label. Geometry from a pure `GaugeMath.angle(value:range:sweep:)` (tested). |
| `RingStack` | 1–3 concentric rings with round caps, track = `Surface.inset`. |
| `ClusterStrip` | row of vertical capsule bars (core map) with an index label (`Type.micro`) and hover callback. |
| `Copyable` modifier | click → copy to pasteboard, the value morphs to "Copied ✓" for 1.2 s (`Motion.snappy`), VoiceOver announcement. Replaces `CopyableValue`. |
| `InsetEmptyState` | SF Symbol 22 pt in a 44 pt `Surface.inset` circle, title, one-line reason, optional action. |

## What to do
1. Build each component with `#Preview`s (light/dark, min/max/empty values).
2. Add pure helpers + tests: `SegmentLayout`, `GaugeMath` (`Sources/iStatsCore/InstrumentGeometry.swift`).
3. All animation goes through `MotionPolicy`. No component reads system accessibility flags itself.

## Definition of done
- `swift test --scratch-path /tmp/istats-build --filter InstrumentGeometryTests` passes. Every component has VoiceOver label/value. No strokes on modules, no `Divider()` in kit code.
