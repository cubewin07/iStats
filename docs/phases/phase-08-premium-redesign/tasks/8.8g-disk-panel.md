## What to do

2. **Now page:**

3. **Detail page (Volumes):** each volume = name, mount point (`Type.mono`), mini storage bar, free/total; hovering a non-boot volume reveals a "Show in Finder" action (`NSWorkspace.activateFileViewerSelecting`, main thread UI call only).
4. **Previews:** single volume, several volumes incl. external, low free space, no I/O data, unavailable.
