# Task 8.4 — `LiveChart`

**Phase:** 8 (Sub-phase 8B) · **Depends on:** 8.2 · **Blocks:** 8.6, 8.8*, 8.10

## Purpose
Make the live trace the hero (Principle 2, feature F4). Replaces the boxed 52 pt `TrendChart` with a full-bleed, gliding, interactive chart.

## What to do
1. **Step 8.4.1 — Pure math (`Sources/iStatsCore/LiveChartMath.swift`):**
   - `smoothPath(points:tension:)`: monotone cubic interpolation (Fritsch–Carlson) so curves never overshoot below 0 or above max. Test that no control point exceeds the bounds of its neighbours.
   - `glideOffset(elapsed:interval:)` → 0…1 fraction for scrolling between samples. Test clamping.
   - `niceTicks(max:count:)` for axis ticks (1-2-5 steps). Test.
   - Reuse `TrendChartMath.computeStats/hoverIndex/computeMaxBound`. Add `peakIndex(values:)`.
2. **Step 8.4.2 — `iStats/UI/Instrument/LiveChart.swift`:** modes `.single`, `.stacked`, `.mirrored` (same semantics as `TrendChartMode`), and `.banded(values:bands:)` for memory pressure. It draws with `Canvas` inside `TimelineView(.animation)` **only** when `MotionPolicy == .full`. Otherwise it uses a static `Canvas` that redraws per sample.
3. **Step 8.4.3 — Visuals:** stroke 1.5 pt in the category tint; fill gradient `tint 32 % → tintDeep 8 % → clear`; horizontal fade mask (first 12 pt fades in) and a bottom fade into the surface; live head dot (5 pt) with a `Motion.pulse` ring; an optional dashed avg line and ▲ peak marker (History).
4. **Step 8.4.4 — Interaction:** `onContinuousHover` gives a crosshair (1 pt, primary 30 %), a snapped sample dot, and a lens callback `onScrub(index?, value?, secondsAgo?)` that the scaffold uses to swap the insight text. Haptic `.alignment` fires when the snap lands on the peak index. `⌘C` copies the scrubbed value (via a focus value).
5. **Step 8.4.5 — Accessibility:** a single element with the label "<Category> chart" and a value summary from `computeStats`. Add `accessibilityChartDescriptor` (`AXChartDescriptorRepresentable`) on macOS 13+ for an audio graph.
6. **Step 8.4.6 — Previews:** each mode at flat, spiky, and empty data, light and dark.

## Files
`Sources/iStatsCore/LiveChartMath.swift`, `Tests/iStatsCoreTests/LiveChartMathTests.swift`, `iStats/UI/Instrument/LiveChart.swift`.

## Definition of done
- Math tests pass. The chart glides at 1 s refresh without visible stutter, freezes under Reduce Motion / paused, and costs ≤ 1 % CPU in isolation (Instruments, recorded in the summary).
