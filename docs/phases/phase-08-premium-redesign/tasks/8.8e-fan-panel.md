# Task 8.8e — Fans Panel: Turbine + Fanless State

**Phase:** 8 (Sub-phase 8C) · **Depends on:** 8.6 · **Blueprint:** [`design.md §6.5`](../design.md)

## What to do
1. **Glance:** max RPM across fans; headline via `PanelHeadline.fan` ("Quiet · 1,250 rpm"); chart = RPM.
2. **Now page:** per fan, a row with:
   - *Turbine:* a custom 5-blade `Shape` (64 pt) rotating via `TimelineView` at `FanMath.visualSpeed(rpm:min:max:)` revolutions/second (pure, tested, capped at 1.5 rps so it reads as motion, not a blur). Static under `MotionPolicy != .full`.
   - `ArcGauge` from `minRPM` to `maxRPM` with the current needle; the label is the RPM via `LiveNumber`. If min/max are unknown, show RPM only (no gauge).
3. **Fanless state:** `InsetEmptyState` with "Fanless by design" / "This Mac cools passively." and an action **Open Temperature** that asks `PanelController` to swap to the thermal panel.
4. Read-only per ADR 0004: no controls.
5. **Previews:** 1 fan idle, 2 fans loaded, unknown bounds, fanless, unavailable.
