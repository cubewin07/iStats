# Task 7.4e — Fans Popover (`Overview · History`) & Legacy Fan View Removal

**Phase:** 7 — Widget & Popover Redesign (Sub-phase 7E: Category Popovers)
**Depends on:** 7.1a, 7.3c
**Parallel with:** 7.4a–d, 7.4f–h

## Purpose

*"Why is it loud?"* — Replace the 6 legacy fan popovers (`FanPopoverView`, `FanDualRPMPopoverView`, `FanTachometerPopoverView`, `FanBladesPopoverView`, `FanBarsPopoverView`, `FanHistoryPopoverView`), `FanSummaryView`, and `FanBladesIllustrationView` with a 2-tab `FanPopover.swift`.

## What to do

1. **Step 7.4e.1 — Build `Overview` tab in `iStats/UI/Popovers/FanPopover.swift` (2 tabs: `Overview · History`):**
   - **Per-fan cards:** One card per `FanReading` in `sample.fans`:
     - Fan name, hero RPM readout, `RangeBar` spanning `minRPM → maxRPM` with a current-position marker, and `"% of max"` caption.
   - **Thermal cause line:** Read `coordinator.latestThermal?.value` using `ThermalSensorClassifier` to display `"Peak 78 °C · CPU"` (read-only) so the user immediately sees *why* the fans are spinning up.
   - **Mode row:** `"Mode: Automatic (firmware)"` — strictly read-only per ADR 0004.
   - **Fanless Mac state (`sample.isFanless == true`):** Render a clean `"Passive cooling"` card explaining that thermal dissipation is handled by the enclosure, accompanied by the current system `ThermalPressure` row.
2. **Step 7.4e.2 — Wire `PopoverFactory` and delete legacy Fan views:**
   - Route `.fan` in `PopoverFactory` to `FanPopover`.
   - Remove the 6 `Fan*PopoverView` structs from `CategoryDetailPopoverView.swift`, and delete `FanSummaryView.swift` and `FanBladesIllustrationView.swift`.
