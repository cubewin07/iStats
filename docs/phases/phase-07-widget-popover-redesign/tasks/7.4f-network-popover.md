# Task 7.4f — Network Popover (`Overview · Connection · History`) & Legacy Network View Removal

**Phase:** 7 — Widget & Popover Redesign (Sub-phase 7E: Category Popovers)
**Depends on:** 7.3c
**Parallel with:** 7.4a–e, 7.4g–h

## Purpose

*"How fast, over what, and is the link healthy?"* — Replace the 4 legacy network popovers, `NetworkSummaryView`, and `NetworkPipesIllustrationView` with a single tabbed `NetworkPopover.swift`.

## What to do

1. **Step 7.4f.1 — Build `Overview` tab in `iStats/UI/Popovers/NetworkPopover.swift`:**
   - **Dual Hero:** Two side-by-side readings: `↓ \(downloadRate)` in `CategoryPalette` `.indigo` and `↑ \(uploadRate)` in `.pink.opacity(0.85)`, formatted with `preferences.networkUnit` (`bytes` vs `bits`).
   - **Chart:** Mirrored duplex `TrendChart` (↓ above / ↑ below) with hover scrubber.
   - **Active Interfaces:** List only interfaces where `bytesInPerSec > 0 || bytesOutPerSec > 0` or `name == primaryInterface` (capped with `"Show all (n)"` if needed): icon (`connectionType.iconName`), interface name, and live ↓ / ↑ rates.
   - **Session Totals:** Total downloaded / uploaded since boot (`totalBytesIn`, `totalBytesOut`).
2. **Step 7.4f.2 — Build `Connection` tab:**
   - **Primary Link:** Connection type + primary interface (`en0`), `CopyableValue` row for local IPv4 address (click-to-copy with `"Copied"` toast), gateway IP, and DNS servers.
   - **Wi‑Fi Details block (only when `wifiDetails != nil`):** Signal quality `RangeBar` derived from SNR, RSSI / noise (`dBm`), Tx link rate (`Mbps`), and channel · band (`5 GHz` / `6 GHz`).
   - **Privacy invariant:** Never make an external network request for public IP lookup (ADR 0006).
3. **Step 7.4f.3 — Wire `PopoverFactory` and delete legacy Network views:**
   - Route `.network` in `PopoverFactory` to `NetworkPopover`.
   - Remove the 4 `Network*PopoverView` structs from `CategoryDetailPopoverView.swift`, and delete `NetworkSummaryView.swift` and `NetworkPipesIllustrationView.swift`.
