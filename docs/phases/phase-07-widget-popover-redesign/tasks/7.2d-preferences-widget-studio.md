# Task 7.2d — Preferences Menu Bar Studio Updates

**Phase:** 7 — Widget & Popover Redesign (Sub-phase 7C: Widget Catalog & Menu Bar Renderer)
**Depends on:** 7.2c
**Blocks:** 7.3c

## What to do

Update `iStats/UI/PreferencesMenuBarPane.swift` and `iStats/UI/PreferencesComponents.swift` so users can configure the redesigned 32-widget catalog:

1. **Step 7.2d.1 — Temperature multi-source widget configuration:**
   - When the Temperature category is selected, allow adding/configuring `Temperature (text)` and `Thermometer (glyph)` widgets per `MetricSource` (`peak`, `cpu`, `gpu`, `memory`, `ssd`, `battery` — hiding `battery` on desktop Macs without a battery).
   - Allow multiple Temperature widgets in the menu bar simultaneously as long as their `source` differs (unique `id = thermal.text.<source>`).
2. **Step 7.2d.2 — Widget-level options in the studio inspector:**
   - For Network and Disk `.throughput` widgets: expose the `Stacked | Single-line` layout picker.
   - For `.sparkline` and `.gauge` widgets across all categories: expose the `"Show 3-letter label"` toggle (`showLabel`).
   - For Fans `.throughput` ("Dual RPM"): only offer when `fans.count ≥ 2`.
3. **Step 7.2d.3 — Fanless Mac handling in the Category Rail:**
   - When `coordinator.latestFan?.value?.isFanless == true`, display the Fans category rail item as disabled (or hidden per 7.0 decision) with subtitle `"This Mac has no fans"`.
4. **Step 7.2d.4 — Live Menu Bar Strip & widget card previews:**
   - Ensure the Live Menu Bar Strip and widget style cards render the new `source`, `glyph`, and `throughputLayout` configurations accurately.
