# Task 7.2c — `MenuBarIconRenderer` Overhaul: Fans, Network, Disk, & Power

**Phase:** 7 — Widget & Popover Redesign (Sub-phase 7C: Widget Catalog & Menu Bar Renderer)
**Depends on:** 7.2b
**Blocks:** 7.2d

## What to do

Complete the `iStats/UI/MenuBarIconRenderer.swift` update for `fan`, `network`, `disk`, and `power`, and update dirty-checking cache keys:

1. **Step 7.2c.1 — Fans widgets (5):**
   - `text` ("Fan RPM"): `FAN` / `1840` (raw RPM instead of % of max). On a fanless Mac (`isFanless`), render `FAN` / `—` with tooltip `"Passive cooling"`.
   - `throughput` ("Dual RPM"): Lines `L 1840` / `R 1910` (only offered when `fans.count ≥ 2`).
   - `glyph` ("Fan glyph"): SF `fan` symbol (tinted via `StatusThresholds.fan` above 80% of max) + RPM.
   - `sparkline` ("RPM History"): Plot **max** fan RPM across `sample.fans` instead of `fans.first`.
   - Remove `fan.gauge` (Tachometer) and `fan.symbol` (Blades).
2. **Step 7.2c.2 — Network (3) & Disk (5) widgets:**
   - **Network & Disk `.throughput`:** Support `config.throughputLayout` (`stacked` vs `singleLine` `"↓1.2M ↑84K"` / `"R 1.2M W 84K"`) with fixed-width monospaced tabular slots so digit or unit changes never shift menu bar width.
   - **Network `.sparkline` & Disk `.sparkline`:** Mirrored duplex history (Network ↓ indigo above / ↑ pink below; Disk Read teal above / Write orange below).
   - **Disk `.gauge` ("Storage Ring"):** Boot volume used %, status colour at ≥ 90% / 95%, optional `SSD` vertical label.
   - **Disk `.text` ("Free Space"):** Two-line `SSD` / `412G` (free bytes on boot volume).
   - Remove `network.bar` and `disk.bar`.
3. **Step 7.2c.3 — Battery & Power widgets (4 battery / 2 desktop):**
   - `symbol` ("Battery"): Keep signature battery shell + state overlays (bolt, plug, pause, `!`) and percentage display option.
   - Keep `text` ("Charge + Time"), `throughput` ("Draw / Adapter W", desktop shows draw only), and `sparkline` ("Wattage History").
   - Remove `power.gauge` ("Charge Ring") and `power.bar` ("Charge Bar").
4. **Step 7.2c.4 — Update renderer cache / dirty-checking keys & geometry tests:**
   - Ensure `MenuBarIconRenderer` dirty-checking keys include `config.source`, `config.throughputLayout`, and `config.showLabel`.
   - Update `MenuBarItemMatrixTests.swift`, `MenuBarGeometryInvarianceTests.swift`, and `MenuBarDirtyCheckingTests.swift` for the 32-widget catalog.
