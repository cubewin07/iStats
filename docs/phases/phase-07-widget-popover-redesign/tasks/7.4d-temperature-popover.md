# Task 7.4d — Temperature Popover (`Overview · Sensors · History`) & Legacy Thermal View Removal

**Phase:** 7 — Widget & Popover Redesign (Sub-phase 7E: Category Popovers)
**Depends on:** 7.1a, 7.3c
**Parallel with:** 7.4a–c, 7.4e–h

## Purpose

*"Is it hot or throttling, and where?"* — Replace the 8 legacy thermal popovers, `ThermalSummaryView`, `ThermalHeatMapIllustrationView`, and `ThermalSubsystem` with a single tabbed `TemperaturePopover.swift` driven by `ThermalPressure` and `ThermalSensorClassifier`.

## What to do

1. **Step 7.4d.1 — Build `Overview` tab in `iStats/UI/Popovers/TemperaturePopover.swift`:**
   - **Hero:** Headline is **system `ThermalPressure`** (`Nominal` / `Fair` / `Serious` / `Critical`) with peak temperature (`°C` / `°F` via `preferences.temperatureUnit`) beside it and a 60 pt peak `TrendChart`.
   - **Component rows:** Render one row per active `MetricSource` (`cpu`, `gpu`, `memory`, `ssd`, `battery` — only those that have matching sensors in `sample.sensors` via `ThermalSensorClassifier`):
     - Shows source icon (`source.symbolName`), peak temperature, a status-coloured `RangeBar` on a shared `20–110 °C` scale, and a compact sparkline.
     - If the popover was opened from a source-specific widget (`focusSource != nil` and `!= .peak`), highlight and auto-expand that component's sensor breakdown.
   - **Eliminate all invented limits:** Do not include TJMax 105 °C headroom, DRAM 2x refresh policy, NAND endurance limit, or arbitrary zone ring limits.
2. **Step 7.4d.2 — Build `Sensors` tab:**
   - Group all sensors by component (`ThermalSensorClassifier`), sorted **hottest first** within each group.
   - Show sensor name + formatted temperature (`°C` / `°F`), with raw sensor key/name in `.help(...)` tooltip.
   - Cap each group at **8 visible rows** with a `"Show all (n)"` toggle so the popover stays within `≤ 480 pt` without a nested `ScrollView` even with 40+ SMC sensors.
3. **Step 7.4d.3 — Wire `PopoverFactory` and delete legacy Thermal views:**
   - Route `.thermal` in `PopoverFactory` to `TemperaturePopover(focusSource: ...)`.
   - Remove `ThermalSubsystem` and all 8 `Thermal*PopoverView` structs from `CategoryDetailPopoverView.swift`, and delete `ThermalSummaryView.swift` and `ThermalHeatMapIllustrationView.swift`.
