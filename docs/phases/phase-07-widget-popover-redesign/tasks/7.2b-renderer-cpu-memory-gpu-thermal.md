# Task 7.2b — `MenuBarIconRenderer` Overhaul: CPU, Memory, GPU, & Temperature

**Phase:** 7 — Widget & Popover Redesign (Sub-phase 7C: Widget Catalog & Menu Bar Renderer)
**Depends on:** 7.1b, 7.2a
**Blocks:** 7.2c, 7.2d

## What to do

Update `iStats/UI/MenuBarIconRenderer.swift` for the first 4 categories (`cpu`, `memory`, `gpu`, `thermal`) according to `plan.md` §3:

1. **Step 7.2b.1 — Shared ring, sparkline & vertical label helpers:**
   - Standardize ring stroke width to `2.6 pt` across all `.gauge` widgets.
   - Support optional 3-letter vertical label (`drawVerticalCategoryText` using `config.category.shortLabel` or `config.source?.shortLabel`) when `config.showLabel == true` on `.gauge` and `.sparkline` widgets.
   - Read all category colours from `CategoryPalette` and all severity tints from `StatusThresholds`.
2. **Step 7.2b.2 — CPU widgets (4):**
   - `text`: Two-line `CPU` / `23%`, value tinted by `StatusThresholds.cpu` when ≥ warning.
   - `gauge` ("Load Ring"): Two-segment 2.6 pt ring: User (`CategoryPalette` blue) + System (`.red` at 70%). Drop the filled pie look.
   - `bar` ("Core Cluster"): Per-core micro bars grouped **E | P** with a `2 pt` gap between clusters, capped at 16 bars (above 16 cores, render cluster summary bars so width stays bounded).
   - `sparkline`: Stacked area User + System instead of a single total line.
3. **Step 7.2b.3 — Memory widgets (4):**
   - `text`: `MEM` / `68%`, value tint driven by `MemoryPressure` via `StatusThresholds.memory` (not used %).
   - `gauge` ("Pressure Ring"): Single ring fill = used %, ring colour = `MemoryPressure` status colour. Remove the 4-segment micro donut.
   - `bar` ("Allocation"): 3 segments only — App / Wired / Compressed (drop Cached).
   - `sparkline`: Line colour = current `MemoryPressure` status colour. Remove `memory.symbol`.
4. **Step 7.2b.4 — GPU widgets (4) & Temperature widgets (3):**
   - **GPU:** `gauge` ("Load Ring") uses category `.purple` and switches to status colour only at ≥ threshold (remove temperature-based tinting). Remove `gpu.symbol` ("GPU Die").
   - **Temperature:**
     - `text` + `source`: Top row shows `source.shortLabel` (`TMP`, `CPU`, `GPU`, `MEM`, `SSD`, `BAT`), bottom row shows temperature from `ThermalSensorClassifier.peakCelsius(in:for:)`. Value tint uses `StatusThresholds.temperature(for: source)`. Draw a `3 pt` status dot top-right when `ThermalPressure ≥ .serious`.
     - `glyph` + `source`: `9 pt` thermometer glyph with status-coloured bulb fill + `"62°"`.
     - Delete the dead thermal `.bar` code path and thermal `.gauge` ring.
