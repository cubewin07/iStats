# Task 7.8 *(Optional, Own ADR)* — Top Processes Sampler (`ProcessSampler`)

**Phase:** 7 — Widget & Popover Redesign (Sub-phase 7F: Shared History & Optional Extensions)
**Depends on:** 7.4a, 7.4b
**Blocks:** — (independent optional enhancement)

## What to do

1. **Step 7.8.1 — Author ADR 0009 ("Lightweight Top-Process Sampling via libproc"):**
   - Document using Darwin `proc_listpids` + `proc_pid_rusage` (`rusage_info_v4`) + `proc_name` / `NSRunningApplication` icon lookup on the background scheduler only.
   - Define the CPU budget gate (`< 0.5%` CPU at 2 s interval; sampled only when CPU/Memory popover is open or at a slower cadence).
2. **Step 7.8.2 — Add `ProcessEntry` models & delta math in `Sources/iStatsCore/`:**
   - Define `ProcessCPUReading(pid:name:cpuPercent:)` and `ProcessMemoryReading(pid:name:footprintBytes:)`.
   - Implement pure delta math in `iStatsCore` computing per-PID CPU % between ticks using `RateMath` invariants (PID reuse / counter reset → `0`, never negative).
3. **Step 7.8.3 — Implement `iStats/Sampling/ProcessSampler.swift`:**
   - Background-only sampler conforming to `Sampler`; degrades gracefully to `.unavailable(reason:)` if `proc_listpids` fails.
4. **Step 7.8.4 — Surface `"Top Apps"` in `CPUPopover` and `MemoryPopover` Overview tabs:**
   - Render top 5 processes by CPU % in `CPUPopover` and top 5 by `ri_phys_footprint` in `MemoryPopover` (within the `≤ 480 pt` height budget).
