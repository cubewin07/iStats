# Task 7.4b — Memory Popover (`Overview · Pressure · History`) & Legacy Memory View Removal

**Phase:** 7 — Widget & Popover Redesign (Sub-phase 7E: Category Popovers)
**Depends on:** 7.3c
**Parallel with:** 7.4a, 7.4c–7.4h

## Purpose

*"Do I need to close something?"* — Replace the 5 legacy `Memory*PopoverView`s, `MemorySummaryView`, `MemoryStickIllustrationView`, and `MemoryPressureView` with a single tabbed `MemoryPopover.swift`.

## What to do

1. **Step 7.4b.1 — Build `Overview` tab in `iStats/UI/Popovers/MemoryPopover.swift`:**
   - **Hero:** `HeroMetric` showing `used` bytes (`11.2 GB`) with context `"of \(total)"`, paired with a 60 pt `TrendChart` tinted by `MemoryPressure` status. Header status pill reflects `MemoryPressure` (`Normal` / `Warning` / `Critical`), never raw used %.
   - **Breakdown:** 5-segment `SegmentedBar` (App / Wired / Compressed / Cached / Free using `.mint` opacity scale from `CategoryPalette`) + `LegendRow`s showing both formatted bytes and `%` of total.
   - **Guidance:** One-line explanation from `VerdictEvaluator` (e.g. `"Plenty of headroom — cached memory is reclaimed automatically"`).
2. **Step 7.4b.2 — Build `Pressure` tab:**
   - **Pressure band timeline:** Horizontal strip showing recent pressure state history (green / yellow / red over the sample window).
   - **Swap section:** `SegmentedBar` or `RangeBar` for `swapUsed / swapTotal` + plain-language explanation when `swapUsed > 0`.
   - **Details:** Compressed bytes + share of used memory; Active and Inactive rows when non-nil.
3. **Step 7.4b.3 — Wire `PopoverFactory` and delete legacy Memory views:**
   - Route `.memory` in `PopoverFactory` to `MemoryPopover`.
   - Remove the 5 `Memory*PopoverView` structs from `CategoryDetailPopoverView.swift`, and delete `MemorySummaryView.swift`, `MemoryStickIllustrationView.swift`, and `MemoryPressureView.swift` (once `StatusBanner` replaces `MemoryPressureAlertBanner`).
