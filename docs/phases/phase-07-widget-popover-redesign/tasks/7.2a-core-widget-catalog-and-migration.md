## What to do

1. **Step 7.2a.1 — Update `MetricDisplayStyle` (`Sources/iStatsCore/MenuBarItemConfig.swift`):**
   - Add `.glyph` case (for Temperature thermometer + °C and Fan SF symbol + RPM).
   - Remove deprecated standalone thermal styles (`cpuTemp`, `gpuTemp`, `memoryTemp`, `storageTemp`, `batteryTemp`) from active `CaseIterable` / `supportedStyles`, while preserving their raw strings in `MenuBarItemConfig.init(from:)` for decode migration.
   - Update `supportedStyles(for:hasBattery:)` to match `plan.md` §3 (**32 total widgets**):
     - **CPU (4):** `.text` ("CPU %"), `.gauge` ("Load Ring"), `.bar` ("Core Cluster"), `.sparkline` ("Usage History")
     - **Memory (4):** `.text` ("Used %"), `.gauge` ("Pressure Ring"), `.bar` ("Allocation"), `.sparkline` ("Used % History") *(removed `.symbol`)*
     - **GPU (4):** `.text` ("GPU %"), `.gauge` ("Load Ring"), `.bar` ("Load Bar"), `.sparkline` ("Load History") *(removed `.symbol`)*
     - **Temperature (3 styles × `source`):** `.text` ("Temperature"), `.glyph` ("Thermometer"), `.sparkline` ("Peak History") *(removed `.gauge`, `.cpuTemp`…`.batteryTemp`)*
     - **Fans (5):** `.text` ("Fan RPM"), `.throughput` ("Dual RPM"), `.glyph` ("Fan Glyph"), `.bar` ("Fan Bars"), `.sparkline` ("RPM History") *(removed `.gauge`, `.symbol`)*
     - **Network (3):** `.throughput` ("Up / Down"), `.sparkline` ("Duplex History"), `.symbol` ("Activity Arrows") *(removed `.bar`)*
     - **Disk (5):** `.throughput` ("Read / Write"), `.sparkline` ("I/O History"), `.symbol` ("R/W LEDs"), `.gauge` ("Storage Ring"), `.text` ("Free Space") *(removed `.bar`, added `.text`)*
     - **Power (4 battery / 2 desktop):** `.symbol` ("Battery"), `.text` ("Charge + Time"), `.throughput` ("Draw / Adapter W"), `.sparkline` ("Wattage History") *(removed `.gauge`, `.bar`)*
2. **Step 7.2a.2 — Extend `MenuBarItemConfig` options & composite `id`:**
   - Add `public var source: MetricSource?` (used by `.thermal` `.text` and `.glyph`; defaults to `.peak` when category is `.thermal` and style is `.text` or `.glyph`).
   - Add `public var throughputLayout: ThroughputLayout?` (`stacked` default vs `singleLine` for Network/Disk `.throughput`).
   - Add `public var showLabel: Bool` (optional 3-letter vertical label for `.sparkline` and `.gauge` widgets).
   - Compute deterministic `id`: `category.style` or `category.style.source` when `source != nil` (e.g. `thermal.text.cpu`).
3. **Step 7.2a.3 — Implement decode-time widget migration & deduplication (`plan.md` §6):**
   - In `MenuBarItemConfig.init(from:)`:
     - `memory.symbol` → `memory.gauge`
     - `gpu.symbol` → `gpu.gauge`
     - `thermal.cpuTemp / gpuTemp / memoryTemp / storageTemp / batteryTemp` → `thermal.text` + `source: .cpu / .gpu / .memory / .ssd / .battery`
     - `thermal.gauge` → `thermal.glyph` + `source: .peak`
     - `fan.gauge`, `fan.symbol` → `fan.glyph`
     - `network.bar` → `network.symbol`
     - `disk.bar` → `disk.text`
     - `power.gauge`, `power.bar` → `power.symbol`
   - Add `MenuBarItemConfig.deduplicated(_ items: [MenuBarItemConfig]) -> [MenuBarItemConfig]` preserving first-occurrence order by `id`, and apply it when `PreferencesStore` loads `activeMenuBarItems`.
4. **Step 7.2a.4 — Write `MenuBarItemConfigMigrationTests`:**
   - Test every row of the §6 widget migration table, unknown raw value fallback, and order-preserving deduplication.
