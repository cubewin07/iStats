# Task 7.4g — Disk Popover (`Overview · Volumes · History`) & Legacy Disk View Removal

**Phase:** 7 — Widget & Popover Redesign (Sub-phase 7E: Category Popovers)
**Depends on:** 7.3c
**Parallel with:** 7.4a–f, 7.4h

## Purpose

*"Am I running out of space, and what's hitting the disk?"* — Replace the 5 legacy disk popovers, `DiskSummaryView`, and `DiskStorageTankIllustrationView` with a single tabbed `DiskPopover.swift`.

## What to do

1. **Step 7.4g.1 — Build `Overview` tab in `iStats/UI/Popovers/DiskPopover.swift`:**
   - **Hero:** `HeroMetric` showing boot volume free space (`412 GB free`), context `"of \(total) · \(volumeName)"`, and a capacity bar (`SegmentedBar` / `RangeBar`) that shifts to status warning/critical at `StatusThresholds.disk` (90% / 95%).
   - **Live I/O Grid:** 2×2 `StatGrid` displaying Read bytes/s, Write bytes/s, Read IOPS, and Write IOPS.
   - **Chart:** Mirrored Read / Write `TrendChart` (Read `.teal` above, Write `.orange` 85% below).
2. **Step 7.4g.2 — Build `Volumes` tab:**
   - List mounted volumes from `sample.volumes`, sorted with internal volumes (`/` first) followed by external/removable volumes.
   - Each volume row shows: volume name, mount point caption, used/total capacity bar (status-coloured ≥ 90%), and free bytes.
   - Cap visible volumes (e.g. 6 rows with `"Show all (n)"`) so 12+ mounted volumes never overflow `480 pt` height or require a nested `ScrollView`.
3. **Step 7.4g.3 — Wire `PopoverFactory` and delete legacy Disk views:**
   - Route `.disk` in `PopoverFactory` to `DiskPopover` (footer context action opens `"Storage Settings"`).
   - Remove the 5 `Disk*PopoverView` structs from `CategoryDetailPopoverView.swift`, and delete `DiskSummaryView.swift` and `DiskStorageTankIllustrationView.swift`.

- Boot volume free space, 2×2 live I/O + IOPS grid, mirrored R/W chart, and multi-volume list (tested with 12 volumes) fit within `330 × ≤ 480 pt`.
