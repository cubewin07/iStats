# Task 7.4c — GPU Popover (`Overview · Engines · History`) & Legacy GPU View Removal

**Phase:** 7 — Widget & Popover Redesign (Sub-phase 7E: Category Popovers)
**Depends on:** 7.3c
**Parallel with:** 7.4a–b, 7.4d–h

## Purpose

*"Is the GPU the bottleneck?"* — Replace the 5 legacy `GPU*PopoverView`s, `GPUSummaryView` (including the synthetic core grid), and `GPUDieIllustrationView` with a single tabbed `GPUPopover.swift`.

## What to do

1. **Step 7.4c.1 — Build `Overview` tab in `iStats/UI/Popovers/GPUPopover.swift`:**
   - **Hero:** `HeroMetric` showing `utilizationPercent` (`58%`), context `"\(deviceName) · \(coreCount)-core"` (omitting core count if nil), paired with a 60 pt category-purple `TrendChart`.
   - **Breakdown:** Renderer % and Tiler % horizontal bars (only rendered when `rendererUtilizationPercent` / `tilerUtilizationPercent` are non-nil).
   - **Memory:** Allocated vs `recommendedMaxWorkingSetBytes` bar (`"3.1 GB of 10.7 GB working set"`, or `memoryUsedBytes` when working set is nil).
   - **Details:** Power draw (`powerWatts` W) and GPU Temperature (`temperatureCelsius` — tapping opens or switches focus to the Temperature popover's `.gpu` source).
2. **Step 7.4c.2 — Build `Engines` (or `Device`) tab:**
   - Dynamically title the second tab `"Engines"` when renderer/tiler telemetry is present, or `"Device"` when both are `nil`.
   - Render Renderer and Tiler mini `TrendChart`s (when available).
   - Render connected displays list from `displayDescriptions`.
   - Render GPU recovery count (`recoveryCount`) as a `StatusBanner` warning row **only when `> 0`** (real hardware fault signal).
   - Collapsible `"About this GPU"` section: Metal family, ray tracing support, unified memory (`isUnifiedMemory`), core count. Never show hard-coded `"Metal Acceleration: Hardware Enabled"` or synthetic core-lighting grids.
3. **Step 7.4c.3 — Wire `PopoverFactory` and delete legacy GPU views:**
   - Route `.gpu` in `PopoverFactory` to `GPUPopover`.
   - Remove the 5 `GPU*PopoverView` structs from `CategoryDetailPopoverView.swift`, and delete `GPUSummaryView.swift` and `GPUDieIllustrationView.swift`.
