# Task 7.1c — Core Popover & Stat UI Primitives (`Design/Components/`)

**Phase:** 7 — Widget & Popover Redesign (Sub-phase 7B: Design System & Component Kit)
**Depends on:** 7.1b
**Blocks:** 7.3b, 7.4a–h

## What to do

Build the reusable non-chart components in `iStats/UI/Design/Components/`, each adhering strictly to `Tokens` and `CategoryPalette`, with `#Preview` blocks covering light/dark and edge states:

1. **Step 7.1c.1 — Header, Tabs & Hero components:**
   - `PopoverHeader.swift`: 28 pt category icon chip (`CategoryPalette.color(for:)`), 13 pt semibold title, 11 pt secondary status sentence from `MetricVerdict`, and semantic status pill (`StatusLevel`). VoiceOver reads status sentence first.
   - `TabBar.swift`: Compact segmented control supporting 2 or 3 `PopoverTab` items with category-specific detail tab title and `⌘1`–`⌘3` keyboard shortcut bindings.
   - `HeroMetric.swift`: 28 pt rounded monospaced-digit primary reading + unit + secondary context string (e.g. `"of 16 GB"`, `"on 10 cores · 3.2 GHz"`) + optional right-aligned slot for a 60 pt inline sparkline.
2. **Step 7.1c.2 — Breakdown & Stat Row components:**
   - `SegmentedBar.swift`: Multi-segment horizontal proportional bar (used by CPU User/System/Idle, Memory App/Wired/Compressed/Cached/Free, Storage capacity) with smooth animation and accessible summary.
   - `LegendRow.swift`: Colour swatch dot + label + primary value + optional secondary share (`%`).
   - `StatRow.swift`: 11 pt key label + right-aligned monospaced value + optional status dot or tooltip.
   - `StatGrid.swift`: 2×2 or 2-column compact card grid of `StatRow`s (used by Disk Read/Write/IOPS, etc.).
   - `RangeBar.swift`: Min → Max horizontal track with current-value marker and optional status-tinted fill (used by Fan RPM min/max and Temperature 20–110 °C sensor bars).
   - `CopyableValue.swift`: Interactive value row that copies its string to `NSPasteboard.general` on click and briefly swaps in a `"Copied"` confirmation badge (used by Network local IPv4/gateway/DNS).
3. **Step 7.1c.3 — State & Banner components:**
   - `StatusBanner.swift`: Compact banner for Paused state (with `"Resume"` button), GPU recovery warning, or Memory pressure warning (replaces `MemoryPressureAlertBanner`).
   - `SkeletonView.swift`: Shimmer/placeholder layout for hero and stat rows when `Sample` is not yet populated (respects `accessibilityReduceMotion`).
4. **Step 7.1c.4 — Add unit/view smoke tests:**
   - Add construction and state rendering tests in `iStatsTests/SwiftUIViewsTests.swift`.
