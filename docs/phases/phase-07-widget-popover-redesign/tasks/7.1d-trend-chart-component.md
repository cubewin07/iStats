# Task 7.1d — Unified `TrendChart` Component

**Phase:** 7 — Widget & Popover Redesign (Sub-phase 7B: Design System & Component Kit)
**Depends on:** 7.1b
**Blocks:** 7.3b, 7.4a–h, 7.5

## What to do

Create `iStats/UI/Design/Components/TrendChart.swift` to replace ad-hoc sparklines and `DualTraceRollingGraphView` across all popovers and the shared `HistoryTab`:

1. **Step 7.1d.1 — Define `TrendChart` data & style model:**
   - Support 3 rendering modes:
     - `.single(values: [Double], color: Color, fillGradient: Bool)` (GPU, Fans, Power, Memory with optional pressure band underlay)
     - `.stacked(primary: [Double], secondary: [Double], primaryColor: Color, secondaryColor: Color)` (CPU User + System)
     - `.mirrored(top: [Double], bottom: [Double], topColor: Color, bottomColor: Color, topLabel: String, bottomLabel: String)` (Network ↓/↑ and Disk Read/Write)
   - Accept `timestamps: [Date]` (or sample interval) so time-ago captions reflect the **actual elapsed window** rather than a hard-coded `"60s"` string.
   - Support configurable `height` (`60 pt` compact hero sparkline vs `140 pt` full `HistoryTab` chart).
2. **Step 7.1d.2 — Implement auto-scaling & `RateMath`-safe decay max:**
   - Fixed `0...100` scale for percentage metrics; dynamic decaying peak scale for throughput/wattage/RPM (never negative, minimum floor > 0 so flat-zero lines rest cleanly at the baseline).
3. **Step 7.1d.3 — Implement interactive hover scrubber & summary strip:**
   - On pointer hover (`onContinuousHover`), draw a vertical hairline at the nearest sample index and show a floating or header-aligned readout: formatted value + relative time (`"14s ago"`).
   - Optional `showStatsStrip: Bool` rendering a compact `Min · Avg · Max · Now` monospaced caption strip below the chart.
4. **Step 7.1d.4 — Add unit tests for scale & stats math:**
   - Extract pure chart math (`TrendChartMath`: min/avg/max/now, mirrored normalization, hover index lookup, relative time formatting) and test it in `DetailViewGraphsTests.swift`.
