# Task 7.5 — Shared `HistoryTab` Integration & Per-Category Series Configuration

**Phase:** 7 — Widget & Popover Redesign (Sub-phase 7F: Shared History & Optional Extensions)
**Depends on:** 7.1d, 7.3b, 7.4a–h
**Blocks:** 7.6, 7.7

## Purpose

*"Has this been going on for a while?"* — Provide one shared `HistoryTab.swift` template used across all 8 category popovers (`plan.md` §4.3).

## What to do

1. **Step 7.5.1 — Create `iStats/UI/Popovers/HistoryTab.swift`:**
   - **Range picker:** `1m | 5m | 15m` segmented control at top (`5m` and `15m` disabled/hidden until optional Task 7.6 is enabled, or dynamically enabled when extended series data is present; time window labels derived from the active sampling interval).
   - **Primary chart:** Full `140 pt` `TrendChart` with hover scrubber and `Min · Avg · Max · Now` monospaced stat strip below.
2. **Step 7.5.2 — Configure per-category series (`plan.md` §4.3):**
   - **CPU:** Stacked `User` (blue) + `System` (red 70%) area chart.
   - **Memory:** `Used %` line with `MemoryPressure` status band underlay.
   - **GPU:** `utilizationPercent` single-series area chart in category `.purple`.
   - **Temperature:** Peak °C/°F chart + interactive per-component toggle chips (`Peak`, `CPU`, `GPU`, `Memory`, `SSD`, `Battery`) powered by `ThermalSensorClassifier`.
   - **Fans:** Max RPM across fans (`fans.map(\.currentRPM).max()`).
   - **Network:** Mirrored duplex ↓ Download (`.indigo`) / ↑ Upload (`.pink` 85%).
   - **Disk:** Mirrored Read (`.teal`) / Write (`.orange` 85%).
   - **Battery & Power:** Power draw (`W`) primary series (+ battery `chargePercent` secondary overlay/readout on battery Macs).
3. **Step 7.5.3 — Connect all 8 category popovers & write view/series tests:**
   - Ensure the `.history` tab of all 8 category popovers renders `HistoryTab(category: ...)`.
   - Add unit tests verifying series extraction for each of the 8 categories from `[Sample<T>]`.

- The `History` tab works across all 8 categories using the in-memory ring buffer, including component filter chips on Temperature and mirrored charts on Network/Disk.
- `xcodebuild test -scheme iStatsApp -destination 'platform=macOS'` passes.
