# Task 7.1b — `Tokens`, `CategoryPalette`, & Deduplicating Category Icon/Colour Switches

**Phase:** 7 — Widget & Popover Redesign (Sub-phase 7B: Design System & Component Kit)
**Depends on:** 7.1a
**Blocks:** 7.1c, 7.1d, 7.2b, 7.2c

## What to do

1. **Step 7.1b.1 — Create `iStats/UI/Design/Tokens.swift`:**
   - Define layout constants: `popoverWidth: CGFloat = 330`, `maxPopoverContentHeight: CGFloat = 480`.
   - Define spacing scale: `xs = 4`, `sm = 8`, `md = 12`, `lg = 16`.
   - Define corner radii: `chipRadius = 6`, `cardRadius = 10`.
   - Define typography tokens:
     - `heroValue`: `.system(size: 28, weight: .bold, design: .rounded).monospacedDigit()`
     - `headerTitle`: `.system(size: 13, weight: .semibold)`
     - `sectionTitle`: `.system(size: 11, weight: .semibold)`
     - `bodyLabel`: `.system(size: 11, weight: .regular)`
     - `monoValue`: `.system(size: 11, weight: .medium, design: .monospaced)`
   - Define surface view modifier / helper `Tokens.cardBackground()` using `.quaternary` fill, `10 pt` corner radius, and `0.5 pt` hairline border.
2. **Step 7.1b.2 — Create `iStats/UI/Design/CategoryPalette.swift`:**
   - Map `MetricCategory` to its single identity `Color` (and `NSColor` for `MenuBarIconRenderer`):
     - `.cpu`: `.blue`
     - `.memory`: `.mint`
     - `.gpu`: `.purple`
     - `.thermal`: `.orange`
     - `.fan`: `.cyan`
     - `.network`: `.indigo`
     - `.disk`: `.teal`
     - `.power`: `.pink` (or decision from 7.0)
   - Map two-channel series colours (`plan.md` §2):
     - Network: download = `.indigo`, upload = `.pink.opacity(0.85)`
     - Disk: read = `.teal`, write = `.orange.opacity(0.85)`
     - CPU: user = `.blue`, system = `.red.opacity(0.70)`
     - Memory composition opacities: App `1.0`, Wired `0.70`, Compressed `0.45`, Cached `0.25` of `.mint`
   - Map `StatusLevel` / `StatusSeverity` to semantic colours (`.green`, `.yellow`, `.orange`, `.red`), keeping identity and severity strictly separate.
3. **Step 7.1b.3 — Remove the 3 duplicate icon/colour switches and wire `VerdictEvaluator` to `StatusThresholds`:**
   - Update `PopoverHeaderView` (`iStats/UI/PopoverCommonComponents.swift`), `DetailPopoverView.swift`, and `PreferencesComponents.swift` to read `category.symbolName` and `CategoryPalette.color(for: category)`.
   - Update `MetricVerdict.swift` (`VerdictEvaluator`) to delegate threshold checks to `StatusThresholds` in `iStatsCore`.
   - Register the new files in `iStats.xcodeproj/project.pbxproj`.
