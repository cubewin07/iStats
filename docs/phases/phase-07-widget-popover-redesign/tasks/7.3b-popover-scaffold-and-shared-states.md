# Task 7.3b — `PopoverScaffold`, Keyboard Shortcuts (`⌘1`–`⌘3`), & Shared States

**Phase:** 7 — Widget & Popover Redesign (Sub-phase 7D: Tabbed Popover Model, Scaffold & Shell)
**Depends on:** 7.1c, 7.1d, 7.3a
**Blocks:** 7.3c, 7.4a–h

## What to do

Create `iStats/UI/Design/Components/PopoverScaffold.swift` implementing the shared skeleton from `plan.md` §4.2:

1. **Step 7.3b.1 — Fixed-frame visual effect container & header/tab wiring:**
   - Wrap content in an `NSVisualEffectView(.popover)` background with fixed width `Tokens.popoverWidth` (`330 pt`) and bounded content height `≤ 480 pt` (no nested `ScrollView`s).
   - Render `PopoverHeader` at top + `TabBar` below it (supporting `⌘1`, `⌘2`, `⌘3` keyboard shortcuts to switch tabs and remembering the last active tab per category when `rememberLastTab` is enabled).
2. **Step 7.3b.2 — Shared Loading, Unavailable & Paused states:**
   - **Paused state:** When `preferences.isSamplingPaused == true`, render `StatusBanner` right under the header with a `"Sampling paused"` message and `"Resume"` button.
   - **Loading state:** When `Sample` is `nil` on initial launch, render `SkeletonView` for the hero and breakdown slots.
   - **Unavailable state:** When `Availability` is `.unavailable(reason:)`, render a muted hero `"—"` and surface the exact `reason` string clearly without crashing or showing fake zeroes.
3. **Step 7.3b.3 — Category-aware Footer (`PopoverFooter`):**
   - Left side: single context action button per category (`plan.md` §4.2):
     - CPU, Memory, GPU → `"Activity Monitor"` (`/System/Applications/Utilities/Activity Monitor.app`)
     - Network → `"Network Settings"` (`x-apple.systempreferences:com.apple.Network-Settings.extension`)
     - Disk → `"Storage Settings"` (`x-apple.systempreferences:com.apple.settings.Storage`)
     - Power → `"Battery Settings"` (`x-apple.systempreferences:com.apple.preference.battery`)
     - Temperature, Fans → no left button
   - Right side: icon-only Pause/Resume button (`⏸` / `▶︎`) and Settings button (`⚙︎`) with `.help(...)` tooltips.
