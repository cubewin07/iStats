# Task 7.3a — Core `PopoverTab`, `PopoverConfig`, & Legacy `PopoverStyle` Migration

**Phase:** 7 — Widget & Popover Redesign (Sub-phase 7D: Tabbed Popover Model, Scaffold & Shell)
**Depends on:** 7.0, 7.1a
**Blocks:** 7.3b, 7.3c

## What to do

1. **Step 7.3a.1 — Create `Sources/iStatsCore/PopoverConfig.swift`:**
   - Define `public enum PopoverTab: String, Codable, CaseIterable, Identifiable, Sendable`:
     - `.overview`, `.detail`, `.history`
     - Add `public func title(for category: MetricCategory, hasDetailedGPUEngines: Bool = true) -> String`:
       - `.overview` → `"Overview"`
       - `.history` → `"History"`
       - `.detail` → CPU `"Cores"`, Memory `"Pressure"`, GPU `hasDetailedGPUEngines ? "Engines" : "Device"`, Thermal `"Sensors"`, Network `"Connection"`, Disk `"Volumes"`, Power `"Health"`, Fan `""` (Fans has 2 tabs: Overview · History).
     - Add `public static func supportedTabs(for category: MetricCategory, hasBattery: Bool = true) -> [PopoverTab]` (returns `[.overview, .history]` for `.fan` and desktop `.power`; `[.overview, .detail, .history]` for all others).
   - Define `public struct PopoverConfig: Codable, Hashable, Equatable, Sendable`:
     - `public var openingTab: PopoverTab` (default `.overview`)
     - `public var rememberLastTab: Bool` (default `true` per 7.0 decision)
     - `public var focusSource: MetricSource?` (used by Temperature to highlight/expand a component row on open)
2. **Step 7.3a.2 — Implement legacy `PopoverStyle` → `PopoverConfig` decode migration (`plan.md` §6):**
   - Provide `PopoverConfig.migrated(fromLegacyRawValue raw: String, category: MetricCategory, widgetSource: MetricSource?) -> PopoverConfig`:
     - `categoryDefault`, `cpuUserSystem`, `memoryComposition`, `memoryAllocation`, `gpuLoadRing`, `thermalRing`, `fan*`, `networkBars`, `diskStorageRing`, `diskActivityLEDs`, `powerBudget`, `powerWattage`, `powerChargeRing`, `powerBar` → `.overview`
     - `thermalCPU / thermalGPU / thermalMemory / thermalStorage / thermalBattery` → `.overview` + `focusSource = .cpu / .gpu / .memory / .ssd / .battery`
     - `cpuCluster`, `memoryPressure`, `gpuEngine`, `gpuDie`, `networkDiagnostics`, `diskStorageTanks` → `.detail`
     - `history` → `.history`
     - Unknown raw string → `.overview`
   - Update `MenuBarItemConfig` to store `public var popover: PopoverConfig?` and automatically decode legacy `popoverStyle` JSON keys into `popover`.
3. **Step 7.3a.3 — Write `PopoverConfigMigrationTests`:**
   - Create `Tests/iStatsCoreTests/PopoverConfigTests.swift` testing every legacy `PopoverStyle` raw value, per-category supported tabs, default tab resolution (e.g. `.sparkline` widget defaults to `.history` opening tab), and unknown value fallback.
