# Task 7.3c — `PopoverFactory`, `MenuBarController` Sizing, & Preferences "Opens on" Picker

**Phase:** 7 — Widget & Popover Redesign (Sub-phase 7D: Tabbed Popover Model, Scaffold & Shell)
**Depends on:** 7.2d, 7.3b
**Blocks:** 7.4a–h

## What to do

1. **Step 7.3c.1 — Create `iStats/UI/Popovers/PopoverFactory.swift`:**
   - Provide `@MainActor public enum PopoverFactory` with `makePopoverView(config:coordinator:preferences:)` and `makeHostingController(config:coordinator:preferences:)`.
   - Resolve the opening `PopoverTab` (from `preferences.lastSelectedTab(for: category)` if `rememberLastTab` is on, else `config.resolvedPopoverConfig.openingTab`) and `focusSource` (from `config.source ?? config.resolvedPopoverConfig.focusSource`).
   - During the transition across tasks `7.4a–h`, route categories whose new `*Popover.swift` has landed to the new tabbed popover and temporarily bridge remaining categories so the app compiles and runs after every single `7.4x` PR.
2. **Step 7.3c.2 — Update `MenuBarController.swift` for fixed 330 pt width & smooth tab height transitions:**
   - Wire `MenuBarController` to `PopoverFactory`.
   - Configure the `NSPopover` / `NSHostingController` sizing options so width stays locked at `330 pt` and vertical height animates cleanly when switching between `Overview`, `Detail`, and `History` tabs.
   - Replace the fallback popover (when zero widgets are enabled) with a compact `"No widgets active — Open Settings"` card so `DetailPopoverView.swift` is no longer needed by `MenuBarController`.
3. **Step 7.3c.3 — Update Preferences Popover Stage (`PreferencesMenuBarPane.swift`):**
   - Replace the 33-item "Popover Style" picker with:
     - `"Opens on: Overview | <Detail> | History"` segmented picker bound to `PopoverConfig.openingTab`.
     - `"Remember last opened tab"` toggle bound to `PopoverConfig.rememberLastTab`.
   - Render the live interactive tabbed popover preview on the stage.
