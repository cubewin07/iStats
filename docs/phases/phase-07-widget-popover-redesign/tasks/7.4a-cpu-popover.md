# Task 7.4a — CPU Popover (`Overview · Cores · History`) & Legacy CPU View Removal

**Phase:** 7 — Widget & Popover Redesign (Sub-phase 7E: Category Popovers)
**Depends on:** 7.3c
**Parallel with:** 7.4b–7.4h

## Purpose

*"Why is my Mac busy?"* — Replace `CPUPopoverView`, `CPUUserSystemPopoverView`, `CPUClusterPopoverView`, `CPUHistoryPopoverView`, `CPUSummaryView`, and `CPUDieIllustrationView` with a single tabbed `CPUPopover.swift`.

## What to do

1. **Step 7.4a.1 — Build `Overview` tab in `iStats/UI/Popovers/CPUPopover.swift`:**
   - **Hero:** `HeroMetric` showing `totalUsage` (`34%`), context `"on \(coreUsage.count) cores"` (+ `" · \(formattedGHz)"` only when `frequencyHz != nil`), paired with a 60 pt stacked User+System `TrendChart`.
   - **Breakdown:** `SegmentedBar` + `LegendRow`s for User (`CategoryPalette` blue), System (`.red` 70%), and Idle.
   - **Clusters:** Two compact rows (`"Performance (\(pCount)) \(pPct)%"` and `"Efficiency (\(eCount)) \(ePct)%"`) with mini progress bars backed by `performanceUsage` / `efficiencyUsage` (shown when E/P core counts > 0).
   - **Details (collapsible):** Load average 1 / 5 / 15 (`"2.1 · 1.8 · 1.6"`) with load-per-core ratio hint (`"below core count — no queueing"` vs `"above core count — threads queueing"`), and system uptime.
2. **Step 7.4a.2 — Build `Cores` tab:**
   - Grid of vertical per-core utilization bars grouped **P** then **E**, labelled by core index.
   - Fits up to 24 cores in 2 rows without scrolling (`height ≤ 480 pt`).
   - Hovering any bar reveals `"Core \(index) · \(pct)%"`. Cluster averages shown above each group.
3. **Step 7.4a.3 — Wire `History` tab & `PopoverFactory`, then delete legacy CPU views:**
   - Wire `.history` tab to `HistoryTab(category: .cpu, ...)` (or placeholder until 7.5 lands).
   - Remove `CPUPopoverView`, `CPUUserSystemPopoverView`, `CPUClusterPopoverView`, `CPUHistoryPopoverView` from `CategoryDetailPopoverView.swift`, and delete `CPUSummaryView.swift` and `CPUDieIllustrationView.swift`.
   - Add `#Preview` blocks for normal, 24-core max, and `.unavailable` states.
