# Summary — 8.3 Glass Panel Host (`MetricPanel`)

## Done
- **Step 8.3.1 — `Sources/iStatsCore/PanelPlacement.swift`**:
  - Pure algorithm computing panel `CGRect` relative to status item frame, screen visible frame, gap, and margin.
  - Horizontally centers below status item; clamps to `[screen.minX + margin, screen.maxX - margin - width]`.
  - Flips above menu bar if insufficient space below.
  - Fully tested across multi-display secondary coordinates, clamping, and edge cases.
- **Step 8.3.2 — `iStats/App/MetricPanel.swift`**:
  - Subclassed `NSPanel` with `.borderless` and `.nonactivatingPanel`.
  - Implemented `canBecomeKey = true`, `canBecomeMain = false` to enable keyboard input (`Esc`, `⌘W`, `⌘P`, `⌘1-3`) without activating the background application.
  - Liquid Glass vibrancy backing: `NSVisualEffectView(.popover)` with 16 pt continuous corner mask.
  - Configured window level `.floating`, shadow, and keyboard handling.
- **Step 8.3.3 & 8.3.4 — `iStats/App/PanelController.swift`**:
  - `@MainActor` coordinator for presentation, layout, placement, crossfade switching, and dismissal.
  - Outside click dismissal via global and local `NSEvent` monitors.
  - Automatic dismissal on space change (`activeSpaceDidChangeNotification`) and app deactivation (`didResignActiveNotification`) unless pinned.
  - Concurrency hardened for Swift 6 strict concurrency (`MainActor.assumeIsolated`).
- **Step 8.3.5 & 8.3.6 — Pinning & Detaching Support**:
  - User can toggle pin status via `⌘P` or pin action.
  - Pinned panels detach, retain their dragged screen origin, dismiss monitors are deactivated, and origins persist in `PreferencesStore.pinnedPanelOrigins`.
- **Step 8.3.7 — Menu Bar Controller Integration**:
  - Connected `MenuBarController.statusItemClicked` to `PanelController.shared.toggle(category:relativeTo:content:)`.
  - Preserved `-legacyPopovers` gate and automated test isolation for Phase 8 migration.
- **Edge case matrix recorded**:
  - Full-screen: panel respects visibleFrame without overlapping full-screen app or menu bar transition.
  - Multi-display: correctly maps coordinates across secondary displays with distinct origins.
  - Notched display: stays below notch boundary within `NSScreen.visibleFrame`.
  - Mission Control: panel dismisses on space change unless pinned.
  - Sleep/wake: non-activating panel dismisses or re-anchors cleanly.
