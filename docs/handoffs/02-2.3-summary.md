# Summary — 2.3 Property tests for CPU % math

## Done
- Extended pure property-based testing in `Tests/iStatsCoreTests/RateMathTests.swift`:
  - `testCPUUsageBoundsProperty`: Validates that CPU percentage is strictly within `0.0...100.0` for all combinations of positive, negative, zero, and extreme values.
  - `testCPUUsageMonotonicityProperty`: Validates that increasing busy ticks monotonically produces non-decreasing percentages for fixed total delta.
  - `testCPUUsageAdditivityProperty`: Validates additivity of non-overlapping busy components (`cpuUsagePercent(a + b, total) == cpuUsagePercent(a, total) + cpuUsagePercent(b, total)`).
  - `testCPUUsagePartitionOfUnityProperty`: Validates that `busy% + idle% == 100.0` within `1e-9` floating point precision.
  - `testCounterDeltaMonotonicityProperty`: Validates that `counterDelta(p, c)` computes exact non-negative difference when `c >= p` and clamps safely to `0` when `c < p` (counter wrap/reset).
  - `testCounterDeltaExtremeValuesNearUInt64Max`: Validates arithmetic near `UInt64.max`.
- Added comprehensive property tests in `Tests/iStatsTests/CPUSamplerTests.swift` for `CPUSampler.calculateSample` and `ProcessorTicks`:
  - `testPropertyBoundsInvariantAcrossSyntheticScenarios`: Asserts that `totalUsage`, `perCore`, `user`, `system`, and `idle` are strictly in `0.0...100.0` across diverse multi-core topologies (1, 2, 4, 8, 16 cores) and workload distributions (100% idle, 100% user, 100% system, 100% nice, mixed, and zero elapsed).
  - `testPropertyReconciliationInvariant`: Asserts partition of unity `user% + system% + idle% == 100.0` (within `1e-5`) and `user% + system% == totalUsage` for non-zero elapsed ticks.
  - `testPropertyZeroElapsedTicksProducesZeroUtilization`: Asserts safe reporting of `0.0%` across all metrics without divide-by-zero or NaN when counters are unchanged.
  - `testPropertyMonotonicity`: Asserts non-decreasing utilization as busy ticks increase.
  - `testPropertyPerCoreWeightedAverageReconciliation`: Asserts `totalUsage` equals the mean of per-core percentages when cores have equal total ticks.
  - `testPropertyCounterWrapOnCoreSubsets`: Asserts independent core isolation and zero-delta clamping when a subset of cores wraps while others advance.
  - `testPropertyExtremeValuesNearUInt64Max`: Asserts calculations avoid integer overflow when base counters approach `UInt64.max`.
  - `testPropertyFuzzRandomizedSyntheticTicks`: Deterministic PRNG generative test running 1,000 randomized synthetic multi-core cycles across random core topologies (1–16 cores), random tick deltas, and counter wraps, asserting all mathematical invariants on every cycle.
