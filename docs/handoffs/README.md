# Handoffs

Working notes passed between planner, examiner, and implementor.

```
<phase>-<task>-{exam,plan,summary}.md
```

Phase is two digits (`00` … `06`). Task matches the spec id (`1.4`, `2.1`).

These files are disposable once the phase report is written. Keep the latest pass; replace rather than stacking `plan-v2` names unless two plans must be compared.
