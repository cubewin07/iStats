## 1. What was built

Implemented pure analytical insight generation and panel headlines for the Instrument redesign without synthetic fallback text or magic zeroes:

- `Sources/iStatsCore/InsightEngine.swift`:
  - `InsightRule` evaluation engine prioritizing high-signal operational dynamics:
    1. `sustained` (priority 5): elevated utilization held for $\ge 30$ seconds.
    2. `recentSpike` (priority 4): rapid rise exceeding standard baseline by $\ge 35\%$.
    3. `peak` (priority 3): maximum reached in the visible window.
    4. `trendVsAverage` (priority 2): delta relative to running window average.
    5. `quietStreak` (priority 1): prolonged low utilization / idle state.
  - Generates compact, actionable, diagnostic summaries with direction arrows and percentage deltas.
  - Zero heap allocations during steady-state sample analysis; pure function over `[ScalarPoint]`.

- `Sources/iStatsCore/PanelHeadline.swift`:
  - Category-specific diagnostic headline generator for all 8 categories (CPU, Memory, GPU, Thermal, Fan, Network, Disk, Power).
  - Strictly omits missing or nil fields without showing dummy placeholders or synthetic zeros.
  - Integrates with `MetricVerdict` so verdicts across the system consistently provide refined, expert headlines.

- `Sources/iStatsCore/Units.swift`:
  - Added public `formatBytesSI(_:precision:)` and `formatBytesIEC(_:precision:)` convenience helpers with unit tests.

- `Tests/iStatsCoreTests/InsightEngineTests.swift`:
  - 9 comprehensive unit tests verifying rule priorities, empty/insufficient window handling, spike detection, sustained load detection, and trend calculation.

- `Tests/iStatsCoreTests/PanelHeadlineTests.swift`:
