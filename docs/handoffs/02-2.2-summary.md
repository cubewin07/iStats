# Summary — 2.2 Load average and CPU frequency

## Done
- Enhanced data models in `Sources/iStatsCore/Models.swift`:
  - Added `LoadAverage` struct (`oneMinute`, `fiveMinute`, `fifteenMinute`).
  - Added `loadAverage: LoadAverage?` and `frequencyHz: UInt64?` to `CPUSample` struct, providing default `= nil` parameters in `init` to preserve complete backward compatibility.
- Added unit formatting helper in `Sources/iStatsCore/Units.swift`:
  - Added `Units.formatFrequencyHz(_ hz: UInt64, fractionDigits: Int = 2) -> String` supporting Hz, kHz, MHz, GHz, and THz formatting.
- Updated `iStats/Sampling/CPUSampler.swift`:
  - Extended `CPUInfoProvider` protocol to declare `func loadAverage() throws -> LoadAverage?` and `func cpuFrequencyHz() throws -> UInt64?`.
  - Added default extension implementation returning `nil` to preserve provider flexibility and compatibility.
  - Implemented `loadAverage()` in `HostProcessorInfoProvider` querying `sysctlbyname("vm.loadavg", ...)` and scaling with `load.fscale`.
  - Implemented `cpuFrequencyHz()` in `HostProcessorInfoProvider` querying `hw.cpufrequency` and `hw.cpufrequency_max` via `sysctlbyname`. Gracefully returns `nil` when unsupported (e.g. Apple Silicon, `ENOENT`/`ENOTSUP`) instead of returning a misleading zero (Requirement 1.3, 1.5).
  - Updated `CPUSampler.sample()` to query load average and CPU frequency and pass them to `calculateSample`.
  - Updated `CPUSampler.calculateSample` pure function to include `loadAverage` and `frequencyHz` in produced `CPUSample`.
- Unit and integration tests:
  - `Tests/iStatsCoreTests/ModelsTests.swift`: Added `testCPUSamplePropertiesAndEquality` (including load average and frequency) and `testLoadAverageEqualityAndCodable`.
  - `Tests/iStatsCoreTests/UnitsTests.swift`: Added `testFormatFrequencyHz`.
  - `Tests/iStatsTests/CPUSamplerTests.swift`: Updated `MockCPUInfoProvider` to support mock load averages & CPU frequencies, and updated `testLiveHostProcessorInfoProvider` to verify live load averages and CPU frequency on macOS.
- Verified test suites and build:

  - `xcodebuild test -scheme iStatsApp -destination 'platform=macOS'` — 6 passed (0 failures).
