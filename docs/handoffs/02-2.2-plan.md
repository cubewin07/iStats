# Plan — 2.2 Load average and CPU frequency

## Task
Implement system load average retrieval (1, 5, 15 minutes) via `sysctl vm.loadavg` and CPU frequency detection via `sysctl hw.cpufrequency*`, gracefully handling missing frequency (e.g. on Apple Silicon) by returning `nil` (Requirement 1.3, 1.5).

## Proposed Changes

### 1. `Sources/iStatsCore/Models.swift`
- Add `LoadAverage` struct (`oneMinute`, `fiveMinute`, `fifteenMinute`).
- Add `loadAverage: LoadAverage?` and `frequencyHz: UInt64?` to `CPUSample` with default `nil` arguments in `init`.

### 2. `Sources/iStatsCore/Units.swift`
- Add `Units.formatFrequencyHz(_ hz: UInt64, fractionDigits: Int = 2) -> String`.

### 3. `iStats/Sampling/CPUSampler.swift`
- Update `CPUInfoProvider` protocol to add `loadAverage() throws -> LoadAverage?` and `cpuFrequencyHz() throws -> UInt64?`.
- Implement `loadAverage()` and `cpuFrequencyHz()` in `HostProcessorInfoProvider`:
  - `loadAverage()`: Uses `sysctlbyname("vm.loadavg", &load, &size, nil, 0)` and scales by `load.fscale`.
  - `cpuFrequencyHz()`: Queries `hw.cpufrequency` and fallback `hw.cpufrequency_max`. If not found / `ENOENT`, returns `nil`.
- Update `CPUSampler.sample()` and `CPUSampler.calculateSample` to populate load average and frequency.

### 4. Tests
- `Tests/iStatsCoreTests/ModelsTests.swift`: Add tests for `LoadAverage` and `CPUSample` additions.
- `Tests/iStatsCoreTests/UnitsTests.swift`: Add tests for `Units.formatFrequencyHz`.
- `Tests/iStatsTests/CPUSamplerTests.swift`: Test mock provider with load average & frequency, and test live host provider.

### 5. Progress Tracking
- Update `docs/handoffs/02-2.2-summary.md` and `docs/progress.md`.
