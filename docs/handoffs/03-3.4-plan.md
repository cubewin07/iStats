# Plan — 3.4 Disk I/O throughput

## Goal
Implement disk read/write throughput (I/O) sampling using IOKit block storage driver statistics (`IOBlockStorageDriver`), calculating throughput and operations rates via pure `RateMath`, and gracefully degrading with `io: nil` if IOKit statistics are inaccessible without blocking mounted volume capacity reporting (Requirement 7.2).

## Proposed changes

1. **`iStats/Sampling/DiskSampler.swift`**:
   - Implement `diskIOCounters()` in `HostDiskInfoProvider` querying `IOBlockStorageDriver` services in the IOKit registry.
   - Aggregate `Bytes (Read)`, `Bytes (Write)`, `Operations (Read)`, and `Operations (Write)` across active drivers.
   - Define `DiskIOState` to store historical cumulative counters and timestamps.
   - Implement `calculateIOSample` to compute `bytesReadPerSec`, `bytesWrittenPerSec`, `readOpsPerSec`, and `writeOpsPerSec` using `RateMath`.
   - Ensure counter resets and zero/negative time steps are clamped to 0 without negative spikes or crashes.
   - Ensure `sample()` degrades gracefully when IOKit is inaccessible or throws, leaving `io = nil` while preserving volume capacity metrics.
2. **`Tests/iStatsTests/DiskSamplerTests.swift`**:
   - Add unit tests for initial sample zero rates.
   - Add unit tests for multi-second sample rate calculations (`bytesReadPerSec`, `bytesWrittenPerSec`, `readOpsPerSec`, `writeOpsPerSec`).
   - Add unit tests for counter-reset handling (clamped to 0).
   - Add unit tests for graceful degradation when I/O stats are unavailable or throwing.
   - Add unit tests for live host IOKit counters.
3. **`docs/progress.md`**:
   - Mark Task 3.4 done.
   - Update Next task to `3.5`.
