# Summary — 5.7 Validate vs Reference Tools + Write Phase 5 Report

## Done
- Executed live validation of Thermal, Fan, and GPU telemetry subsystems on host Apple Silicon hardware (Apple M4 Pro, 12 CPU cores, 16 GPU cores, macOS 15+ / 27.0):
  - **Thermal Monitoring (`ThermalSampler` & `HostThermalInfoProvider`)**:
    - Validated 20+ live sensor channels via AppleSMC (`Tp0T`, `Tp01`..`Tp0k`, `Te05`, `Te0S`, `Tg05`, `Tg0S`, `TCHP`, `TCMb`, `TCMz`, `TB0T`..`TB2T`, `TD00`..`TD04`, `Ts0P`).
    - Verified physical plausibility bounds ($0.0^\circ\text{C} < T < 110.0^\circ\text{C}$).
    - Verified dynamic °C and °F unit conversions matching `Units.formatTemperature`.
    - Cross-validated system thermal pressure state (`nominal`) with `ProcessInfo.processInfo.thermalState` and `pmset -g therm` (100% agreement).
  - **Cooling & Fans (`FanSampler` & `HostFanInfoProvider`)**:
    - Verified active fan count ($2\text{ fans}$ on MacBook Pro).
    - Verified fan rotational readings ($0\text{ RPM}$ idle during passive firmware cooling) and min/max hardware bounds ($2317\dots 7826\text{ RPM}$).
    - Validated fan control policy (`"System Controlled"`, zero root escalation, safety bounds clamping).
  - **GPU Telemetry (`GPUSampler` & `HostGPUInfoProvider`)**:
    - Verified IOKit `IOAccelerator` (`AGXAccelerator`) performance statistics dictionary extraction.
    - Verified GPU device identifier (`Apple M4 Pro`).
    - Verified unified memory in use ($612.86\text{ MiB} = 642,629,632\text{ bytes}$) and GPU temperature ($55.9^\circ\text{C}$).
    - Verified non-negative power draw handling and dynamic unmetered gating.
