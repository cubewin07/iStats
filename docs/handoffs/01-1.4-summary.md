# Summary — 1.4 Implement the SampleScheduler

## Done
- Implemented `SampleScheduler.swift` in `Sources/iStatsCore/`:
  - `AnySampler`: Type-erased `Sendable` wrapper for any `Sampler` conforming type or standalone closure.
  - `MetricReading`: Unified enum wrapping all 8 category samples (`.cpu`, `.memory`, `.thermal`, `.fan`, `.gpu`, `.network`, `.disk`, `.power`) and `.unavailable(category:reason:timestamp:)` with `category`, `timestamp`, and `availability` accessors.
  - `actor SampleScheduler`:
    - Background task loops per registered and enabled category (Requirement 12.1, ADR 0002).
    - Error and timeout isolation per sampler via `withThrowingTaskGroup` racing against `timeBudget` (Requirement 12.3).
    - Per-category interval configuration with immediate restart on interval change to reduce wake frequency (Requirement 12.4).
    - Multiple delivery mechanisms: `nonisolated var stream: AsyncStream<MetricReading>`, `onSample`, and `onMainActorSample`.
    - Lifecycle controls: `start()`, `stop()`, `register()`, `unregister()`, `setEnabled()`, `sampleOnce()`, `sampleAll()`.
- Implemented comprehensive test suite in `Tests/iStatsCoreTests/SampleSchedulerTests.swift`:
  - `testRegistrationAndCategoryManagement`: Tests registration and unregistration.
  - `testSamplingRunsOffMainThread`: Proves `Thread.isMainThread == false` during sampling (Requirement 12.1).
  - `testSampleOnceAndSampleAll`: Tests direct sampling and value wrapping.
  - `testErrorIsolation`: Proves a thrown error (`SamplerError.unsupported`) is isolated to that category without affecting others (Requirement 12.3).
  - `testTimeoutIsolation`: Proves a slow/hanging sampler times out cleanly and surfaces as `.unavailable` without blocking others (Requirement 12.3).
  - `testAsyncStreamPublishing`: Tests multi-consumer `AsyncStream` subscription and live sample delivery.
  - `testDynamicIntervalAdjustment`: Proves updating sampling interval alters timer frequency (Requirement 12.4).
  - `testCategoryEnablementToggling`: Proves enabling/disabling categories stops and resumes tasks properly.
  - `testStartStopLifecycle`: Proves clean start, stop, and task cancellation.
  - `testOnSampleCallbacks`: Proves execution of general and `@MainActor` callbacks.
  - `testMetricReadingPropertiesAndWrapping`: Tests all properties and wrapping logic across all categories.
- Verified test suite: all 55 unit tests pass (`swift test --scratch-path /tmp/istats-build`).
- Verified app target build: `xcodebuild -scheme iStatsApp -configuration Debug build` succeeded.
