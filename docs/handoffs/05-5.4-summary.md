# Summary — 5.4 ADR 0004 + Opt-in Fan Control Policy & Read-Only Safety Posture

## Done
- Authored and accepted **ADR 0004** (`docs/architecture/adr/0004-privilege-and-fan-control.md`) addressing Requirements 4.1, 4.2, 4.3, 4.4, 13.1, and 13.2:
  - Documented the technical mechanics of SMC fan control on Apple Silicon and Intel hardware.
  - Analyzed the thermal safety hazards of manual fan overrides (disrupting closed-loop PMU thermal PID curves, risks of thermal throttling degradation, component stress, and emergency shutdown).
  - Evaluated privilege architectures (unprivileged IOKit reads vs root `launchd`/`SMAppService` helper daemons) and rejected root daemons to eliminate Local Privilege Escalation (LPE) attack surfaces.
  - Formally accepted the **Strict Read-Only Monitoring Posture with Zero Privilege Escalation**.
- Implemented pure domain fan control modes, safety bounds, error types, and policy models in `Sources/iStatsCore/Models.swift`:
  - `FanControlMode` (`.systemAutomatic`, `.manual(targetRPM: Int)`, `.unsupported`).
  - `FanSafetyError` (`.targetBelowMinimum`, `.targetAboveMaximum`, `.boundsUnavailable`, `.invalidBounds`).
  - `FanSafetyBounds.clamp(targetRPM:minRPM:maxRPM:)` strictly clamping target speeds within hardware bounds to prevent under-cooling (clamping below minRPM) and bearing wear (clamping above maxRPM).
  - `FanSafetyBounds.validate(targetRPM:minRPM:maxRPM:)` returning strong validation results.
  - `FanControlPolicy` defining default mode (`.systemAutomatic`), UI status label (`"System Controlled"`), and educational user explanations.
  - `FanSample.isFanless` boolean property.
- Enhanced `FanSummaryView.swift` in `iStats/UI/`:
  - Added a `"System Controlled"` status badge (`checkmark.shield` icon) in the header for machines with cooling fans.
  - Added a clear explanatory note in the view footer communicating that fan speeds are automatically regulated by macOS system firmware to protect thermal safety and hardware longevity (Requirements 4.3, 4.4).
- Added comprehensive unit test suites in `Tests/iStatsCoreTests/FanSafetyBoundsTests.swift` and `Tests/iStatsTests/FanSamplerTests.swift`:
  - Tested clamping below min, above max, within bounds, with nil bounds, inverted bounds, and negative targets.
  - Tested validation logic for boundary violations and missing bounds.
  - Tested `FanControlMode` enum cases and JSON Codable serialization.
  - Tested `FanControlPolicy` text constants and UI rendering in SwiftUI.
