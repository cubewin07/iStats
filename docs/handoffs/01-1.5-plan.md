# Plan — 1.5 Implement the MetricsStore Ring Buffer

## Context
Implement `MetricsStore` in `iStatsCore` as an in-memory, fixed-capacity ring buffer store per metric category holding rolling history for the detail-view graphs and live inspection (Requirement 10.2). Keep it pure, non-persisted, and `Sendable` in accordance with ADR 0006.

## Objectives
1. Enhance `RingBuffer` with `clear()` and `Equatable` conformance.
2. Implement `MetricsStore`:
   - Fixed-capacity ring buffer per `MetricCategory` (`RingBuffer<MetricReading>`).
   - Configurable default and per-category capacities.
   - Appending individual and batch readings, as well as `record` and `recordUnavailable` helpers.
   - Chronological querying (`readings(for:)`, `latest(for:)`, `count(for:)`, `capacity(for:)`, `isEmpty(for:)`, `isFull(for:)`, `subscript(category:)`).
   - Typed extractors and history filters (`latestCPU()`, `latestMemory()`, `cpuHistory()`, `memoryHistory()`, etc.).
   - Resetting/clearing support (`clear(category:)`, `clearAll()`).
3. Add unit tests for `RingBuffer` additions and complete `MetricsStore` functionality (capacity, FIFO eviction order, multi-category isolation, unavailable filtering, and equality).
4. Update progress and on-disk tracking.
