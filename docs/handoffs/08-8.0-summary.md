# Summary — 8.0 ADR 0009 "Instrument" Design Language & API Spike

## Done
- **Step 8.0.1 — API Spike Executed on Xcode 27.0 / Swift 6.4 macOS SDK**:
  - `View.glassEffect(_:in:)`: Confirmed available (`macOS 26.0+`, iOS 26.0+), signature `nonisolated public func glassEffect(_ glass: Glass = .regular, in shape: some Shape = DefaultGlassEffectShape()) -> some View`.
  - `GlassEffectContainer`: Confirmed available (`macOS 26.0+`), signature `public struct GlassEffectContainer<Content: View>: View`, `init(spacing: CGFloat? = nil, @ViewBuilder content: () -> Content)`. Matching AppKit primitives `NSGlassEffectView` and `NSGlassEffectContainerView` verified.
  - `contentTransition(.numericText(value:))`: Confirmed available (`macOS 14.0+`), supporting both `value: Double` and `countsDown: Bool`.
  - `symbolEffect(...)`: Confirmed available (`macOS 14.0+`), supporting discrete and indefinite animations.
  - `sensoryFeedback(...)`: Confirmed available (`macOS 14.0+`), for view-triggered haptics.
  - `pointerStyle(...)`: Confirmed available (`macOS 15.0+`), supporting `.link`, `.grabIdle`, `.columnResize`, etc., without cursor stack imbalance.
  - `NSPanel` with `[.borderless, .nonactivatingPanel]`: Confirmed that subclassing `NSPanel` and overriding `canBecomeKey = true` allows borderless panels to become key windows and receive `keyDown` (`Esc`) and `performKeyEquivalent` (`⌘1–3`) in an `LSUIElement` accessory app.
