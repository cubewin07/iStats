# Summary — 5.3 Implement FanSampler (read-only)

## Done
- Implemented `FanSampler` and `FanInfoProvider` protocol in `iStats/Sampling/FanSampler.swift` (Requirements 4.1, 4.2, 4.4, ADR 0003, ADR 0004):
  - Abstract `FanInfoProvider` protocol with methods `fanCount() throws -> Int` and `fans() throws -> [FanReading]`.
  - Concrete `HostFanInfoProvider` reading physical fan speeds and hardware limits from `AppleSMC` IOKit user client (`IOServiceMatching("AppleSMC")`) using Darwin 80-byte `SMCParamStruct`.
  - Reads `FNum` for active fan count (supporting 0 to 16 fans).
  - Iterates per-fan keys: `F\(i)Ac` for actual RPM, `F\(i)Mn` for minimum RPM bounds, `F\(i)Mx` for maximum RPM bounds, and `F\(i)ID` for fan hardware descriptors (with fallback to "Left Fan", "Right Fan", or "Fan N").
  - Multi-tier key decoding for Apple Silicon (`flt ` 32-bit Float) and Intel (`sp78` 8.8 fixed-point, `fpe2` 14.2 fixed-point, `ui16`, `ui8 `).
  - Clean fanless system handling: MacBook Air and fanless desktop configurations return empty `fans: []` cleanly without throwing errors or crashing.
  - Strict value clamping and validation in `calculateSample` (non-negative RPM and non-negative bounds).
- Added rotational speed formatting helpers to `Sources/iStatsCore/Units.swift`:
  - `Units.formatRPM(_ rpm: Int) -> String` (e.g., `"1,850 RPM"`).
  - `Units.formatFanBounds(min: Int?, max: Int?) -> String?` (e.g., `"1,200 RPM – 5,500 RPM"`).
- Created `FanSummaryView.swift` in `iStats/UI/`:
  - Header with fan icon, "Fans & Cooling", and fan count or "Fanless" badge.
  - Primary fan RPM prominently displayed with peak fan indicator for multi-fan systems.
  - Sparkline rolling history graph using `RollingGraphView`.
  - Per-fan rows with speed gauge bars showing proportion within hardware `[minRPM, maxRPM]` bounds.
  - Informative "Passive Cooling" badge when running on a fanless Mac.
- Integrated `FanSampler` into `MetricsCoordinator.swift` and `DetailPopoverView.swift`:
  - Registered `FanSampler()` in background scheduler.
  - Exposed `@Published latestFan` and `@Published fanHistory`.
  - Routed `.fan` reading dispatch.
  - Added `FanSummaryView` to `DetailPopoverView` conditioned on `preferences.isCategoryEnabled(.fan)`.
- Added comprehensive unit and hardware tests in `Tests/iStatsTests/FanSamplerTests.swift` and `Tests/iStatsCoreTests/UnitsTests.swift`:
  - Dual-fan, single-fan, fanless, and corrupt/negative bound handling tests.
  - Live hardware tests querying host AppleSMC (verified 2 fans on host Apple Silicon hardware).
  - SwiftUI view rendering tests for active fans, fanless state, and `DetailPopoverView`.
