## Summary of Changes
1. **`ChartScrubState` & Environment Propagation (`iStats/UI/Instrument/LiveChart.swift`)**
   - Added `ChartScrubState: Equatable, Sendable` with nested `SecondaryReadout: Equatable, Sendable` (`text`, `unit`, `color`, `label`), `formattedPrimary`, `primaryUnit`, `primaryLabel`, `relativeTimeText`, `clockTimeText`, `headlineText`, and pure helpers `splitFormattedValue`, `formatRelativeTime`, `formatClockTime`, and `make(...)`.
   - Added `ChartScrubAction` and `EnvironmentValues.chartScrubAction` so both hero `LiveChart` and `HistoryPage` charts can publish scrub updates to the enclosing `PanelScaffold` without coupling to `PageSwitcher` or `StatusRibbon`.
   - Updated `ScrubController` (`ResolvedTarget.timestamp`, `readoutValueForIndex`, `onScrubState`, `shouldDispatch`) and `LiveChart` (`.onScrubStateChange`, `.onChange(of: scrubIndex)`, `.onDisappear`) to emit and clear `ChartScrubState` cleanly.

2. **Crosshair v2 (`iStats/UI/Instrument/LiveChart.swift`)**
   - Removed the floating `RoundedRectangle` tooltip/callout pill from `LiveChart.crosshairOverlay`.
   - Rendered a `1 pt` vertical hairline with `6 pt` top/bottom alpha fades and a `6 pt` snapped bead (`1.5 pt` `Instrument.Surface.panel` cutout stroke, B11) on each active series at the interpolated Y value (`ChartTimeline.interpolateValue`) under the cursor.
   - Added fast spring smoothing (`.spring(response: 0.12, dampingFraction: 0.9)` when `motionPolicy == .full`) for horizontal crosshair X movement.

3. **Glance Header Scrub Integration & Insight Caption Placement (`iStats/UI/Panels/PanelScaffold.swift`)**
   - Added `scrubState` (`@State` + optional `Binding<ChartScrubState?>?`) with `activeScrubSourceID` race guard and injected `\.chartScrubAction`.
   - When `activeScrubState != nil`, the Glance numeral (`scrubValueDisplay`) renders the scrubbed primary (and dual-ticker secondary when present) value while `scrubHeadline` renders `"<relativeTimeText> · <clockTimeText>"` with a subtle `Color.secondary.opacity(0.12)` highlight and `monospacedDigit()`; releasing hover restores live telemetry.
   - Moved `glance.insight` into a dedicated `11 pt` (`Instrument.Typography.caption`) row (`insightCaptionRow`) directly below `chartZone` (collapsed on `.history`, loading, and `.unavailable`).
   - Preserved `PanelStackLayout`, single `ScrollView`, and `PanelContentHeightKey` invariants; added internal `PanelScaffoldProbeKey` (gated behind `\.panelScaffoldProbeEnabled`, default `false`).

4. **Tests (`Tests/iStatsTests/PanelScaffoldTests.swift`)**
