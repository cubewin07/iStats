# Summary — 2.4 Implement MemorySampler

## Done
- Enhanced `MemorySample` model in `Sources/iStatsCore/Models.swift` with optional detailed breakdown fields (`appMemory`, `active`, `inactive`, `swapTotal`, `swapFree`) while maintaining complete backward compatibility.
- Implemented `iStats/Sampling/MemorySampler.swift`:
  - `RawVMStatistics`: Page counts model (`free`, `active`, `inactive`, `wire`, `compressed`, `purgeable`, `external`, `internal`).
  - `SwapUsageData`: Total, used, and free swap memory in bytes.
  - `MemoryInfoProvider`: Abstract protocol for testable virtual memory, swap, physical RAM, and pressure querying.
  - `HostMemoryInfoProvider`: Darwin Mach and sysctl implementation using `host_statistics64(HOST_VM_INFO64)`, `host_page_size`, `sysctl hw.memsize`, `sysctl vm.swapusage`, and `sysctl kern.memorystatus_vm_pressure_level`.
  - `MemorySampler`: Conforms to `Sampler` (category `.memory`).
  - `calculateSample`: Pure static function applying macOS Activity Monitor standard memory breakdown (App Memory = internal - purgeable, Memory Used = App Memory + Wired + Compressed, Cached Files = Purgeable + External, Free = Free pages * page size).
- Added comprehensive unit and live verification tests in `Tests/iStatsTests/MemorySamplerTests.swift`:
  - Mock provider tests for 16KB Apple Silicon page sizes and 4KB Intel page sizes.
  - Edge case testing for purgeable >= internal.
  - Swap usage reporting.
  - Pressure level mappings.
  - Error isolation and throwing of `SamplerError.systemCallFailed` upon Mach or sysctl failures.
  - Live system integration assertions checking agreement with `ProcessInfo.processInfo.physicalMemory`.
- Updated Xcode project `iStats.xcodeproj/project.pbxproj` with file references and build phases for `MemorySampler.swift` and `MemorySamplerTests.swift`.
