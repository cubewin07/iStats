# Summary — 8.5.3 `LiveChart` v3 (Time-Domain Renderer, Independent Mirrored Scales, Dark-Mode Bloom)

## Done
- **Step 8.5.3.1 — `LiveChartMode` Time-Domain Upgrade (`iStats/UI/Instrument/LiveChart.swift`):**
  - Converted `LiveChartMode` into a `Sendable` struct with time-domain factories (`.single(points:)`, `.stacked(points:)`, `.mirrored(points:)`, `.banded(points:)`, `.envelope(buckets:)`, `.mirroredEnvelope(top:bottom:)`) supporting `[ChartPoint]`, `[DualChartPoint]`, `[BucketPoint]`, `domainFloor`, and `ChartBand` thresholds.
  - Preserved backward-compatible `[Double]` convenience factories (`.single(values:)`, `.stacked(primary:secondary:)`, `.mirrored(top:bottom:)`, `.banded(values:)`) so all existing panels, previews, and tests compile without modification.
- **Step 8.5.3.2 — Time-Domain Engine (`ChartModel`, `ChartRenderer`, `ScrubController`):**
  - Replaced the old `truncatingRemainder` + last-point vertical interpolation code with `ChartModel` wrapping `ChartTimeline` and `ChartScaleState` (`topScale` / `bottomScale`).
  - Driven `ChartTimeline` by sample timestamps rather than value changes, eliminating B7's flat-series twitch/snap-back and A1/A2/A3/A5/A7 glide/wobble artifacts while keeping partial buffers unstretched.
  - Collapsed the four duplicate series renderers into `ChartRenderer`'s shared Fritsch–Carlson path builder (`buildSeriesGeometry`, `buildEnvelopePolygon`, `drawSeries`, `drawHeadBead`).
  - Rendered the `6 pt` calm head bead with a `2 pt` `Instrument.Surface.panel` cutout halo and removed the looping 60 fps radar pulse ring (A8).
  - Throttled `TimelineView` to `1/60 s` for key/transient panels and `1/30 s` for pinned non-key panels (`LiveChart.frameInterval(isPinnedNonKey:)`), pausing ticks when `motionPolicy != .full` or scrubbing.
- **Step 8.5.3.3 — Independent Mirrored Scales (`.mirrored`, `.mirroredEnvelope`):**
  - Maintained independent `topScale` and `bottomScale` (`ChartScaleState`) for `.mirrored` and `.mirroredEnvelope`, rendering left-gutter ceiling labels (`↓ ...`, `↑ ...`) in `9.5 pt` tabular text.
- **Step 8.5.3.4 — Visual Polish & Crosshair Compatibility:**
  - Upgraded primary stroke to `1.75 pt` round-joined with Dark Mode underlay bloom (`5.0 pt` at `16%` opacity + `3.0 pt` blur when `colorScheme == .dark && colorSchemeContrast == .standard`), `20% → 0%` vertical area fill over `85%` of plot height, and a `20 pt` leading fade-in mask applied strictly to series layers so left-gutter labels stay crisp.
  - Added 3 solid `0.5 pt` hairlines (`Color.primary.opacity(0.06)`) with left-gutter axis labels (`2 pt` above interior lines, clamped at top ceiling), `3%` threshold zone washes + vertical stroke gradient shading in `.banded` mode, and `min...max` envelope polygons (`14%` tint) under `mean` strokes for `[BucketPoint]`.
  - Added `ScrubController` for time-domain hover resolution and replaced hardcoded white crosshair dot rings with `Instrument.Surface.panel` (B11), keeping existing `onScrub` / `scrubIndex` behavior compatible for Task 8.5.4.
- **Unit & Render Tests (`Tests/iStatsTests/SwiftUIViewsTests.swift`):**
  - Added 5 tests (`testLiveChartV3TimeDomainAndEnvelopeRenderModes`, `testLiveChartFlatSeriesTimelineDoesNotTwitchB7`, `testLiveChartIndependentMirroredScalesAndPartialBufferProjection`, `testLiveChartEnvelopePolygonAndFrameIntervalThrottling`, `testLiveChartScrubControllerTimeDomainResolution`).
