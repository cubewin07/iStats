## Done
- **Name collision resolved (`iStats/App/AlertCoordinator.swift`)**:
  - Renamed the app-target `struct AlertEvaluator` to `AlertMessageBuilder` (emoji-free alert titles/bodies) and updated `AlertCoordinatorTests` and `SettingsWindowTests`.

- **Core sustained alerts engine (`Sources/iStatsCore/AlertEvaluator.swift`)**:
  - Added pure value types `AlertDecision` (`.none`, `.fire`, `.clear`), `AlertRuleState` (`pendingSince`, `lastFired`, `armed`), and `AlertEvaluator` with `mutating func evaluate(rule: AlertRule, value: Double?, now: Date) -> AlertDecision`.
  - Enforces continuous sustain duration (`sustainSeconds`), repeat suppression (`cooldownSeconds`), hysteresis re-arming (5% of threshold or 2 °C for `.temperature`), pending-state reset on unavailable (`nil` / non-finite) readings, and safe timestamp clamping on backwards clock jumps.

- **Removed legacy alert keys/properties (`Sources/iStatsCore/PreferencesStore.swift`, `Sources/iStatsCore/PreferencesMigration.swift`)**:
  - Moved `LegacyAlertKeys` into `PreferencesMigration` so v1 → v2 migration continues reading the raw legacy string keys directly from `UserDefaults`.
  - Removed the legacy computed alert bridge properties (`cpuAlertEnabled` … `alertCooldownInterval`) from `PreferencesStore`, added `alertRule(for:)`, `setAlertRule(_:)`, `updateAlertRule(_:_:)`, and `defaultAlertCooldownSeconds`, and updated callers and tests.
