# Summary — 2.1 Implement CPUSampler (total + per-core)

## Done
- Enhanced `RateMath` in `Sources/iStatsCore/RateMath.swift`:
  - Added `counterDelta(previous: UInt64, current: UInt64) -> UInt64` helper to standardize counter diffing across all samplers with counter wrap/reset protection (Invariant 3).
  - Updated `bytesPerSecond` to use `counterDelta`.
- Created `CPUSampler` in `iStats/Sampling/CPUSampler.swift`:
  - Defined `ProcessorTicks` struct holding per-core `user`, `system`, `idle`, and `nice` tick counts.
  - Defined `CPUInfoProvider` protocol enabling full dependency injection for deterministic unit and property testing.
  - Implemented `HostProcessorInfoProvider` invoking Darwin Mach `host_processor_info(mach_host_self(), PROCESSOR_CPU_LOAD_INFO, ...)`.
  - Enforced kernel call validation (`kern_return_t == KERN_SUCCESS`, non-null pointers, count bounds) and guaranteed Mach VM deallocation (`defer { vm_deallocate(...) }`).
  - Implemented `final class CPUSampler: Sampler, @unchecked Sendable` conforming to `Sampler` (`Output = CPUSample`, `category = .cpu`).
  - Thread-safe state tracking (`NSLock`) storing previous tick snapshot.
  - Implemented pure rate math in `CPUSampler.calculateSample` returning aggregate %, per-core % array, user %, system % (including nice), and idle %.
  - Handled first-sample initialization (graceful cold-start with 0%) and counter wraps/topology changes.
- Added unit tests:
  - `Tests/iStatsCoreTests/RateMathTests.swift`: Added test cases for `counterDelta` (normal, counter reset/wrap, and identical values).
  - `Tests/iStatsTests/CPUSamplerTests.swift`: Added 6 comprehensive test cases covering cold-start zero utilization, multi-core rate calculation with synthetic ticks, counter wrap protection, core topology change tolerance, error propagation on system call failure, and live host sampling on macOS.
- Updated Xcode Project & Schemes:
  - Added `Sampling` group and `CPUSampler.swift` to `iStats` app target.
  - Configured `iStatsTests` unit test bundle target in `iStats.xcodeproj` and updated shared schemes.
- Verified test suites and build:

  - `xcodebuild test -scheme iStatsApp -destination 'platform=macOS'` — 6 passed (0 failures).
