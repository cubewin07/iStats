# Summary — 5.2 Implement ThermalSampler

## Done
- Implemented `ThermalSampler` and `ThermalInfoProvider` protocol in `iStats/Sampling/ThermalSampler.swift` (Requirements 3.1, 3.2, 3.3, 3.4, 11.3, ADR 0003):
  - Abstract `ThermalInfoProvider` protocol with methods `thermalSensors() throws -> [SensorReading]` and `thermalPressure() throws -> ThermalPressure?`.
  - Concrete `HostThermalInfoProvider` reading thermal sensors via `AppleSMC` IOKit service with C-compatible 80-byte `SMCParamStruct` and `ProcessInfo.processInfo.thermalState` for system thermal pressure.
  - Multi-tier key decoding for `flt ` (32-bit float), `sp78` (16-bit fixed point 8.8), `fpe2` (14.2), `ui8 `, and `ui16`.
  - Maps raw keys to human-friendly labels: CPU Package/Cores (`Tp0T`, `Tp01`..`0k`), Efficiency Cores (`Te05`, `Te0S`), GPU Clusters (`Tg05`, `Tg0S`), Memory Modules (`TCMb`, `TCMz`), Chipset/SoC (`TCHP`), Battery Gas Gauge (`TB0T`..`TB2T`), Die Arrays (`TD00`..`TD07`), and Intel fallbacks (`TC0P`, `TG0P`, `TM0P`, `Th0H`, `Ts0P`).
  - Strict physical range filtering (`0.0°C < temp < 150.0°C`) to filter invalid or unpopulated hardware channels.
  - Graceful resilience: missing sensors or hardware faults degrade cleanly without crashing (throw `SamplerError.unsupported` / `systemCallFailed` for `SampleScheduler` to surface `.unavailable`).
- Added temperature unit conversion and formatting helpers to `Sources/iStatsCore/Units.swift`:
  - `Units.formatTemperature(_ celsius: Double, unit: TemperatureUnit, fractionDigits: Int) -> String`
  - `Units.formatTemperatureSensor(_ sensor: SensorReading, unit: TemperatureUnit, fractionDigits: Int) -> String`
- Enhanced `ThermalPressure` enum in `Sources/iStatsCore/Models.swift` with `displayName`, `isElevated`, `severityRank`, and `Comparable` (`<`) conformance.
- Created `ThermalSummaryView.swift` in `iStats/UI/`:
  - Thermal pressure status badge with color indication (Nominal / Fair / Serious / Critical).
  - Primary sensor temperature in prominent typography with peak sensor indicator.
  - Sparkline rolling history graph using `RollingGraphView`.
  - Expandable sensor list showing all live sensors with mini visual temperature bars and dynamic °C/°F formatting tied to `PreferencesStore.temperatureUnit`.
  - Clean degraded state handling when hardware sensors are unavailable.
- Integrated `ThermalSampler` into `MetricsCoordinator.swift` and `DetailPopoverView.swift`:
  - Registered `ThermalSampler()` in background scheduler.
  - Exposed `@Published latestThermal` and `@Published thermalHistory`.
  - Routed `.thermal` reading dispatch.
