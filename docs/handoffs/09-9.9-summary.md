# Summary — 9.9 Settings Shell

## Done
- **Core (`Sources/iStatsCore/`)**:
  - `SettingsSection` (`Hashable, Sendable, Identifiable`): `.general`, `.appearance`, `.menuBar`, `.category(MetricCategory)` (all 8), `.notifications`, `.about`. Supports `storageKey` / `init?(storageKey:)` with `"alerts"` aliased to `.notifications`, `resolved(storageKey:)` falling back to `.general` on nil/unknown keys, `groups(hasBattery:activeCategories:)` and `allSections(hasBattery:activeCategories:)`, `title(hasBattery:)`, `symbolName(hasBattery:)`, and notification constants `SettingsSection.openNotificationName` (`"iStats.openSettingsSection"`) / `deepLinkUserInfoKey` (`"section"`) / `showWelcomeNotificationName` (`"iStats.showWelcomeAgain"`).
  - `TemperatureThresholdScale`: converts the thermal alert slider between display units (`°C`: `60...105` step `5`; `°F`: `140...220` step `10`) and the stored Celsius threshold (`AlertKind.temperature.thresholdRange`).
  - `DiagnosticsReport`: pure report builder containing app version/build, `hw.model` + architecture (via `sysctlbyname`, called off-main-thread), macOS version, and per-sampler `Availability` — zero telemetry values.
- **Single Window Path (`iStats/App/`)**:
  - `PreferencesWindowController`: retains the single `NSWindow` (`"iStats Settings"`, `frameAutosaveName: "iStatsSettingsWindowV1"`), preserves `showPreferences()`, adds `show(section: SettingsSection?)`, persists selection via `PreferencesStore.lastSettingsSection`, and observes `Notification.Name("iStats.openSettingsSection")` (`userInfo["section"] as? String`) to navigate and bring the window front.
  - `AppDelegate`: initializes `PreferencesWindowController.shared` on launch so deep links work before the window has been opened.
  - `iStatsApp.swift`: replaced the live `Settings { PreferencesView(...) }` body with `SettingsSceneForwarder` and `CommandGroup(replacing: .appSettings)` forwarding `⌘,` to `PreferencesWindowController.shared.showPreferences()`.
- **Settings UI (`iStats/UI/Settings/` & `iStats/UI/`)**:
  - `SettingsView` + `SettingsNavigationModel` + `SettingsSidebar`: `NavigationSplitView` (`.navigationSplitViewStyle(.balanced)`) with `List(selection:)` across 3 groups (General/Appearance/Menu Bar, 8 category pages using `CategoryIdentity`, Notifications/About).
  - `GeneralSettingsPage`: native grouped `Form` for launch at login, Dock icon, pause sampling, Low Power Mode auto-pause, refresh interval, units, and reset defaults confirmation.
  - `AppearanceSettingsPage`: native grouped `Form` for `menuBarAppearance`, `lastPanelDestination` start page, and macOS Reduce Motion / Reduce Transparency status + Accessibility Settings link.
  - `CategorySettingsPage`: placeholder per-category `Form` page (for 9.10) with category toggle and sampler availability status.
  - `NotificationsSettingsPage` + `PreferencesAlertsPane`: separates `store.notificationsEnabled` from `UNUserNotificationCenter` authorization state, shows inline `"Open System Settings"` banner when denied (or `"Allow Notifications"` when `.notDetermined`), exposes default cooldown and `"Send Test Alert"`, embeds `PreferencesAlertsPane` threshold rows with `TemperatureThresholdScale` `°F` conversion, and removes all emoji from `AlertCoordinator` alert titles.
  - `AboutSettingsPage`: bundle app icon, version/build, GitHub/issues links, acknowledgements, off-main-thread **Copy Diagnostics**, `"Show Welcome Again"` hook (`SettingsSection.showWelcomeNotificationName`), and no fake `"Verified"` pill.
  - Removed legacy `PreferencesView.swift`, `PreferencesGeneralPane.swift`, `PreferencesAboutPane.swift`, and `PreferencesSection` enum (and zero-opacity shortcut buttons); added accessibility labels to switches in Settings and hosted panes.
