## 1. What was built

Implemented the unified shell for the Instrument redesign (ADR 0009 / Task 8.6), composing zones ① through ⑤, states, keyboard navigation, and factory routing:

- `iStats/UI/Panels/PageSwitcher.swift`:
  - 22×22 icon buttons with a sliding glass puck animated via `matchedGeometryEffect`.
  - SF Symbol icon mapping for `.overview`, `.detail` (category-specific), and `.history`.
  - Tooltips with titles from `PopoverTab.title(for: category)`.

- `iStats/UI/Panels/StatusRibbon.swift`:
  - Severity-tinted alert strip displayed only when `status >= .elevated` or sampling is paused.
  - Smooth asymmetric height transition (`.opacity.combined(with: .move(edge: .top))`).
  - Supports optional action buttons (e.g. "Resume").

- `iStats/UI/Panels/PanelScaffold.swift`:
  - Full composition of all 5 zones:
    - **Zone ① Eyebrow:** category glyph + tracked uppercase title, `PageSwitcher`, context utility menu (Activity Monitor, Network/Storage/Battery settings, pause/resume, preferences), pin/unpin toggle button.
    - **Zone ② Glance:** display numeral (`LiveNumber` rolling digits, 44 pt), unit (`Type.unit`, 17 pt), dual ticker support (Network ↓ / ↑), headline (`PanelHeadline`), trailing top-aligned insight (`InsightEngine`) or live scrub lens readout.
    - **Zone ③ Living Chart:** full-bleed `LiveChart` spanning the full 352 pt panel width (via `-Instrument.Space.xl` negative padding), interactive scrub lens callback feeding Zone ②.
    - **Zone ④ Status Ribbon:** height-eased alert strip.
    - **Zone ⑤ Page Body:** directional transition between pages; `.overview` fits content without scrolling; `.detail` and `.history` scroll when content exceeds limits.
  - Comprehensive states: loading ghost (`--` quaternary numeral, no skeleton shimmer), unavailable (`—` numeral, headline reason, `InsetEmptyState` card), paused/low-power (ribbon + frozen/desaturated chart), detached/pinned.
  - Dual-layer keyboard navigation:
    - macOS 13+ support via `MetricPanel.keyDown` intercepting `Esc`, `⌘1–3`, `←/→`, `Space`, `⌘P`, `⌘,`, `⌘W` and broadcasting `PanelCommand`.
    - `PanelScaffold` listens to `NotificationCenter.default.publisher(for: .panelCommandReceived)` and animates page changes with `Motion.snappy`.

- `iStats/UI/Panels/PanelFactory.swift`:
  - Modern replacement for `PopoverFactory` routing all 8 categories (CPU, Memory, GPU, Thermal, Fan, Network, Disk, Power) to `PanelScaffold` via `PanelHostView`.
  - Wires `MetricsCoordinator` live samples, `InsightEngine` telemetry insights, `PanelHeadline` copy, and `LiveChart` data modes.

- `iStats/App/MenuBarController.swift`:
  - Updated `makePanelContentView(forConfigId:)` to call `PanelFactory.makePanelView(...)`.

- `Tests/iStatsTests/PanelScaffoldTests.swift`:
  - Unit tests verifying rendering of all 8 categories at 352 pt width, `PageSwitcher` tab titles and icons, `StatusRibbon` visual thresholds, unavailable states, and `PanelCommand` notification dispatch.
