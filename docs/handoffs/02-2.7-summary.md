# Summary — 2.7 Validate vs Reference Tools + Phase 2 Report

## Done
- Executed comprehensive live metric validation on Apple Silicon hardware (Apple M4 Pro, 12 cores, 24 GiB RAM, macOS 14+) comparing `CPUSampler` and `MemorySampler` against native macOS reference tools (`top`, `uptime`, `vm_stat`, `sysctl vm.swapusage`, `sysctl hw.memsize`):
