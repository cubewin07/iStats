# Summary — 8.5.1 Pure Chart Math v3 (`ChartTimeline`, `ChartScale`, `Downsampler.alignedBuckets`)

## Done
- **Step 8.5.1.1 — Time-Domain Coordinates & Delayed Edge (`Sources/iStatsCore/LiveChartMath.swift`):**
  - Added `ChartPoint(timestamp:value:)` (plus `init(scalarPoint:)`) and `DualChartPoint(timestamp:primary:secondary:)`.
  - Implemented `ChartTimeline` with `edge`, `frozenEdge`, `sampleInterval`:
    - `targetEdge(now:latestTimestamp:)` returns `min(now - sampleInterval, latestTimestamp)`.
    - `step(now:latestTimestamp:dt:isScrubbing:)` freezes `edge` at `frozenEdge` while scrubbing (A7), snaps immediately if `abs(targetEdge - edge) > 3.0 * sampleInterval` (wake-from-sleep), and otherwise advances monotonically at `1.0 s/s` (never moving backward on late samples, A1, and advancing cleanly on flat series via wall-clock timestamps, B7) with a `250 ms` cubic ease-out catch-up after scrub release.
    - `xPosition(for:width:window:)` projects timestamps directly without stretching partial buffers (A5).
    - `valueAtEdge(points:)` and `value(at:points:)` evaluate the interpolated Y coordinate along `LiveChartMath.smoothSegments(points:tension:1.0)` without rewriting the spline.
- **Step 8.5.1.2 — Adaptive Nice-Number Scale & Domain Floors (`Sources/iStatsCore/LiveChartMath.swift`):**
  - Implemented `ChartScale.niceCeiling(for:floorVal:minSpan:)` using the `{1, 2, 2.5, 5} × 10^k` ladder with 3 clean intervals and `1.10` headroom.
  - Implemented `ChartScale.domainFloor(for:visibleMin:fixedFloor:)` (`.thermal`: `max(20, floor((visibleMin - 5) / 10) * 10)`, `.fan`: `fixedFloor ?? 0`, percentage/throughput/power: `0`, A9).
  - Implemented `ChartScaleState` with asymmetric dynamics: immediate `0.35 s` critically damped upward spring (`dampingFraction: 1.0`, no overshoot) and `3.0 s` hysteresis hold below `0.70 * displayedCeiling` before `0.60 s` ease-out contraction (A4), plus `update(visibleMax:visibleMin:category:...)` convenience.
- **Step 8.5.1.3 — Time-Aligned Envelope Buckets (`Sources/iStatsCore/Downsampler.swift`):**
  - Added `BucketPoint(timestamp:min:max:mean:)`.
  - Implemented `Downsampler.alignedBuckets(_:bucketWidth:windowDuration:)` grouping by `Int(floor(timestamp / bucketWidth))` with center timestamp `(Double(bucketID) + 0.5) * bucketWidth` and bucket-aligned window cutoff so closed historical buckets prior to the active epoch never mutate when new samples arrive (A6).
