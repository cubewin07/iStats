# Plan — 1.4 Implement the SampleScheduler

## Context
Implement `SampleScheduler` in `iStatsCore` to manage periodic background sampling of system telemetry, isolate sensor errors and timeouts, support per-category interval tuning, and publish typed results to consumers on the main thread (ADR 0002, Requirements 12.1, 12.3, 12.4).

## Objectives
1. Implement `AnySampler` type-erased wrapper for any `Sampler` conforming type.
2. Implement `MetricReading` composite enum for all metric categories and unavailable state with unified properties (`category`, `timestamp`, `availability`).
3. Implement `actor SampleScheduler` executing sampling loops off the main thread with error & timeout isolation (`withThrowingTaskGroup` time budget) and publishing via `AsyncStream` and MainActor callbacks.
4. Comprehensive unit tests covering registration, background execution, error isolation, timeout isolation, interval adjustment, enablement toggling, and stream consumption.
