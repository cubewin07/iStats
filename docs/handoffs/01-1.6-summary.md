# Summary — 1.6 Build the preferences shell

## Done
- Enhanced `Sources/iStatsCore/Units.swift`:
  - Extended `ByteUnitStandard` to conform to `String, CaseIterable, Identifiable, Codable, Sendable`.
  - Added `TemperatureUnit` (`.celsius`, `.fahrenheit`) and `NetworkUnit` (`.bytesPerSecond`, `.bitsPerSecond`) enums conforming to `String, CaseIterable, Identifiable, Codable, Sendable`.
- Created `Sources/iStatsCore/PreferencesStore.swift`:
  - Thread-safe, observable (`ObservableObject`), `Sendable` preferences store backed by `UserDefaults`.
  - Enforced sampling refresh interval clamping within `[minRefreshInterval (0.5s), maxRefreshInterval (60.0s)]` with default `2.0s` (Requirements 11.2, 11.4).
  - Persists enabled metric categories (`Set<MetricCategory>`), temperature unit, network rate unit, byte format standard, Dock icon visibility, and launch-at-login.
  - Implemented `resetToDefaults()` and dependency-injected initializer for test isolation.
- Created `Tests/iStatsCoreTests/PreferencesStoreTests.swift`:
  - Unit tests covering defaults, lower bound interval clamping, upper bound interval clamping, valid interval values, multi-instance persistence across isolated suites, category toggling, unit metadata, and reset to defaults.
- Created `iStats/UI/PreferencesView.swift`:
  - SwiftUI multi-tab preferences window (`General`, `Categories`, `Units`, `About`) with continuous slider, interval presets, Dock icon toggle, and unit pickers.
- Created `iStats/App/PreferencesWindowController.swift`:
  - `@MainActor` window controller managing preferences window instantiation, ordering front, and activating app in `LSUIElement` accessory mode.
- Updated `iStats/UI/DetailPopoverView.swift` to add "Preferences..." button opening the settings window.
- Updated `iStats/App/iStatsApp.swift` hooking `PreferencesView` to the `Settings` scene.
