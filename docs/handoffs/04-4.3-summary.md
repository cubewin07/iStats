# Summary — 4.3 Instantaneous power draw / wattage

## Done
- Implemented instantaneous power draw and adapter wattage monitoring in `HostPowerInfoProvider` and `PowerSampler`:
  - Adapter power (`adapterWatts`): Read from `AdapterDetails["Watts"]` / `PowerDistribution["IPDInputPower"]` / `props["Watts"]` when connected to AC power. Degrades to `nil` when running on battery or when unexposed.
  - Instantaneous power draw (`powerDrawWatts`): Read from Apple Silicon power telemetry (`PowerTelemetryData["SystemLoad"]`, `SystemPowerIn`, `SystemEnergyConsumed`, `BatteryPower`) or derived from `abs(Amperage * Voltage) / 1,000,000.0`.
  - Clean degradation: When hardware does not expose wattage, fields degrade cleanly to `nil` rather than misleading zeros (Requirement 8.3).
- Added comprehensive unit and live validation tests in `Tests/iStatsTests/PowerSamplerTests.swift`:
  - `testPowerSamplerInstantaneousPowerDrawAndAdapterWatts`: Validates adapter wattage (68.0 W) and power draw (15.299 W) from power telemetry data.
  - `testPowerSamplerPowerDrawFromAmperageAndVoltage`: Validates calculation from current amperage (-1500 mA) and voltage (12000 mV) producing 18.0 W.
  - `testPowerSamplerUnexposedWattageDegradesToNil`: Validates that unexposed adapter and power draw metrics degrade to `nil` rather than 0.0.
  - `testLiveHostPowerInfoProviderAndSampler`: Live verification against the macOS host (`IOPS` power source and `AppleSmartBattery` telemetry).
