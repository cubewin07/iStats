# Plan — 1.6 Build the Preferences Shell

## Intent
Build a persistent preferences store in `iStatsCore` and a native SwiftUI preferences window in the `iStats` app target. Wire the refresh-interval control with sane min/max bounds and ensure settings persist across launches (Requirements 11.2, 11.4).

## Current code
- What exists:
  - `iStatsCore`: `Units.swift` (temperature and byte conversions), `MetricCategory.swift` (all categories), `SampleScheduler.swift`, `MetricsStore.swift`.
  - `iStats`: `iStatsApp.swift`, `AppDelegate.swift`, `MenuBarController.swift`, `DetailPopoverView.swift`, `DockIconManager.swift`.
- What is missing:
  - `PreferencesStore` (persisted settings store with bounded interval, category toggles, unit options, dock icon visibility, and launch-at-login).
  - `PreferencesView` (SwiftUI multi-tab preferences window shell).
  - `PreferencesWindowController` (AppKit window controller to open settings in accessory / LSUIElement mode).
  - Popover entry point to open preferences.

## Approach
1. Update `Units.swift`:
   - Extend `ByteUnitStandard` with `String, CaseIterable, Identifiable, Codable`.
   - Add `TemperatureUnit` and `NetworkUnit` enums with `String, CaseIterable, Identifiable, Codable, Sendable`.
2. Implement `Sources/iStatsCore/PreferencesStore.swift`:
   - `PreferencesStore`: `ObservableObject`, thread-safe / main-actor friendly, backed by `UserDefaults`.
   - Bounded `refreshInterval: TimeInterval` clamped to `[0.5, 60.0]` with default `2.0`.
   - `enabledCategories: Set<MetricCategory>` defaulting to `MetricCategory.allCases`.
   - `temperatureUnit`, `networkUnit`, `byteUnitStandard`.
   - `showDockIcon` and `launchAtLogin`.
   - `resetToDefaults()`.
   - Initializer taking optional `UserDefaults` suite for test isolation.
3. Add unit tests in `Tests/iStatsCoreTests/PreferencesStoreTests.swift`:
   - Assert defaults, min/max interval clamping, multi-instance persistence across the same suite, category mutations, and reset.
4. Implement `iStats/UI/PreferencesView.swift`:
   - Multi-tab preferences window: General (refresh interval slider/presets, Dock icon toggle, Launch at login), Categories (toggles), Units (pickers), About (info and privacy statement).
5. Implement `iStats/App/PreferencesWindowController.swift` & update `DetailPopoverView.swift` and `iStatsApp.swift`:
   - Hook Settings scene and popover settings button to present the preferences window.
6. Update `iStats.xcodeproj/project.pbxproj` with new UI and App source files.
7. Run test suite and Xcode build to verify.
8. Create `docs/handoffs/01-1.6-summary.md` and update `docs/progress.md`.
