# Plan — 1.3 Define core protocols and value types

## Intent
Complete and verify the core value types and protocols in `Sources/iStatsCore`, adding missing composite wrappers (`ThermalSample`, `FanSample`, `NetworkSample`, `DiskSample`, `PowerSample`, `GPUSample`) and adding comprehensive unit test suites covering `Availability`, `Sample<T>`, `MetricCategory`, `Sampler`, and `Models`.

## Current code
- `Sources/iStatsCore/Availability.swift`: `Availability` and `Sample<Value>` exist.
- `Sources/iStatsCore/MetricCategory.swift`: `MetricCategory` exists.
- `Sources/iStatsCore/Sampler.swift`: `Sampler` protocol and `SamplerError` exist.
- `Sources/iStatsCore/Models.swift`: `CPUSample`, `MemoryPressure`, `MemorySample`, `SensorReading`, `FanReading`, `InterfaceThroughput` exist.
- Missing: `ThermalPressure`, `ThermalSample`, `FanSample`, `NetworkSample`, `VolumeCapacity`, `DiskIO`, `DiskSample`, `BatteryState`, `PowerSample`, `GPUSample`.
- Missing: Unit tests for core types in `Tests/iStatsCoreTests/`.

## Approach
1. Update `Sources/iStatsCore/Availability.swift`:
   - Add `Codable` conformance and `unavailableReason: String?` helper to `Availability`.
   - Add conditional `Equatable`, `Codable` conformances to `Sample<Value>`.
   - Add default parameter for `timestamp: Date = Date()` on `Sample.init`.
2. Update `Sources/iStatsCore/MetricCategory.swift`:
   - Ensure `Identifiable` conformance (`id: String { rawValue }`).
3. Update `Sources/iStatsCore/Models.swift`:
   - Add `ThermalPressure` (`nominal`, `fair`, `serious`, `critical`).
   - Add `ThermalSample` (`sensors: [SensorReading]`, `pressure: ThermalPressure?`).
   - Add `FanSample` (`fans: [FanReading]`).
   - Add `NetworkSample` (`interfaces: [InterfaceThroughput]`, plus aggregate throughput helpers).
   - Add `VolumeCapacity` (`name: String`, `mountPoint: String`, `total: UInt64`, `used: UInt64`, `free: UInt64`).
   - Add `DiskIO` (`bytesReadPerSec: Double`, `bytesWrittenPerSec: Double`, `readOpsPerSec: Double`, `writeOpsPerSec: Double`).
   - Add `DiskSample` (`volumes: [VolumeCapacity]`, `io: DiskIO?`).
   - Add `BatteryState` (`charging`, `discharging`, `charged`, `acConnected`, `unknown`).
   - Add `PowerSample` (`hasBattery: Bool`, `charge: Double?`, `state: BatteryState?`, `timeRemaining: TimeInterval?`, `cycleCount: Int?`, `condition: String?`, `designCapacity: Int?`, `currentMaxCapacity: Int?`, `powerDrawWatts: Double?`, `adapterWatts: Double?`).
   - Add `GPUSample` (`utilization: Double?`, `memoryUsed: UInt64?`, `tempCelsius: Double?`, `powerWatts: Double?`).
4. Create test files in `Tests/iStatsCoreTests/`:
   - `AvailabilityTests.swift`: test `Availability` cases, `isAvailable`, `unavailableReason`, `Sample` wrapping and equality.
   - `MetricCategoryTests.swift`: test all cases, `displayName`, `Identifiable`, `Codable`, `CaseIterable`.
   - `SamplerTests.swift`: test `Sampler` protocol with a mock sampler, and `SamplerError` cases.
   - `ModelsTests.swift`: test initialization, properties, equatability, and helper calculations for all domain models.
5. Run tests & build:
   - `swift test --scratch-path /tmp/istats-build`
   - `xcodebuild -scheme iStatsApp -derivedDataPath ./build build`
6. Update documentation:
   - Create `docs/handoffs/01-1.3-summary.md`
   - Update `docs/progress.md` (mark 1.3 `done`, next task `1.4`, update On disk table).
