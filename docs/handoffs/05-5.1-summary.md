# Summary — 5.1 Spike + ADR 0003: thermal/fan data source

## Done
- Executed hardware telemetry spike on Apple Silicon host machine (Apple M4 Pro, 14 cores, arm64, macOS 27):
  - **AppleSMC UserClient (`IOServiceMatching("AppleSMC")`)**:
    - Confirmed connection and communication via selector `2` (`kSMCHandleYPCEvent`) using an exact 80-byte C-compatible struct layout.
    - Verified fan telemetry: `FNum` = 2 fans, `F0Ac`/`F1Ac` (actual RPM, `flt` 32-bit float), `F0Mn`/`F1Mn` (min RPM: 2317 RPM), `F0Mx`/`F1Mx` (max RPM: 7826 RPM), `F0Md`/`F1Md` (mode).
    - Verified thermal keys: Battery thermals (`TB0T`..`TB2T`), SoC/Package (`Tp0T`), die array (`TD00`..`TD24`), memory/chipset (`TCHP`, `TCMb`, `TCMz`), E-cores (`Te05`, `Te0S`), and GPU clusters (`Tg05`, `Tg0S`).
    - Successfully read without requiring root privileges.
  - **IOHIDEventSystemClient (`IOKit.framework`)**:
    - Successfully connected and matched `PrimaryUsagePage = 0xff00` (AppleVendor) and `PrimaryUsage = 5` (Temperature Sensor).
    - Discovered 77 live thermal sensor services with descriptive hardware labels (`PMU tdie1`..`14`, `NAND CH0 temp`, `gas gauge battery`, `PMU tcal`, etc.) reading floating-point °C values.
    - Operates without elevated permissions.
  - **IOKit `IOAccelerator` (`AGXAccelerator`)**:
    - Discovered `PerformanceStatistics` dictionary in IORegistry.
    - Exposes live GPU metrics: `Device Utilization %`, `In use system memory` (bytes), `Alloc system memory` (bytes), `Renderer Utilization %`, `Tiler Utilization %`.
  - **Thermal Pressure**:
    - `ProcessInfo.processInfo.thermalState` provides high-level system thermal pressure (`nominal`, `fair`, `serious`, `critical`).
  - **IOReport / Powermetrics**:
    - `libIOReport.dylib` energy channels inspected (`GPU (mJ)`, `ANE (mJ)`, `DRAM (mJ)`).
    - `powermetrics` confirmed to require `sudo`, verifying its rejection as a runtime background sampler.
- Authored and updated **ADR 0003** (`docs/architecture/adr/0003-thermal-fan-data-source.md`) to **Accepted**, documenting data sources, memory layouts, key tables, and degradation policies.
- Verified test suites:
