# Summary — 2.6 Render CPU + memory in the detail view

## Done
- Extended `PreferencesStore` in `Sources/iStatsCore/PreferencesStore.swift`:
  - Added `MenuBarDisplayMode` enum (`icon`, `cpu`, `memory`, `both`) with `displayName` and `Codable`/`Sendable` conformances.
  - Added `@Published public var menuBarDisplayMode: MenuBarDisplayMode` persisted to `UserDefaults`.
  - Added reset support in `resetToDefaults()`.
- Implemented `iStats/App/MetricsCoordinator.swift`:
  - Central `@MainActor` coordinator bridging `SampleScheduler` background execution with `MetricsStore` telemetry buffers.
  - Registers `CPUSampler` and `MemorySampler`.
  - Observes and syncs sampling interval and category toggles from `PreferencesStore`.
  - Publishes `@Published` store, `latestCPU`, `latestMemory`, `cpuHistory`, and `memoryHistory`.
- Implemented `iStats/UI/RollingGraphView.swift`:
  - High-performance, lightweight SwiftUI vector graph rendering rolling historical samples (Requirement 10.2).
  - Smooth Bezier/linear strokes with subtle gradient area fills and grid lines.
- Implemented `iStats/UI/CPUSummaryView.swift`:
  - Comprehensive CPU card with total usage badge, live rolling graph, user/system/idle multi-segment progress breakdown, 1m/5m/15m load averages, clock frequency, and responsive per-core matrix with individual core progress bars (Requirements 10.1, 10.2, 10.3).
- Updated `iStats/UI/MemoryPressureView.swift`:
  - Enhanced `MemorySummaryView` with `RollingGraphView` displaying rolling memory percentage history over time alongside pressure badges, warning/critical alert banners, and memory breakdown grids.
- Updated `iStats/UI/DetailPopoverView.swift`:
  - Dynamically observes `MetricsCoordinator` and `PreferencesStore`.
  - Renders live `CPUSummaryView` and `MemorySummaryView` cards with real-time graph updates without blocking the main UI thread.
- Updated `iStats/UI/PreferencesView.swift`:
  - Added "Menu Bar Presentation" section with a selector for `MenuBarDisplayMode` (`Icon Only`, `CPU Usage`, `Memory Usage`, `CPU & Memory`) in the General tab (Requirement 9.4).
- Updated `iStats/App/MenuBarController.swift`:
  - Dynamically updates `NSStatusItem` title and icon according to `menuBarDisplayMode` and live telemetry updates from `MetricsCoordinator`.
  - Formats rich status item tooltips.
- Updated `iStats/App/AppDelegate.swift`:
  - Starts `MetricsCoordinator.shared.start()` on application launch.
- Created `Tests/iStatsTests/DetailViewGraphsTests.swift`:
  - Unit tests for `MetricsCoordinator` sample handling and state updates.
  - Geometry and point math tests for `RollingGraphView`.
  - View hierarchy and layout tests for `CPUSummaryView` and `DetailPopoverView`.
  - Pure string and tooltip formatting tests for `MenuBarController`.
- Extended `Tests/iStatsCoreTests/PreferencesStoreTests.swift`:
  - Tested `MenuBarDisplayMode` persistence across instances and defaults reset.
- Registered all new source and test files in `iStats.xcodeproj/project.pbxproj`.
