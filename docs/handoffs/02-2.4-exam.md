## Risks and unknowns
- `host_page_size` returns 16384 bytes on Apple Silicon and 4096 bytes on Intel x86_64; page count multiplications must use `UInt64` to prevent 32-bit overflow.
- `host_statistics64` with `HOST_VM_INFO64` returns `vm_statistics64_data_t` which must be cast with `mach_msg_type_number_t(HOST_VM_INFO64_COUNT)`.
- Activity Monitor definition of memory used: `app memory (internal - purgeable) + wired + compressed`. Cached files: `purgeable + external`. Free memory: `free`.
