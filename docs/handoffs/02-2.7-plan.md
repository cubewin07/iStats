# Plan — 2.7 Validate vs Reference Tools + Write Phase 2 Report

**Phase:** 2 — CPU & Memory  
**Task:** 2.7 Validate vs reference tools + write Phase 2 report  
**Requirements:** 14.5, 14.3  

---

## 1. Goal

1. Cross-validate live CPU and Memory telemetry from `CPUSampler` and `MemorySampler` against native macOS reference tools (`top`, `uptime`, `vm_stat`, `sysctl vm.swapusage`, `sysctl hw.memsize`).
2. Verify both idle state and active synthetic CPU workload to confirm direction and magnitude agreement.
3. Validate graceful handling of Apple Silicon dynamic CPU frequency (ADR 0002).
4. Run the full automated test suite (`iStatsCoreTests` and `iStatsTests`).
5. Write the comprehensive Phase 2 report in `docs/phases/phase-02-cpu-memory/report.md` capturing architectural learnings, validation results, and gotchas.
6. Update `docs/progress.md` marking Task 2.7 and Phase 2 as complete.

---

## 2. Validation Protocol

1. **CPU Idle Check:**
   - Sample CPU utilization at 1s intervals with `CPUSampler`.
   - Compare with `top -l 2 -s 1 -n 0` and `uptime`.
   - Check total usage %, user %, sys %, idle %, and 1m/5m/15m load averages.
2. **CPU Workload Check:**
   - Spawn a multi-core tight CPU loop across 4 cores.
   - Run `CPUSampler` and `top -l 2` concurrently.
   - Verify aggregate utilization rises predictably and per-core distribution reflects the active cores.
3. **Memory & Swap Check:**
   - Sample memory with `MemorySampler`.
   - Cross-check against `top` PhysMem, `vm_stat`, `sysctl vm.swapusage`, and `sysctl hw.memsize`.
   - Verify App Memory, Wired, Compressed, Cached, and Free memory math.
4. **Automated Test Validation:**
   - `swift test --scratch-path /tmp/istats-build`
   - `xcodebuild test -scheme iStatsApp -destination 'platform=macOS'`
   - `xcodebuild -scheme iStats -configuration Debug build`
