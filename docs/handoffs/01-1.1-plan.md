# Plan — 1.1 Create the Swift App Target with LSUIElement

## Intent
Create the initial `iStats` macOS application target with `LSUIElement` configured so the app runs as a menu bar agent without a Dock icon by default, while supporting dynamic activation policy toggling via `DockIconManager` for future preferences (Phase 6).

## Current code
- `Package.swift` — Defines `iStatsCore` library and unit tests.
- `Sources/iStatsCore/` — Pure core logic on disk.
- Missing: `iStats/` app source directory, `Info.plist`, and `iStats.xcodeproj`.

## Approach
1. Create `iStats/Resources/Info.plist` with `LSUIElement` set to `true` (`<key>LSUIElement</key><true/>`).
2. Create `iStats/App/DockIconManager.swift` to handle switching between `.accessory` and `.regular` activation policies on `@MainActor`.
3. Create `iStats/App/AppDelegate.swift` and `iStats/App/iStatsApp.swift` as the SwiftUI/AppKit app entry point.
4. Create `iStats.xcodeproj` (with `project.pbxproj` and shared scheme `iStats.xcscheme`) configured for macOS 13+, Swift 6, non-sandboxed (ADR 0005), and linking `iStatsCore`.
5. Verify build with `xcodebuild -scheme iStats -configuration Debug build` and test suite with `swift test --scratch-path /tmp/istats-build`.
6. Update `docs/progress.md` and write summary handoff.
