# Plan — 1.2 Install the status item and detail popover

## Intent
Install an `NSStatusItem` in the macOS menu bar via a dedicated `@MainActor` `MenuBarController` instantiated on app launch in `AppDelegate`, and wire its button click to toggle an `NSPopover` displaying an empty SwiftUI detail view shell (`DetailPopoverView`).

## Current code
- `iStats/App/AppDelegate.swift` exists but only initializes `DockIconManager`.
- `iStats/App/iStatsApp.swift` exists as the SwiftUI `@main` entry point.
- `iStats.xcodeproj` compiles target `iStats` linking `iStatsCore`.
- Missing: `MenuBarController.swift`, `DetailPopoverView.swift`, and wiring in `AppDelegate.swift`.

## Approach
1. Create `iStats/UI/DetailPopoverView.swift`:
   - SwiftUI View providing a clean macOS-styled placeholder detail shell.
   - Includes header ("iStats"), placeholder status indicator ("System Monitor"), and a footer with a Quit button.
2. Create `iStats/App/MenuBarController.swift`:
   - `@MainActor public final class MenuBarController: NSObject`
   - Owns `statusItem: NSStatusItem` created via `NSStatusBar.system.statusItem(withLength: NSStatusItem.variableLength)`.
   - Configures the status bar button with an SF symbol (`gauge.with.dots.needle.bottom.50percent` or `chart.bar.xaxis` / template image) and accessibility label.
   - Owns `popover: NSPopover` configured with `.transient` behavior and `NSHostingController(rootView: DetailPopoverView())`.
   - Implements `@objc func togglePopover(_ sender: AnyObject?)` to show/close popover relative to the status bar button.
3. Update `iStats/App/AppDelegate.swift`:
   - Hold a strong reference to `menuBarController: MenuBarController?`.
   - In `applicationDidFinishLaunching(_:)`, initialize `menuBarController = MenuBarController()`.
4. Update `iStats.xcodeproj/project.pbxproj`:
   - Add group `UI` under `iStats`.
   - Add file references and build files for `MenuBarController.swift` and `DetailPopoverView.swift`.
5. Build and verify:
   - `xcodebuild -scheme iStats -configuration Debug build`
   - `swift test --scratch-path /tmp/istats-build`

- `swift test --scratch-path /tmp/istats-build` — ensure no regressions in `iStatsCore`.

## Validation against a reference tool
- Not applicable for metric numbers in this task (no samplers running yet).
- Visual/interactive validation: status item present in menu bar, click toggles popover.

## Risks
- Popover edge positioning: popover should show with `preferredEdge: .minY` under the status bar item.
- Popover closing when losing focus: `.transient` behavior handles outside clicks automatically.

## Out of scope

- Preferences window opening from popover (Task 1.6 / Phase 6).
