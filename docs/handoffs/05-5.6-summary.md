# Summary — 5.6 ADR 0005 Sandbox/Entitlements + Graceful Degradation

## Done
- Authored and accepted **ADR 0005** (`docs/architecture/adr/0005-sandbox-and-entitlements.md`) addressing Requirements 13.1, 13.2, 12.3, and 12.4:
  - Documented the macOS security architecture constraints (App Sandbox `com.apple.security.app-sandbox`, Hardened Runtime, Gatekeeper/Notarization, and TCC permissions).
  - Conducted a comprehensive **Metric-by-Metric Sandbox Survivability & Entitlement Audit** across all 8 metric categories (CPU, Memory, Network, Disk, Power, Thermal, Fans, GPU).
  - Analyzed architectural alternatives: non-sandboxed unprivileged desktop app (chosen for v1), sandboxed app with privileged/unsandboxed XPC helper daemon (`SMAppService`), and sandboxed app with restricted metrics.
  - Formally accepted the **Non-Sandboxed Unprivileged Desktop Application Posture with Strict Least-Privilege**: zero root permissions requested, zero silent privilege escalation, zero helper daemons.
  - Formulated the **Graceful Degradation Contract**: all denied sensor reads, missing hardware, restricted Mach/sysctl/IOKit calls degrade cleanly to `Availability.unavailable(reason:)` without throwing uncaught exceptions, hanging, or crashing the process.
  - Verified scheduler error isolation (ADR 0002) ensuring failures in one sampler never block or degrade sibling samplers.
- Implemented comprehensive sandbox denial and graceful degradation test suite in `Tests/iStatsTests/SandboxDegradationTests.swift`:
  - Tested `ThermalSampler` degradation under simulated `EPERM` / access denial.
  - Tested `FanSampler` degradation when `AppleSMC` connection fails.
  - Tested `GPUSampler` degradation when `IOAccelerator` performance dictionaries or statistics are denied or return nil.
  - Tested `SampleScheduler` multi-category isolation: proved healthy `CPUSampler` yields `.available` readings while denied `Thermal`, `Fan`, and `GPU` samplers concurrently degrade to `.unavailable` without stalling the pipeline.
  - Tested UI component resilience: verified `ThermalSummaryView`, `FanSummaryView`, `GPUSummaryView`, and `DetailPopoverView` render cleanly when data is unavailable or empty.
- Updated Xcode project `iStats.xcodeproj/project.pbxproj` to include `SandboxDegradationTests.swift`.
- Verified test suites and build:
  - `swift test --scratch-path /tmp/istats-build` — **115 passed** (0 failures).
  - `xcodebuild test -scheme iStatsApp -derivedDataPath ./build` — **135 passed** (0 failures).
  - `xcodebuild -scheme iStatsApp -derivedDataPath ./build build` — **BUILD SUCCEEDED**.
