# Plan — 2.6 Render CPU + memory in the detail view

## Intent
Render live CPU metrics (aggregate utilization, per-core matrix, load average, frequency) and memory statistics in the detail popover with smooth rolling history graphs fed from `MetricsStore`, and allow configuring the menu bar display mode (Icon Only, CPU, Memory, or CPU & Memory) per Requirements 9.4, 10.1, 10.2, and 10.3.

## Current code
- `Sources/iStatsCore/PreferencesStore.swift`: Manages intervals, category enablement, units.
- `Sources/iStatsCore/MetricsStore.swift`: Ring buffer store with typed accessors (`cpuHistory()`, `memoryHistory()`, `latestCPU()`, `latestMemory()`).
- `Sources/iStatsCore/SampleScheduler.swift`: Background sampling actor supporting registration, dynamic intervals, and async streams.
- `iStats/Sampling/CPUSampler.swift` & `MemorySampler.swift`: Samplers producing `CPUSample` and `MemorySample`.
- `iStats/App/MenuBarController.swift`: Configures `NSStatusItem` and hosts `DetailPopoverView`.
- `iStats/UI/DetailPopoverView.swift`: Base popover shell.
- `iStats/UI/MemoryPressureView.swift`: Memory gauge and pressure indicators.

## Approach
1. **Extend Preferences for Menu Bar Display (Requirement 9.4)**:
   - Add `MenuBarDisplayMode` enum (`icon`, `cpu`, `memory`, `both`) to `Sources/iStatsCore/PreferencesStore.swift`.
   - Persist to `UserDefaults` under `Keys.menuBarDisplayMode`.
   - Add picker to `iStats/UI/PreferencesView.swift` under the General tab.
2. **Implement MetricsCoordinator (`iStats/App/MetricsCoordinator.swift`)**:
   - `@MainActor public final class MetricsCoordinator: ObservableObject`.
   - Manages `SampleScheduler` and `MetricsStore`.
   - Registers `CPUSampler` and `MemorySampler`.
   - Subscribes to `scheduler.stream` / `onMainActorSample` and updates `@Published` store, `latestCPU`, `latestMemory`, `cpuHistory`, and `memoryHistory`.
   - Syncs refresh interval and enabled category changes from `PreferencesStore`.
3. **Build Reusable Rolling Graph Component (`iStats/UI/RollingGraphView.swift`)**:
   - SwiftUI graph drawing historical values as a smooth line with gradient fill below the curve.
   - Configurable stroke color, gradient, baseline, bounds (0...100 or custom), and subtle gridlines.
   - Handles empty / single-value states cleanly.
4. **Build CPUSummaryView (`iStats/UI/CPUSummaryView.swift`)**:
   - Total CPU utilization gauge / headline (e.g. `14.2%`).
   - Rolling history graph (`RollingGraphView`) showing last N samples.
   - Breakdown badges/bars: User %, System %, Idle %.
   - Load averages: 1 min, 5 min, 15 min.
   - CPU clock frequency if available (e.g. `3.20 GHz`).
   - Per-core utilization matrix: compact multi-column grid displaying individual bars and percentages for all CPU cores.
5. **Update MemorySummaryView with Rolling Graph (`iStats/UI/MemoryPressureView.swift`)**:
   - Add `RollingGraphView` rendering historical memory usage percentage over time.
6. **Update DetailPopoverView (`iStats/UI/DetailPopoverView.swift`)**:
   - Connect to `MetricsCoordinator.shared`.
   - Conditionally render `CPUSummaryView` and `MemorySummaryView` when their respective categories are enabled in `PreferencesStore`.
   - Display live metrics updating smoothly on every scheduler tick.
7. **Update MenuBarController for Live Metric Display (`iStats/App/MenuBarController.swift`)**:
   - Dynamically format `NSStatusItem` title and icon based on `PreferencesStore.shared.menuBarDisplayMode` and `MetricsCoordinator.shared` updates.
   - `.icon`: SF symbol only.
   - `.cpu`: e.g. "CPU 14%".
   - `.memory`: e.g. "RAM 62%".
   - `.both`: e.g. "CPU 14%  RAM 62%".
8. **Start Coordinator in AppDelegate (`iStats/App/AppDelegate.swift`)**:
   - Start `MetricsCoordinator.shared.start()` on application launch.
9. **Unit & View Tests**:
   - Add `PreferencesStoreTests` cases in `Tests/iStatsCoreTests/` verifying `menuBarDisplayMode` persistence and reset.
   - Add `DetailViewGraphsTests.swift` in `Tests/iStatsTests/` verifying graph math, view hierarchy rendering, and menu bar string formatting.
10. **Register New Files in Xcode Project**:
    - Update `iStats.xcodeproj/project.pbxproj` with new Swift files and test target references.

## Tests
- `swift test --scratch-path /tmp/istats-build`
- `xcodebuild test -scheme iStatsApp -destination 'platform=macOS'`
- Assertions for:
  - `MenuBarDisplayMode` raw value mapping, persistence, and reset defaults.
  - `MetricsCoordinator` stores samples, tracks active category buffers, and propagates to `@MainActor`.
  - `RollingGraphView` point calculation for arbitrary datasets.
  - `CPUSummaryView` and `MemorySummaryView` rendering across varied core counts (e.g. 1 to 24 cores).
  - Status item title formatting for all display modes.

## Validation against a reference tool
- Run Activity Monitor and compare:
  - Aggregate CPU % and per-core activity window against iStats live display.
  - Memory used and pressure level against iStats memory card and graph.

## Risks
- View layout jitter: Fixed-width monospaced formatting for menu bar text and detail labels prevents layout jumping when numbers change.

## Out of scope
- Thermal, Fan, GPU, Network, Disk, Power sampling/graphs (scheduled for Phases 3–5).
