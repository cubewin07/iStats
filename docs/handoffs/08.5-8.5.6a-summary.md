## Changes Implemented

### 1. Persistent Host & Open/Close Content Lifecycle (`iStats/App/MetricPanel.swift`)
- Kept a single persistent `PanelBackgroundView` and `NSHostingView<AnyView>` (`sizingOptions = []`, `translatesAutoresizingMaskIntoConstraints = false`, `wantsLayer = true`) created in `init` so Auto Layout never fights animated frame updates.
- `setSwiftUIContent(_:)` swaps `hostingView.rootView` in place, attaches `.onPreferenceChange(PanelContentHeightKey.self)` forwarding reported heights to `onContentHeightChanged`, and pins content `.frame(maxWidth: .infinity, maxHeight: .infinity, alignment: .top)`.
- Added `clearContent()` to reset `hostingView.rootView = AnyView(EmptyView())`, remove `"openTransform"` layer animations, and clear `targetHeight`, ensuring timelines stop and `onDisappear` fires on close (keeping `startProcessDemand`/`stopProcessDemand` balanced).
- Added `animateOpenTransform()` (0.28 s scale `0.96 -> 1.0` from top-center, `y: -6 -> 0`, model transform kept at `CATransform3DIdentity`, skipped during tests and Reduce Motion) and `targetHeight`.

### 2. Single Height Channel, First-Open Sizing, Close/Show Race & Pinned Guard (`iStats/App/PanelController.swift`, `iStats/App/MenuBarController.swift`)
- **Single height channel (B2, A10):** Replaced both `DispatchQueue.main.async { updateFittingHeight }` blocks and all `.fittingSize` reads with `setContentHeight(_:for:animated:)` performing top-anchored `setFrame` (`0.32 s`, `CAMediaTimingFunction(controlPoints: 0.2, 0.9, 0.25, 1.0)`), clamped to screen `visibleFrame.minY + 8.0`.
- **First-open size (B5):** `show(...)` builds `content()` once and measures synchronously via `NSHostingController(rootView: AnyView(builtView)).sizeThatFits(in: CGSize(width: Instrument.Size.panelWidth, height: Instrument.Size.maxHeight))`, clamped to `[160, Instrument.Size.maxHeight]` before ordering front.
- **Close/show race & status-item click handling (B1):** Added `transitionGeneration: UInt64` counter. `show(...)` bumps it, restores `alphaValue = 1.0` if `wasVisible`, and cancels stale fade-out teardowns (`self.transitionGeneration == closeGen && self.currentCategory == nil`). Injected `statusItemHitTest: ((NSPoint) -> Bool)?` from `MenuBarController` (`containsStatusItem(at:)`) so global/local dismissal monitors ignore clicks on any app status-item button.
- **Pinned guard (B6):** Both `show(...)` and `handleStatusItemHover(...)` close any transient panel and front a visible pinned panel for that category instead of creating a duplicate transient panel. `MenuBarController` guards `startScrubbingMonitor()` and `currentlyShownButton` with `isTransientPanelOpen(for:)`.
- **Pin/unpin motion:** `togglePin(for:)` animates moving to the saved origin (`0.28 s`); `unpin(category:immediately:)` and `unpinAll(immediately:)` fade out (`0.12 s` ease-in) before `orderOut` and `clearContent()`.

### 3. Single Scroll Container, PreferenceKey & Cross-View Effect Removal (`iStats/UI/Panels/PanelScaffold.swift`)
- Added `PanelContentHeightKey: PreferenceKey` and `PanelStackLayout: Layout` to compute chrome + clamped scroll-body height in one pass without `@State` chrome-height lag.
- Replaced `ViewThatFits` with a single `ScrollView(.vertical, showsIndicators: false)` around `PageBodySlot` for all three tabs, sized to `min(measuredBodyHeight, maxHeight - chromeHeight)`, with `.scrollDisabled(bodyFits)` and `.id(selection)` tab transitions.
- Removed `@Namespace private var chartNamespace`, `.environment(\.chartNamespace, ...)`, and `.matchedGeometryEffect` on `chartZone` so hero chart collapses cleanly while History fades/slides 8 pt. Preserved `EnvironmentValues.chartNamespace` (`nil` default) so `HistoryPage.swift` remains untouched and compatible.
