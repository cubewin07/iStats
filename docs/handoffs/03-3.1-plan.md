# Plan — 3.1 Implement NetworkSampler

**Role:** Planner
**Phase:** 3 — Network & Disk
**Task:** 3.1 Implement NetworkSampler
**Requirements:** 6.1, 6.2, 6.3

---

## 1. Context & Objectives

- Implement `NetworkSampler` conforming to `Sampler` (`Output = NetworkSample`, `category = .network`).
- Read network interface byte statistics from Darwin kernel using `sysctl(NET_RT_IFLIST2)` (providing 64-bit `if_data64` counters without 32-bit wrap) with fallback to `getifaddrs`.
- Report current upload and download throughput per interface and calculate system aggregate (Requirements 6.1, 6.2).
- Track cumulative bytes sent and received for the session (Requirement 6.3).
- Provide clean dependency injection via `NetworkInfoProvider` protocol to allow deterministic unit testing.
- Integrate `NetworkSampler` into `MetricsCoordinator` and register with `SampleScheduler`.

---

## 2. Implementation Steps

1. **Implement `NetworkSampler.swift`** (`iStats/Sampling/NetworkSampler.swift`):
   - `RawInterfaceCounters`: Value struct with `name`, `bytesIn`, `bytesOut`, `isLoopback`, `isUp`.
   - `NetworkInfoProvider`: Protocol returning `[RawInterfaceCounters]`.
   - `HostNetworkInfoProvider`: Darwin implementation querying `sysctl(CTL_NET, PF_ROUTE, 0, 0, NET_RT_IFLIST2, 0)` with memory safety and error checking, falling back to `getifaddrs` if needed.
   - `NetworkSampler`:
     - Keeps state of previous timestamps, previous byte counters per interface, and cumulative session totals per interface.
     - Pure static method `calculateSample(previous:current:currentTimestamp:sessionTotals:includeLoopback:)` computing `[InterfaceThroughput]`.
     - Handles cold start (first sample produces 0 B/s), interface churn, and session total accumulation.

2. **Update `MetricsCoordinator.swift`** (`iStats/App/MetricsCoordinator.swift`):
   - Add `@Published public private(set) var latestNetwork: Sample<NetworkSample>?`.
   - Add `@Published public private(set) var networkHistory: [Sample<NetworkSample>] = []`.
   - Register `NetworkSampler()` in `start()`.
   - Update `latestNetwork` and `networkHistory` in `handleReading(_:)`.

3. **Update Xcode Project** (`iStats.xcodeproj/project.pbxproj`):
   - Add `NetworkSampler.swift` to `iStats` app target and `Sampling` group.
   - Add `NetworkSamplerTests.swift` to `iStatsTests` target and `Tests/iStatsTests` group.

4. **Add Unit Tests** (`Tests/iStatsTests/NetworkSamplerTests.swift`):
   - Cold start first sample testing.
   - Multi-interface throughput calculation over elapsed time.
   - Session total accumulation across multiple samples.
   - Interface addition/removal behavior.
   - Loopback filtering (`includeLoopback = false` vs `true`).
   - System error handling and exception isolation.
   - Live `HostNetworkInfoProvider` integration test.

5. **Verification & Handoff**:
   - Run `swift test --scratch-path /tmp/istats-build`.
   - Run `xcodebuild test -scheme iStatsApp -destination 'platform=macOS'`.
   - Update `docs/progress.md` and write `docs/handoffs/03-3.1-summary.md`.
   - Commit Task 3.1.
