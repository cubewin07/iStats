# Summary — 9.2 Preferences model v2 and migration

## Done
- `PreferencesMigration` (`currentVersion = 2`, key `iStats.preferencesSchemaVersion`), called at the top of `PreferencesStore.init`. Idempotent. v1 -> v2:
  - builds `alertRules` from the 12 legacy alert keys (legacy keys are left in place);
  - sets `hasCompletedOnboarding = true` when any `iStats.*` key already existed, otherwise false (never overwrites an existing value);
  - folds `widgetPopoverStyles` and per-item `popoverStyle` into per-item `popover` (raw-dictionary rewrite, so unknown fields survive; `menuBarItems` is never dropped);
  - removes `widgetPopoverStyles` and `menuBarDisplayMode`; a future schema version is left untouched.
- `AlertRule` / `AlertKind` / `AlertComparison` (`enabled`, `threshold`, `comparison`, `sustainSeconds`, `cooldownSeconds`, optional `target`). `PreferencesStore.alertRules` always holds one clamped rule per kind. The old `cpuAlertEnabled` ... `alertCooldownInterval` properties remain as computed bridges, so `AlertCoordinator` and the Alerts pane are unchanged. `memoryAlertCriticalPressureOnly` and `notificationsEnabled` stay as their own keys (no `AlertRule` field).
- `PanelDestination` (`.overview` / `.category`, Codable as its `storageKey` string) and `MenuBarAppearance` (`monochrome` / `statusTint` default / `categoryColor`).
- New store keys: `lastPanelDestination` (default `.overview`), `lastSettingsSection` (`String?`), `hasCompletedOnboarding`, `menuBarAppearance`, `networkInterfaceSelection` (`String?`). `resetToDefaults()` resets all but `hasCompletedOnboarding`.
- Pinned origins: `pinnedOrigin(forDestinationKey:)` / `setPinnedOrigin(_:forDestinationKey:)` plus `PanelDestination` and `MetricCategory` overloads (existing category-keyed entries stay valid).
- Tab memory is per category only: `PanelFactory.makePanelView` always uses `categoryLastTabs`; `PopoverConfig.rememberLastTab` removed (old key decoded and ignored, never re-encoded); the "Remember last tab" toggle was removed from `PreferencesMenuBarPane`.
- Dead state removed: `MenuBarDisplayMode`, `menuBarDisplayMode`, `MenuBarController.formatTitle/formatToolTip`, `widgetPopoverStyles`, `PopoverStyle` (28 cases), `MenuBarItemConfig.popoverStyle/resolvedPopoverStyle` (legacy `popoverStyle` still decodes into `popover`), and the store helpers `isItemEnabled`, `toggleItem`, `updateItemOptions`, `toggleCategory`, `setSamplingPaused`, `toggleSamplingPaused`, `popoverStyle(for:)`, `resolvedPopoverStyle`, `setPopoverStyle`.
