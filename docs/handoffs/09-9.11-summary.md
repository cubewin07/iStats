# Summary — 9.11 Onboarding and Metric Glossary

## Done
- **Core Glossary & Debug Scratch Defaults (`Sources/iStatsCore/MetricGlossary.swift`, `Sources/iStatsCore/PreferencesStore.swift`)**:
  - Added `MetricTerm`, `GlossaryEntry(key, category, title, summary, typical)` (with `meaning` and `learnMore` aliases), and `MetricGlossary` (`entry(for:)`, `entry(forKey:)`, `requiredKeys`, `entries(for:)`, `entries(for:enabledCategories:)`) covering CPU, Memory, GPU, Thermal, Fans, Network, Disk, and Power terms (`memory_pressure`, `swap`, `compressed`, `wired`, `load_average`, `pe_cores`, `cycle_count`, `max_capacity`, `iops`, `rssi`, `snr`, `throttling`, `thermal_state`, `gpu_engines`, `fan_rpm_range`, etc.).
  - Added `#if DEBUG` launch argument `-iStatsUseScratchDefaults YES` support (`shouldUseScratchDefaults(arguments:)`, `makeScratchDefaults(suiteName:)`) on `PreferencesStore.shared`, plus `applyOnboarding(preset:appearance:hasBattery:hasFans:)` and `skipOnboarding(hasBattery:hasFans:)`.
- **Contextual `InfoButton` & Panel/Settings Wiring (`iStats/UI/Instrument/InfoButton.swift`, `MetricRow.swift`, `Module.swift`, `SectionEyebrow.swift`, `AlertsSettingsView.swift`, `iStats/UI/Panels/*.swift`)**:
  - Added `InfoButton(term:)` / `InfoButton(key:)` using `Instrument` design tokens (`TokenLintTests` green) with `"About <title>"` accessibility label and popover showing title, summary, and typical values.
  - Added optional `glossaryKey: MetricTerm?` to `MetricRow`, `Section` (`Module.swift`), and `SectionEyebrow`, and wired `glossaryKey` / `InfoButton` onto key rows and sections across `CPUPanel`, `MemoryPanel`, `GPUPanel`, `TemperaturePanel`, `FanPanel`, `NetworkPanel`, `DiskPanel`, `PowerPanel`, and `AlertRuleEditorRow` in `AlertsSettingsView`.
- **`?` Glossary Sheet (`iStats/UI/Instrument/InfoButton.swift`, `PanelScaffold.swift`, `OverviewView.swift`, `PanelChrome.swift`, `PanelController.swift`)**:
  - Wired `?` (`PanelCommand.showGlossary`) and `"Metric Glossary  ?"` in `PanelHeaderStrip`'s `⋯` menu to present `GlossarySheetView` for the active `PanelDestination` (category terms or grouped enabled-category terms on Overview).
  - Updated `PanelController`'s local mouse monitor so clicks inside child popovers and attached sheets do not dismiss transient panels.
- **Welcome Onboarding & Launch/About Wiring (`iStats/UI/Welcome/WelcomeView.swift`, `iStats/App/WelcomeWindow.swift`, `iStats/App/AppDelegate.swift`)**:
  - Built 3-step `WelcomeView` + `WelcomeFlowModel`: (1) iStats overview + in-memory privacy promise (ADR 0006), (2) hardware-aware `MenuBarPreset` (`.minimal`, `.balanced`, `.everything`) + `MenuBarAppearance` with live `WidgetPreview` menu bar strip, (3) optional notification permission request and explicit launch-at-login toggle (`SMAppService`, never enabled silently).
  - Applying writes `menuBarItems`, `menuBarAppearance`, and `hasCompletedOnboarding = true`; skipping applies `.balanced` and sets `hasCompletedOnboarding = true`.
  - `AppDelegate` initializes `WelcomeWindow.shared` (observing `SettingsSection.showWelcomeNotificationName` from About Settings) and presents it on launch only when `PreferencesStore.shared.hasCompletedOnboarding == false`.
