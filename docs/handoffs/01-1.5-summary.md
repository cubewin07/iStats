# Summary — 1.5 Implement the MetricsStore Ring Buffer

## Done
- Enhanced `RingBuffer` in `Sources/iStatsCore/RingBuffer.swift`:
  - Added `mutating func clear()` to reset stored elements while preserving buffer capacity.
  - Added `extension RingBuffer: Equatable where Element: Equatable`.
- Implemented `MetricsStore` in `Sources/iStatsCore/MetricsStore.swift`:
  - Pure, in-memory `struct MetricsStore: Sendable, Equatable` holding rolling histories per `MetricCategory` (Requirement 10.2, ADR 0006).
  - Per-category `RingBuffer<MetricReading>` initialized across all `MetricCategory.allCases`.
  - Configurable `defaultCapacity` (default: 60) with optional per-category capacity overrides.
  - Ingestion methods: `append(_ reading: MetricReading)`, `append(_ readings: [MetricReading])`, `record(category:value:timestamp:availability:)`, `recordUnavailable(category:reason:timestamp:)`.
  - Query APIs: `readings(for:)` (FIFO chronological order: oldest to newest), `latest(for:)`, `count(for:)`, `capacity(for:)`, `isEmpty(for:)`, `isFull(for:)`, `subscript(category:)`.
  - Aggregates: `totalCount`, `activeCategories`.
  - Typed sample extractors & history filters for all 8 categories (`latestCPU()`, `latestMemory()`, `latestThermal()`, `latestFan()`, `latestGPU()`, `latestNetwork()`, `latestDisk()`, `latestPower()`, `cpuHistory()`, `memoryHistory()`, `thermalHistory()`, `fanHistory()`, `gpuHistory()`, `networkHistory()`, `diskHistory()`, `powerHistory()`).
  - Clearing APIs: `clear(category:)`, `clearAll()`.
- Added unit tests:
  - `Tests/iStatsCoreTests/RingBufferTests.swift`: Added tests for `clear()` preserving capacity and `Equatable` conformance.
  - `Tests/iStatsCoreTests/MetricsStoreTests.swift`: Added 10 test cases covering default initialization, custom/per-category capacities, FIFO ordering, eviction at capacity (oldest sample dropped first), category isolation, batch append, unavailable record handling, typed extractors and history filtering, category/all clearing, and equality comparison.
- Verified test suite: all 67 unit tests pass (`swift test --scratch-path /tmp/istats-build`).
- Verified app target build: `xcodebuild -scheme iStatsApp -configuration Debug build` succeeded.
