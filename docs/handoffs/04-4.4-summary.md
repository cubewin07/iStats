# Summary — 4.4 Handle the no-battery case

## Done
- Created `PowerSummaryView` in `iStats/UI/PowerSummaryView.swift`:
  - Renders live Battery & Power telemetry in the detail popover view.
  - Implements dedicated handling for machines with no internal battery (e.g. desktop Macs such as Mac Studio, Mac mini, Mac Pro, iMac) (Requirement 8.4).
  - On no-battery machines:
    - Displays an AC power indicator banner (`Desktop Mac (AC Powered)` / `No internal battery installed`).
    - Hides or marks battery-specific metrics (charge %, state, time remaining, cycle count, condition, capacity) as not applicable.
    - Completely eliminates misleading 0% charge, 0 cycle count, or fake error states.
    - Preserves system power draw / power supply wattage if exposed by hardware.
  - On battery-equipped machines:
    - Renders dynamic battery charge gauge, state badge, and time remaining (e.g. `75% · Discharging · 3h left`, `45% · Charging · 50m to full`).
    - Renders battery health card (cycle count, condition, maximum capacity vs design capacity).
    - Renders instantaneous power draw & adapter wattage with rolling 60s history graph (`RollingGraphView`).
- Updated `DetailPopoverView.swift` in `iStats/UI/`:
  - Integrated `PowerSummaryView` gated by `preferences.isCategoryEnabled(.power)`.
  - Added optional override support for `powerSample` and `powerHistory` for SwiftUI previews and automated unit testing.
- Updated Xcode Project (`iStats.xcodeproj/project.pbxproj`):
  - Registered `PowerSummaryView.swift` under the `UI` group in `iStats` app target.
- Added comprehensive unit tests in `Tests/iStatsTests/DetailViewGraphsTests.swift` & `Tests/iStatsTests/PowerSamplerTests.swift`:
  - `testMetricsCoordinatorHandlesPowerReadings`: Validates `MetricsCoordinator` handling of `.power` readings and publishing to `latestPower` / `powerHistory`.
  - `testPowerSummaryViewRenderingWithBattery`: Validates rendering with an active battery sample and health/wattage details.
  - `testPowerSummaryViewRenderingChargingState`: Validates rendering during active AC charging with time-to-full.
  - `testPowerSummaryViewRenderingNoBatteryMachine`: Validates graceful no-battery handling on desktop Macs with exposed wattage.
  - `testPowerSummaryViewRenderingNoBatteryUnexposedWattage`: Validates graceful no-battery handling when wattage is unexposed.
  - `testPowerSummaryViewRenderingNilSample`: Validates sampling/loading state without errors.
  - `testDetailPopoverViewWithAllCategoriesIncludingPower`: Validates rendering with all five categories active (CPU, Memory, Network, Disk, Power).
  - `testDetailPopoverViewWithNoBatteryMachine`: Validates popover rendering on desktop machines without batteries.
  - `testPowerSamplerNoBatteryMachine`: Validates pure sampler derivation on desktop machines.
  - `testPowerSamplerBatteryNotPresentGracefulDegradation`: Validates degradation when battery is reported as physically absent/disconnected (`isPresent: false`).
  - `testPowerSamplerDesktopMacWithPowerSupplyWattage`: Validates that desktop Mac preserves adapter/system wattage while keeping all battery fields strictly `nil`.
  - `testPowerSamplerDesktopMacAllMetricsAreStrictlyNil`: Validates that all battery and wattage metrics degrade cleanly to `nil` with zero dummy values.
