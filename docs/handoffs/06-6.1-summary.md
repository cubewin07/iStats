# Summary — 6.1 Full Preferences: Categories, Menu Bar Content, Units

## Done
- Expanded `MenuBarDisplayMode` in `PreferencesStore` with support for all telemetry display modes:
  - `.icon`: Clean status item icon only.
  - `.cpu`: Percentage utilization ("CPU 42%").
  - `.memory`: RAM utilization ("RAM 50%").
  - `.both`: Combined processor and RAM ("CPU 35%  RAM 25%").
  - `.network`: Dual upload/download throughput with configurable rate & byte units ("↓ 1.2 MB/s  ↑ 45 KB/s").
  - `.battery`: Battery level and charging state ("92% ⚡", "85%", or "AC Power" for desktops).
  - `.thermal`: Primary SoC package temperature respecting °C/°F unit preferences ("45 °C" / "113 °F").
  - `.gpu`: GPU utilization ("GPU 64%").
- Enhanced `MenuBarController`:
  - Added reactive subscription pipeline across all preference keys and telemetry publishers (`$latestCPU`, `$latestMemory`, `$latestNetwork`, `$latestPower`, `$latestThermal`, `$latestGPU`, `$menuBarDisplayMode`, `$temperatureUnit`, `$networkUnit`, `$byteUnitStandard`).
  - Added rich multi-metric tooltip generator formatting snapshot stats across all active categories.
- Updated `MemorySummaryView` and `DetailPopoverView`:
  - Added `byteStandard: Units.ByteUnitStandard` support to `MemorySummaryView` so that changing IEC vs SI preference dynamically formats memory quantities (wired, compressed, cached, swap, used, total).
- Added comprehensive unit tests in `Tests/iStatsTests/MenuBarDisplayTests.swift`:
