# Summary — 4.2 Battery health metrics

## Done
- Implemented battery health telemetry reading in `HostPowerInfoProvider` via `AppleSmartBattery` IOKit registry:
  - Cycle count (`cycleCount`): Read from `props["CycleCount"]` / `BatteryData["CycleCount"]`.
  - Condition (`condition`): Read from `props["Condition"]` / `PermanentFailureStatus` (0 -> "Normal", non-zero -> "Service Battery").
  - Design capacity (`designCapacity`): Read from `BatteryData["DesignCapacity"]` / `props["DesignCapacity"]` in mAh.
  - Current maximum capacity (`currentMaxCapacity`): Read from `BatteryData["NominalChargeCapacity"]` / `BatteryData["FullChargeCapacity"]` / `AppleRawMaxCapacity` in mAh.
- Implemented pure calculation in `PowerSampler.calculateSample` attaching battery health metrics to `PowerSample`.
- Graceful degradation: When `smartBatteryData` is unavailable or on machines with no battery, all health fields degrade cleanly to `nil` rather than fake zeros or error states.
- Added comprehensive unit tests in `Tests/iStatsTests/PowerSamplerTests.swift`:
  - `testPowerSamplerBatteryHealthMetrics`: Validates cycle count (79), condition ("Normal"), design capacity (6249), and current max capacity (5894).
  - `testPowerSamplerHealthConditionServiceBattery`: Validates "Service Battery" condition reporting on degraded batteries.
  - `testPowerSamplerSmartBatteryUnavailableDegradesToNil`: Validates that unavailable smart battery data results in `nil` fields while charge and state remain functional.
  - `testPowerSamplerNoBatteryMachine`: Validates that no-battery machines report `nil` for all health metrics.
