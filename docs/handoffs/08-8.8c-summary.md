# Task 8.8c Summary: GPU Panel (Engine Rings)

## Overview
Implemented `GPUPanel.swift` adhering to ADR 0009 "Instrument" design language and task specification `8.8c-gpu-panel.md`. Features the signature Engine Rings (`RingStack` with Device, Renderer, and Tiler tracks), Device-only ring fallback with caption for GPUs without engine decomposition, VRAM working set meter, driver recovery status in the status ribbon, and comprehensive hardware architecture facts on the detail page.

## Implementation Details
1. **`GPUPanel.swift`**:
   - **Glance**:
     - GPU utilization percentage via `PanelGlance`.
     - Concise headline generated via `PanelHeadline.gpu(sample:)`.
     - Rolling 60s interactive `LiveChart` driven by `ScalarSeriesKey.gpuUtilization`.
     - Dynamic status resolution: warning for driver recoveries (> 0), elevated for utilization >= 80%, critical for >= 95%.
     - Recovery status ribbon warning when GPU driver resets are detected.
   - **Now Page (Overview)**:
     - 76 pt concentric `RingStack` displaying Device, Renderer, and Tiler utilization rings with color tint gradations.
     - Device-only fallback showing a single ring and the caption `"Engine breakdown not exposed by this GPU"`.
     - Side-by-side indicator dots, labels, and rolling tabular digits via `LiveNumber`.
     - VRAM Working Set `Meter` showing allocated vs recommended maximum bytes, or allocated graphics working set row.
     - Subsystem telemetry rows for power consumption (watts) and die temperature.
   - **Detail Page (Engines / Device)**:
     - Dynamic tab title resolving to "Engines" when detailed engines are present, or "Device" when device-only.
     - Per-engine `Meter` visualizers for Device, 3D Renderer, and Geometry / Tiler engines.
     - Hardware Architecture facts module: Metal device name, GPU core count, unified vs discrete memory architecture, Metal feature set, ray tracing support, and connected display descriptions.
   - **History Page**:
     - Clean telemetry module preparing for unified Phase 8.10 history page.
2. **Integration & Tests**:
   - Wired `GPUPanel` into `PanelFactory.swift` and `project.pbxproj`.
   - Added `testGPUPanelRendersFullEnginesCleanly` and `testGPUPanelDeviceOnlyFallbackAndRecoveryWarning` in `Tests/iStatsTests/PanelScaffoldTests.swift`.
