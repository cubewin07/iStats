# Plan — 3.3 Disk capacity per volume

## Goal
Implement `DiskSampler` capacity reads (total / used / free) per mounted volume via `statfs` (Darwin `getfsstat`), dynamically discovering mounted volume additions and removals across sampling cycles without requiring app restarts (Requirements 7.1, 7.3).

## Proposed changes

1. **`iStats/Sampling/DiskSampler.swift`**:
   - Define `RawDiskIOCounters` and `DiskInfoProvider` protocol for dependency injection.
   - Implement `HostDiskInfoProvider` using Darwin `getfsstat(..., MNT_NOWAIT)` to read `statfs` structures for all mounted filesystems.
   - Resolve localized volume display names via `URLResourceKey.volumeLocalizedNameKey` / `volumeNameKey` / `FileManager.displayName`.
   - Calculate `total`, `used`, `free` capacity bytes per mounted volume, filtering out 0-capacity / pseudo filesystems.
   - Implement `DiskSampler: Sampler` (`Output = DiskSample`, `category = .disk`).
2. **`iStats/App/MetricsCoordinator.swift`**:
   - Register `DiskSampler` in `start()`.
   - Expose `@Published public private(set) var latestDisk: Sample<DiskSample>?`.
   - Expose `@Published public private(set) var diskHistory: [Sample<DiskSample>] = []`.
   - Handle `.disk` reading category in `handleReading(_:)`.
3. **`Tests/iStatsTests/DiskSamplerTests.swift`**:
   - Test category `.disk`.
   - Test volume capacity parsing with mock provider.
   - Test dynamic volume addition and removal across sample calls without restarting.
   - Test error propagation and isolation.
   - Test live `HostDiskInfoProvider` on macOS.
4. **`iStats.xcodeproj/project.pbxproj`**:
   - Register `DiskSampler.swift` and `DiskSamplerTests.swift`.
