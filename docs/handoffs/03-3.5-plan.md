# Plan — 3.5 Network/disk in detail view + bytes/bits option

**Task:** 3.5 Network/disk in detail view + bytes/bits option  
**Phase:** 3 — Network & Disk  
**Requirements:** 10.1, 11.3  

## Objective
Render Network and Disk monitoring in the detail view popover with live metrics, 60s rolling history graphs, per-interface metrics, session transfer totals, mounted volume storage gauges, and a user preference for network throughput units (bytes/s vs bits/s).

## Approach

1. **Pure Units & Formatters (`iStatsCore`):**
   - Add `Units.formatNetworkRate(_:unit:standard:fractionDigits:)` supporting `bytesPerSecond` (IEC/SI) and `bitsPerSecond` (bps, Kbps, Mbps, Gbps).
   - Add `Units.formatDiskRate(_:standard:fractionDigits:)`.
   - Add unit tests in `UnitsTests.swift`.

2. **Network UI Component (`NetworkSummaryView`):**
   - Live aggregate upload and download throughput.
   - 60-second rolling graph (`RollingGraphView`) of total bandwidth.
   - Cumulative session data transfer totals (`totalBytesIn`, `totalBytesOut`).
   - Per-interface breakdown for active interfaces (`bytesInPerSec`, `bytesOutPerSec`, session totals).

3. **Disk UI Component (`DiskSummaryView`):**
   - Live read and write I/O rates + ops/sec if available (`io: DiskIO`), with 60s rolling I/O graph.
   - Clean degradation if I/O is unavailable / nil.
   - Per-volume capacity cards: mount point, progress gauge with color thresholds, used/free/total byte counts.

4. **Integration (`DetailPopoverView`):**
   - Wire up `coordinator.latestNetwork`, `coordinator.networkHistory`, `coordinator.latestDisk`, `coordinator.diskHistory`.
   - Render `NetworkSummaryView` and `DiskSummaryView` conditionally based on `preferences.isCategoryEnabled`.
   - Propagate `preferences.networkUnit` and `preferences.byteUnitStandard`.

5. **Testing & Verification:**
   - Unit tests for pure rate formatters in `UnitsTests`.
   - UI snapshot/rendering and view hierarchy tests in `DetailViewGraphsTests`.
   - Run `swift test --scratch-path /tmp/istats-build` and `xcodebuild test -scheme iStatsApp`.
