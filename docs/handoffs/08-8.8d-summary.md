# Task 8.8d Summary: Temperature Panel (Thermal Spectrum)

## Overview
Implemented `TemperaturePanel.swift` adhering to ADR 0009 "Instrument" design language and task specification `8.8d-thermal-panel.md`. Features the signature Thermal Spectrum bar (10 pt capsule painted with `ThermalRamp.linearGradient`), collision-free marker placement via pure `SpectrumLayout.place(markers:width:minSpacing:)`, sorted group meters, quiet-when-healthy thermal pressure surfacing, and collapsible, copyable sensor lists.

## Implementation Details
1. **Pure Collision Layout Engine (`SpectrumLayout.swift`)**:
   - `SpectrumLayout.place(markers:width:minSpacing:minValue:maxValue:)`:
     - Resolves multi-sensor marker placement along the 30°–110°C spectrum bar.
     - Automatically assigns vertical tiers (`tier = 0, 1, ...`) when distance between adjacent markers is below `minSpacing` (e.g. 16 pt).
     - Handles identical temperature readings and preserves deterministic ascending order.
   - `SpectrumLayout.placeHorizontal(markers:width:minSpacing:minValue:maxValue:)`:
     - Alternate 1D non-overlapping layout engine enforcing horizontal relaxation within width boundaries.
   - Comprehensive test suite in `Tests/iStatsCoreTests/SpectrumLayoutTests.swift` (7 unit tests).
2. **`TemperaturePanel.swift`**:
   - **Glance**:
     - Peak temperature formatted cleanly respecting user preferences (°C vs °F).
     - Headline generated via `PanelHeadline.thermal(sample:cpuTemp:gpuTemp:)`.
     - 60s interactive `LiveChart` representing peak thermal trend.
     - Quiet-when-healthy status: nominal pressure is `.fine` (no banner/ribbon); elevated/serious/critical triggers appropriate status color and warning ribbon.
   - **Now Page (Overview)**:
     - 10 pt capsule filled with Display P3 `ThermalRamp.linearGradient`.
     - Collision-free marker placement across the spectrum bar for each active subsystem (CPU, GPU, Memory, Storage, Battery).
     - Color-interpolated marker dots with vertical stacking offsets for colliding groups.
     - Thermal Groups module displaying each active hardware group with temperature reading and mini `Meter` range bar, sorted hottest first.
   - **Detail Page (Sensors)**:
     - Sensors grouped by classifier (`ThermalSensorClassifier`), sorted hottest first.
     - Each sensor row includes `ThermalRamp.color` indicator, readable sensor name, exact temperature, and click-to-copy via `.copyable(text:)`.
3. **Integration & Tests**:
   - Wired `TemperaturePanel` into `PanelFactory.swift` and `project.pbxproj`.
   - Added `testTemperaturePanelRendersCleanly` and `testTemperaturePanelThermalPressureRibbon` in `Tests/iStatsTests/PanelScaffoldTests.swift`.
