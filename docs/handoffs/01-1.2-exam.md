# Exam — 1.2 Install the status item and detail popover

## Snapshot
On disk today:
- `iStatsCore` has pure models (`CPUSample`, `MemorySample`, etc.), `Availability`, `MetricCategory`, `Sampler`, `RateMath`, `RingBuffer`, and `Units`.
- `iStatsApp` SwiftUI entry point exists with an `@NSApplicationDelegateAdaptor(AppDelegate.self)`.
- `AppDelegate` configures `DockIconManager.shared.applyCurrentPolicy()` in `applicationDidFinishLaunching(_:)`.
- `DockIconManager` dynamically manages `.accessory` vs `.regular` activation policy.

## Risks and unknowns
- Popover dismissal behavior: `NSPopover.Behavior.transient` must be used so clicking outside automatically closes the popover.
- Window key status: when popover opens, ensuring proper focus without breaking accessory app behavior.
- Dark/Light mode template images: the status bar icon should be marked as template (`isTemplate = true`) or use SF symbols configured for menu bar so it renders correctly on all wallpaper/accent settings.
