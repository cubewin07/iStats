# Summary — 3.5 Network/disk in detail view + bytes/bits option

## Done
- Implemented pure throughput rate formatters in `Units` (`Sources/iStatsCore/Units.swift`):
  - `Units.formatNetworkRate(_:unit:standard:fractionDigits:)` supporting `bytesPerSecond` (IEC `B/s`, `KiB/s`, `MiB/s`, `GiB/s` and SI `B/s`, `KB/s`, `MB/s`, `GB/s`) and `bitsPerSecond` (decimal `bps`, `Kbps`, `Mbps`, `Gbps`, `Tbps`).
  - `Units.formatDiskRate(_:standard:fractionDigits:)`.
  - Added unit test cases covering normal, unit conversion, SI/IEC standard, and edge case inputs in `Tests/iStatsCoreTests/UnitsTests.swift` (11 tests passed).
- Implemented `NetworkSummaryView` (`iStats/UI/NetworkSummaryView.swift`):
  - Header showing aggregate upload/download rates formatted by active network unit preference.
  - 60-second rolling history graph (`RollingGraphView`) tracking network throughput.
  - Session cumulative transfer totals (`totalBytesIn`, `totalBytesOut`).
  - Per-interface breakdown displaying individual active interface throughput (down/up) and session totals.
- Implemented `DiskSummaryView` (`iStats/UI/DiskSummaryView.swift`):
  - Header showing live Read / Write I/O rates (or volume count if I/O unavailable).
  - 60-second rolling history graph for disk I/O throughput + ops/sec badges (when I/O statistics available).
  - Mounted volumes capacity section with visual progress gauge bars, percentage used, total, and free storage amounts.
  - Graceful degradation when I/O is unavailable.
- Integrated `NetworkSummaryView` and `DiskSummaryView` into `DetailPopoverView` (`iStats/UI/DetailPopoverView.swift`):
  - Added network and disk state bindings and preview/test overrides.
  - Dynamically rendered sections based on `preferences.isCategoryEnabled(.network)` and `preferences.isCategoryEnabled(.disk)`.
  - Propagated `preferences.networkUnit` and `preferences.byteUnitStandard` to reflect live user preference changes.
- Registered new UI views in `iStats.xcodeproj/project.pbxproj`.
- Added UI and coordinator test cases in `Tests/iStatsTests/DetailViewGraphsTests.swift`:
  - Verified `MetricsCoordinator` processes `.network` and `.disk` readings and publishes history.
  - Verified `NetworkSummaryView` rendering under bytes/sec, bits/sec, IEC, SI, and nil samples.
  - Verified `DiskSummaryView` rendering with and without I/O stats (graceful degradation).
  - Verified `DetailPopoverView` rendering with all categories enabled.
