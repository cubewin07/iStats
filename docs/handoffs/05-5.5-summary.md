# Summary — 5.5 Implement GPUSampler

## Done
- Implemented `GPUSampler`, `GPUInfoProvider` protocol, `HostGPUInfoProvider`, and `RawGPUStatistics` in `iStats/Sampling/GPUSampler.swift`:
  - Queries IOKit `IOAccelerator` (`AGXAccelerator` on Apple Silicon and AMD/Intel accelerators) via non-privileged IORegistry performance statistics dictionary (`PerformanceStatistics`).
  - Reads GPU core utilization percentage (supporting `"Device Utilization %"`, `"GPU Activity(%)"`, `"GPU Core Utilization"`, `"Renderer Utilization %"`), clamped to `0...100%`.
  - Reads GPU memory usage (`"In use system memory"`, `"vramUsedBytes"`), and allocated memory (`"Alloc system memory"`).
  - Reads renderer and tiler utilization statistics.
  - Queries GPU temperature telemetry via `PerformanceStatistics` and fallback AppleSMC GPU thermal keys (`Tg05`, `Tg0S`, `TG0P`, `TG0D`, `TG0T`).
  - Emits pure domain `GPUSample` models with validation and clamping (`calculateSample(raw:)`).
  - Degrades gracefully: when GPU statistics are absent, throws `SamplerError.unsupported` allowing `SampleScheduler` to surface `Availability.unavailable(reason:)` without affecting other samplers (Requirement 5.3, ADR 0003).
- Implemented `GPUSummaryView.swift` in `iStats/UI/`:
  - Native SwiftUI card component displaying GPU core utilization, rolling history graph (60s with peak indicator), memory in use (IEC/SI standard), GPU temperature (°C/°F), and power draw.
  - Handles sampling states, active states, and graceful unavailable degradation.
- Updated `DetailPopoverView.swift` in `iStats/UI/`:
  - Added GPU section rendering `GPUSummaryView` when `preferences.isCategoryEnabled(.gpu)` is true.
  - Added testing and preview overrides for `gpuSample` and `gpuHistory`.
- Updated `MetricsCoordinator.swift` in `iStats/App/`:
  - Registered `GPUSampler()` in `start()`.
  - Added `@Published public private(set) var latestGPU: Sample<GPUSample>?` and `gpuHistory: [Sample<GPUSample>] = []`.
  - Updated `handleReading` for `.gpu` readings.
- Updated Xcode project `iStats.xcodeproj/project.pbxproj`:
  - Added `GPUSampler.swift` and `GPUSummaryView.swift` to `iStats` target.
  - Added `GPUSamplerTests.swift` to `iStatsTests` target.
- Added comprehensive unit and integration test suite in `Tests/iStatsTests/GPUSamplerTests.swift`:
  - Tested `GPUSampler` category (`.gpu`).
  - Tested mock provider with full metrics, partial metrics, nil statistics, and provider failure.
  - Tested pure `calculateSample` clamping for out-of-bounds utilization, negative memory, and out-of-bounds temperatures/power.
  - Tested live `HostGPUInfoProvider` on Apple Silicon host hardware (verified non-zero utilization, in-use memory, and temperature).
  - Tested `GPUSummaryView` rendering with active metrics, Fahrenheit/SI units, and unavailable states.
  - Tested `DetailPopoverView` integration with GPU category.
  - Tested `MetricsCoordinator` GPU stream handling and sample updates.
