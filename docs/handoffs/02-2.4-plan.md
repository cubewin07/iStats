# Plan — 2.4 Implement MemorySampler

## Intent
Implement `MemorySampler` conforming to `Sampler` in `iStats/Sampling/MemorySampler.swift`. Read VM statistics via Mach `host_statistics64(HOST_VM_INFO64)`, system page size via `host_page_size`, physical installed memory via `sysctl hw.memsize`, swap usage via `sysctl vm.swapusage`, and initial memory pressure via `sysctl kern.memorystatus_vm_pressure_level`. Ensure memory page math adheres strictly to macOS Activity Monitor conventions.

## Current code
- `Sources/iStatsCore/Models.swift`: `MemorySample` and `MemoryPressure` exist.
- `iStats/Sampling/CPUSampler.swift`: Exemplar implementation with `CPUInfoProvider` and pure calculation function `calculateSample`.

## Approach
1. Enhance `MemorySample` in `Sources/iStatsCore/Models.swift` to optionally expose `appMemory`, `active`, `inactive`, `swapTotal`, `swapFree` while keeping initializers fully backward-compatible.
2. Create `iStats/Sampling/MemorySampler.swift`:
   - Define `RawVMStatistics` containing raw page counts (`free`, `active`, `inactive`, `wire`, `compressed`, `purgeable`, `external`, `internal`).
   - Define `SwapUsageData` containing total, used, free swap in bytes.
   - Define `MemoryInfoProvider` protocol with methods for `vmStatistics()`, `physicalMemoryBytes()`, `swapUsage()`, and `memoryPressure()`.
   - Implement `HostMemoryInfoProvider` using Darwin Mach calls (`host_statistics64`, `host_page_size`) and `sysctlbyname` (`hw.memsize`, `vm.swapusage`, `kern.memorystatus_vm_pressure_level`).
   - Implement `MemorySampler` with pure `calculateSample(stats:pageSize:totalPhysicalMemory:swapUsage:pressure:) -> MemorySample`.
3. Add `MemorySampler.swift` and `MemorySamplerTests.swift` to `iStats.xcodeproj/project.pbxproj`.
4. Create `Tests/iStatsTests/MemorySamplerTests.swift` with comprehensive unit and live verification tests.
5. Verify test pass with `swift test --scratch-path /tmp/istats-build` and `xcodebuild test -scheme iStatsApp`.

## Tests
- `swift test --scratch-path /tmp/istats-build`
- `xcodebuild test -scheme iStatsApp -destination 'platform=macOS'`
- Specific assertions:
  - Page size multiplication handles Apple Silicon (16KB) and Intel (4KB).
  - Memory used = App Memory (internal - purgeable) + Wired + Compressed.
  - Cached files = Purgeable + External.
  - Free = free_count * page_size.
  - Total RAM matches `hw.memsize` exactly.
  - Swap used correctly decodes `xsw_usage`.
  - Darwin system errors throw `SamplerError.systemCallFailed`.

## Validation against a reference tool
- Run `vm_stat` and `sysctl hw.memsize vm.swapusage` on local host.
- Compare with `HostMemoryInfoProvider` readings to verify agreement.

## Risks
- Mach buffer counts: `HOST_VM_INFO64_COUNT` must be passed correctly to `host_statistics64`.
- Checked return values: never force-unwrap kern_return_t or sysctl return values.
