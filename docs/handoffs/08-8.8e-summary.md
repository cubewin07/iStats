# Task 8.8e Summary: Fans Panel (Turbine + Fanless State)

## Overview
Implemented `FanPanel.swift` adhering to ADR 0009 "Instrument" design language and task specification `8.8e-fan-panel.md`. Features the signature rotating `TurbineView` (5-blade aerodynamic shape driven by `FanMath` visual speed curves), `ArcGauge` dials per fan with min/max hardware limits, read-only safety policy per ADR 0004, and a dedicated `InsetEmptyState` for fanless Macs with a one-click action to swap directly to the temperature panel.

## Implementation Details
1. **Pure Speed Mathematics (`FanMath.swift`)**:
   - `FanMath.visualSpeed(rpm:min:max:)`:
     - Translates raw RPM readings to revolutions per second (RPS).
     - Caps maximum visual rotation speed strictly at 1.5 rps to prevent visual blur/strobing.
     - Maps minimum/idle spinning RPM smoothly to 0.2 rps.
     - Returns 0.0 rps when RPM <= 0 or when fan is stopped.
   - `FanMath.fraction(rpm:min:max:)` and `FanMath.rotationDegrees(time:speedRPS:)`.
   - 7 unit tests in `Tests/iStatsCoreTests/FanMathTests.swift`.
2. **Turbine Shape & Widget (`TurbineShape.swift`)**:
   - `TurbineShape`: Custom 5-blade aerodynamic path with central hub and quad-curved blades.
   - `TurbineView`: Rotating instrument turbine driven by `TimelineView` (minimum interval 1/60s), halting animation under `MotionPolicy != .full` or when sampling is paused.
3. **`FanPanel.swift`**:
   - **Glance**:
     - Max RPM across all active fans (or 0 for fanless).
     - Headline generated via `PanelHeadline.fan(sample:)`.
     - 60s interactive `LiveChart` representing fan speed trends (omitted cleanly when fanless).
     - Read-only acoustic policy notice referencing ADR 0004.
   - **Now Page (Active Fans)**:
     - Per-fan module with signature `TurbineView`, 54 pt `ArcGauge` dial from `minRPM` to `maxRPM`, and large `LiveNumber` RPM display.
     - Range bounds formatting with fallback for SMC implementations without exposed limits.
   - **Fanless State**:
     - Polished `InsetEmptyState` with `wind` icon: "Fanless by design" / "This Mac cools passively. See Temperature for heat."
     - One-click button "Open Temperature" triggering `PanelController.shared.swapToCategory(.thermal)`.
4. **Integration & Tests**:
   - Wired `FanPanel` into `PanelFactory.swift` and `project.pbxproj`.
   - Added `testFanPanelActiveFansRendersCleanly` and `testFanPanelFanlessMacRendersEmptyStateWithAction` in `Tests/iStatsTests/PanelScaffoldTests.swift`.
