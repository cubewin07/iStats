# Summary — 3.1 Implement NetworkSampler

## Done
- Created `NetworkSampler` in `iStats/Sampling/NetworkSampler.swift`:
  - Defined `RawInterfaceCounters` holding interface name, bytes in/out, loopback status, and up state.
  - Defined `NetworkInfoProvider` protocol for dependency injection and testing.
  - Implemented `HostNetworkInfoProvider` using Darwin `sysctl(CTL_NET, PF_ROUTE, 0, 0, NET_RT_IFLIST2, 0)` to read 64-bit `if_data64` counters without 32-bit counter wrap, with graceful fallback to `getifaddrs`.
  - Implemented `NetworkSampler` conforming to `Sampler` (`Output = NetworkSample`, `category = .network`).
  - Thread-safe state tracking with `NSLock` storing previous snapshot (`InterfaceState`) and session totals (`InterfaceSessionTotal`).
  - Pure calculation in `calculateSample` computing per-interface `InterfaceThroughput` and session totals, with loopback filtering (`includeLoopback: false` by default).
- Updated `MetricsCoordinator.swift` in `iStats/App/`:
  - Added `@Published public private(set) var latestNetwork: Sample<NetworkSample>?`.
  - Added `@Published public private(set) var networkHistory: [Sample<NetworkSample>] = []`.
  - Registered `NetworkSampler()` in `start()`.
  - Handled `.network` readings in `handleReading(_:)`.
- Updated Xcode Project (`iStats.xcodeproj/project.pbxproj`):
  - Registered `NetworkSampler.swift` under `Sampling` group in `iStats` app target.
  - Registered `NetworkSamplerTests.swift` under `Tests/iStatsTests` in `iStatsTests` test target.
