# Task 5.4 — ADR 0004 + opt-in fan control (if safe)

**Phase:** 5 — Thermal, Fan & GPU
**Requirements:** 4.3, 4.4, 13.2

## What to do

- Author ADR 0004 on privilege and fan control.
- If safe and feasible on the target hardware, implement opt-in fan control within
  hardware-reported bounds via a privileged helper.
- Otherwise present fans as read-only and clearly explain why.

## Goal (definition of done)

- ADR 0004 records the privilege decision; no silent privilege escalation.
- Fan control is either opt-in and bounded, or clearly read-only with an explanation.
