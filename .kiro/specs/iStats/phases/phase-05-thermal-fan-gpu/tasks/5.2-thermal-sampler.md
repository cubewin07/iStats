# Task 5.2 — Implement ThermalSampler

**Phase:** 5 — Thermal, Fan & GPU
**Requirements:** 3.1, 3.2, 3.3, 3.4, 11.3

## What to do

- Read available thermal sensors via the source chosen in ADR 0003.
- Give each sensor a human-readable name; report °C with a °F option.
- Report system thermal pressure/state where exposed.
- Mark `.unavailable` (without crashing or blocking others) when sensors are inaccessible.

## Goal (definition of done)

- Accessible sensors are listed with readable names and correct °C/°F values.
- Thermal pressure shown where exposed; clean `.unavailable` otherwise.
