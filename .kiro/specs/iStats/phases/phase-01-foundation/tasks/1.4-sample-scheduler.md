# Task 1.4 — Implement the SampleScheduler

**Phase:** 1 — Foundation
**Requirements:** 12.1, 12.3, 12.4

## What to do

Implement `SampleScheduler`:

- Runs on a background queue; triggers each enabled sampler at its per-category interval.
- Publishes results to the main actor.
- Wraps each `sampler.sample()` in do/catch with a time budget so one failing/slow sampler
  marks itself `.unavailable` for the cycle without affecting the others.

## Goal (definition of done)

- Sampling runs off the main thread (Requirement 12.1).
- A thrown error in one sampler is isolated (Requirement 12.3).
- Increasing the interval reduces sampling frequency (Requirement 12.4).
