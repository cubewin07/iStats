# Task 1.3 — Define core protocols and value types

**Phase:** 1 — Foundation
**Requirements:** 1.5, 12.3

## What to do

Define the core, pure value types and the sampler protocol:

- `Sampler` protocol (with `category` and `sample() throws -> Output`).
- `Sample<T>` (value + timestamp + availability).
- `Availability` (`available` / `unavailable(reason:)`).
- `MetricCategory` enum.

## Goal (definition of done)

- Types compile and live in `Core/` with no OS/hardware dependencies.
- Every later sampler can conform to `Sampler` and report `.unavailable` cleanly.
