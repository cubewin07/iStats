# Task 1.5 — Implement the MetricsStore ring buffer

**Phase:** 1 — Foundation
**Requirements:** 10.2

## What to do

- Implement `MetricsStore`: a fixed-capacity ring buffer per metric category holding the
  last N minutes of samples in memory.
- Keep it pure (no OS dependency, no telemetry persistence).
- Add unit tests for capacity and eviction (oldest sample dropped when full).

## Goal (definition of done)

- Ring buffer respects its capacity and evicts oldest-first.
- Unit tests pass and cover the full/overflow edge cases.
