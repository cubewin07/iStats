# Task 0.2 — Write the prerequisites & learning guide

**Phase:** 0 — Documentation scaffolding & learning baseline
**Requirements:** 14.4, 14.5

## What to do

Write `docs/prerequisites-and-learning.md` covering:

- OS concepts and macOS frameworks needed for this project: `sysctl`, Mach host stats
  (`host_statistics`, `host_processor_info`), IOKit, SMC, `IOPowerSources`,
  IOReport/`powermetrics` concepts, and SwiftUI/AppKit menu bar patterns.
- A per-metric "validate against reference tool" checklist mapping each metric category to
  a known-good reference: Activity Monitor, `top`, `df`, `pmset`, `powermetrics`.

## Goal (definition of done)

- A developer with no prior OS-level macOS experience can read this doc and know what to
  study before each phase.
- Every metric category has at least one named reference tool and a short note on how to
  compare values.
