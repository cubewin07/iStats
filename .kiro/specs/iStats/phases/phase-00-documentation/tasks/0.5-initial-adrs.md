# Task 0.5 — Author the initial ADRs

**Phase:** 0 — Documentation scaffolding & learning baseline
**Requirements:** 14.1, 13.3

## What to do

Author the initial Architecture Decision Records:

- **ADR 0001 — Language & UI stack:** Swift + SwiftUI/AppKit native, with the rationale
  (OS learning, full API access) and alternatives considered (Tauri/Electron).
- **ADR 0002 — Threading & scheduling model:** background `SampleScheduler` with
  per-sampler isolation; results published to the main actor.
- **ADR 0006 — Telemetry privacy / no persistence:** telemetry kept in-memory only;
  only preferences persisted; data never leaves the device (Requirement 13.3).

## Goal (definition of done)

- Three ADRs exist in `docs/adr/`, each in standard ADR format
  (context, decision, consequences, status).
- The privacy/no-persistence stance is fixed before any sampler is built.
