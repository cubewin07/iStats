# Task 2.5 — Memory pressure level + UI surfacing

**Phase:** 2 — CPU & Memory
**Requirements:** 2.2, 2.4

## What to do

- Derive the macOS memory pressure level (normal / warning / critical) via the memory
  pressure source / `sysctl`.
- Surface warning/critical states visibly in the UI.

## Goal (definition of done)

- Pressure level is reported alongside memory stats.
- When pressure becomes warning or critical, the UI makes it clearly visible
  (Requirement 2.4).
