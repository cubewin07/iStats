# Task 2.3 — Property tests for CPU % math

**Phase:** 2 — CPU & Memory
**Requirements:** 1.1, 12.1

## What to do

Add pure unit/property tests for the CPU % computation using synthetic tick counters:

- Result is always within `0...100`.
- Monotonic non-decreasing counters never produce negative utilization.
- user + system + idle reconciles to the total within rounding tolerance.

## Goal (definition of done)

- CPU % math is covered by property tests independent of hardware.
- Tests pass and document the invariants.
