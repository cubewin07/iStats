# Task 2.2 — Load average and CPU frequency

**Phase:** 2 — CPU & Memory
**Requirements:** 1.3, 1.5

## What to do

- Read the system load average (1/5/15 minute) via `sysctl vm.loadavg`.
- Read CPU frequency where the hardware exposes it; otherwise mark it `.unavailable`
  (expected on Apple Silicon).

## Goal (definition of done)

- Load average is reported and matches `uptime`/`top`.
- CPU frequency is reported where available, else cleanly `.unavailable` (no misleading
  zero).
