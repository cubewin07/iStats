# Task 2.1 — Implement CPUSampler (total + per-core)

**Phase:** 2 — CPU & Memory
**Requirements:** 1.1, 1.2, 1.4

## What to do

Implement `CPUSampler` using Mach `host_processor_info`:

- Read cumulative CPU tick counters; hold the previous reading.
- Compute total and per-core utilization % from tick deltas.
- Break down user / system / idle time.

## Goal (definition of done)

- Sampler returns aggregate %, per-core %, and user/system/idle split each cycle.
- Values track real load and are sane (0–100% per core).
