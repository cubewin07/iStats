# Task 3.3 — Disk capacity per volume

**Phase:** 3 — Network & Disk
**Requirements:** 7.1, 7.3

## What to do

- Implement `DiskSampler` capacity reads (total / used / free) per mounted volume via
  `statfs`.
- React to volumes being added or removed by updating the monitored list.

## Goal (definition of done)

- Capacity figures match `df` for each mounted volume.
- Mounting/unmounting a volume updates the list without a restart.
