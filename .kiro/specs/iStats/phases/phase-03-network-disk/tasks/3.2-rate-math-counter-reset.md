# Task 3.2 — Network rate math with counter-reset handling

**Phase:** 3 — Network & Disk
**Requirements:** 6.4

## What to do

- Derive throughput from byte deltas between consecutive samples.
- Handle counter reset / interface restart: if the current counter is below the previous,
  treat the delta as 0 for that cycle (never negative or absurd).
- Add property tests for the rate function.

## Goal (definition of done)

- Rate is never negative and a counter reset never produces a huge false spike.
- Property tests cover normal deltas and reset edge cases.
